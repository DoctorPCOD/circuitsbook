    Section 1.6 Elementary Signals

    Elementary signals are used to mathematically describe the types of signals used as sources, or signals that are commonly encountered in the analog circuit world. Each of the signals can be expressed mathematically.
    🔗

    Subsection 1.6.1 Dirac Delta Function

    The Dirac delta function is a useful approximation of a “spike.” It is used to model an impulse, and is commonly used in signal processing (including Fourier analysis). It is defined as a normal (Gaussian) distribution when the variance is equal to zero. The mathematical expression used to define the Dirac delta function is defined in (1.6.1), where \(A\) is the amplitude of the function and \(\tau\) is the time at which the function occurs.
    🔗
    \begin{equation} f(t) = A\delta(t-\tau)\tag{1.6.1} \end{equation}
    🔗
    The Dirac delta function defined in (1.6.1) is depicted graphically in Figure 1.6.1.
    🔗

    Example 1.6.2 Plotting a signal composed of Dirac delta functions.

    Plot \(f(t) = 4\delta(t-1) - 2\delta(t+3)\text{.}\) The first term has an amplitude of \(A = 4\) and is located at \(t = 1~\textrm{s}\text{.}\) The second term has an amplitude of \(A = -2\) and is located at \(t = -3~\textrm{s}\text{.}\) The graph is shown in Figure 1.6.3.
    🔗
    🔗
    The Dirac delta function has a sifting property. It is capable of being used to determine the value of a continuous function at a certain point. This property is defined in (1.6.2).
    🔗
    \begin{equation} \int_{-\infty}^\infty f(t)\delta(t-a)\, dt = f(a)\tag{1.6.2} \end{equation}
    🔗
    🔗

    Subsection 1.6.2 Step Function

    The unit step function is a piecewise function whose value is zero when the argument is negative, and equal to one when the argument is zero or positive. This function is described in (1.6.3).
    🔗
    \begin{equation} u(\tau) = \begin{cases} 0 \amp \text{if } \tau \lt 0\\ 1 \amp \text{if } \tau \geq 0 \end{cases}\tag{1.6.3} \end{equation}
    🔗
    The unit step function comes from integrating the Dirac delta function, as shown in (1.6.4).
    🔗
    \begin{equation} u(t) = \int_{-\infty}^{t} \delta(\tau) \, d\tau\tag{1.6.4} \end{equation}
    🔗
    The step function is very useful for describing a source that is off for a long period of time before being turned on at some moment. Mathematically, the step function is defined in (1.6.5), where \(A\) is the amplitude of the function and \(\tau\) is the time at which the step starts.
    🔗
    \begin{equation} f(t) = Au(t-\tau)\tag{1.6.5} \end{equation}
    🔗
    The step function defined in (1.6.5) is depicted graphically in Figure 1.6.4.
    🔗
    Typically in this textbook, we will see the unit step function used to depict a function that starts at a particular period in time. (This will specifically be the case in Chapter 5, Chapter 6, Chapter 7, and Chapter 11.)
    🔗

    Example 1.6.5 Deriving the equation of a signal composed of step functions.

    Derive an equation corresponding to the graph shown in Figure 1.6.6.
    🔗
    This signal is composed of four different step functions. The first occurs at \(t = -2~\textrm{s}\) and has an amplitude of \(A = 1\text{.}\) The second step function occurs at \(t = 0~\textrm{s}\text{.}\) It must have an amplitude of \(A = 2\) in order to bring the total amplitude from 1 to 3. The third step function occurs at \(t = 2~\textrm{s}\text{.}\) Because the signal goes from a value of 3 to −2, the step function must have an amplitude of \(A = -5\text{.}\) The last step function occurs at \(t = 5~\textrm{s}\) and has an amplitude of \(A = 2\) to bring the signal value back to zero.
    🔗
    The equation defining this function is given in (1.6.6).
    🔗
    \begin{equation} f(t) = u(t+2) + 2u(t) - 5u(t-2) + 2u(t-5)\tag{1.6.6} \end{equation}
    🔗
    🔗
    When differentiating functions including the step function, it is important to determine if the function is continuous. (Function continuity is reviewed in Subsection 5.6.1.) As long as the function is continuous, there is no trick to differentiating a function modified by the unit step function. Note that the solution to the derivative will likely itself be a piecewise function that must be modified by the unit step function.
    🔗
    (Discontinuous piecewise functions will not be differentiated in this textbook. However, as described in (1.6.4), as the integral of the Dirac delta function leads to the step function, the derivative of a step function discontinuity will include a Dirac delta function term.)
    🔗

    Example 1.6.7 Differentiating a function modified by the unit step function.

    Consider the voltage measured over a circuit element known as a capacitor that’s defined by (1.6.7).
    🔗
    \begin{equation} v(t) = 3~\textrm{V}~\textrm{e}^{-10t}~u(t) + 3~\textrm{V}~u(-t)\tag{1.6.7} \end{equation}
    🔗
    This function is graphed in Figure 1.6.8.
    🔗
    The current through this circuit element, having a value of \(C = 0.03~\textrm{F}\text{,}\) is defined by the equation \(i(t) = C dv(t)/dt\) (this will be introduced and explained in detail in Section 5.3).
    🔗
    Plugging (1.6.7) into the equation for current, we see that
    🔗
    \begin{equation*} i(t) = (0.03~\textrm{F}) \frac{d}{dt} \left[3~\textrm{V}~\textrm{e}^{-10t}~u(t) + 3~\textrm{V}~u(-t)\right]\text{.} \end{equation*}
    🔗
    The term in the voltage equation containing \(u(t)\) describes the function when \(t \geq 0\text{,}\) and the derivative of this part of the function will also only be valid when \(t \geq 0\text{.}\)
    🔗
    Similarly, the term containing \(u(-t)\) describes the function when \(t \lt 0\text{,}\) and the derivative of this part of the function will also only be valid when \(t \lt 0\text{.}\)
    🔗
    This means we can effectively pull the step functions out of the derivative, as they will define the piecewise nature of the solution. The function becomes
    🔗
    \begin{equation*} i(t) = (0.03~\textrm{F}) \frac{d}{dt} \left[3~\textrm{V}~\textrm{e}^{-10t}\right]~u(t) + (0.03~\textrm{F}) \frac{d}{dt} \left[3~\textrm{V}\right]~u(-t)\text{.} \end{equation*}
    🔗
    Now we can complete the differentiation and solve for \(i(t)\text{.}\)
    🔗
    \begin{align*} i(t) \amp= (0.03~\textrm{F}) \frac{d}{dt} \left[3~\textrm{V}~\textrm{e}^{-10t}\right]~u(t) + (0.03~\textrm{F}) \frac{d}{dt} \left[3~\textrm{V}\right]~u(-t)\\ \amp= (0.03~\textrm{F}) (-30~\textrm{V/s})~\textrm{e}^{-10t}~u(t) + (0.03~\textrm{F}) (0)~u(-t)\\ \amp= -0.9~\textrm{A}~\textrm{e}^{-10t}~u(t) \end{align*}
    🔗
    🔗
    When integrating functions including the step function, the step function may modify the limits of integration of any definite integrals. For example, a definite integral with limits of integration between negative infinity and infinity of a function containing the term \(u(t)\) will have its limits of integration changed to zero through infinity, as the function is equal to zero prior to \(t = 0\text{.}\)
    🔗
    Additionally, the solution to the integral may also itself be a piecewise function that must be modified by the unit step function.
    🔗

    Example 1.6.9 Integrating a function modified by the unit step function.

    Consider the voltage measured over a circuit element known as an inductor that’s defined by (1.6.8).
    🔗
    \begin{equation} v(t) = 120~\textrm{V}~\textrm{e}^{-400t}~u(t)\tag{1.6.8} \end{equation}
    🔗
    This function is graphed in Figure 1.6.10.
    🔗
    The current through this circuit element, having a value of \(L = 5~\textrm{H}\text{,}\) is defined by the equation \(i(t) = \frac{1}{L} \int_{-\infty}^{t} v(\tau)\,d\tau\) (this will be introduced and explained in detail in Section 6.3).
    🔗
    Plugging (1.6.8) into the equation for current, we see that
    🔗
    \begin{equation*} i(t) = \frac{1}{5~\textrm{H}} \int_{-\infty}^{t} \left[120~\textrm{V}~\textrm{e}^{-400\tau}~u(\tau)\right]\,d\tau\text{.} \end{equation*}
    🔗
    The function has a value of 0 for all values of time less than 0. Therefore, the lower limit of integration can be changed from \(-\infty\) to zero. In addition, the solution will be a piecewise function that is only valid for time values greater than zero. Therefore, the unit step function can be pulled out of the integral. The function becomes
    🔗
    \begin{equation*} i(t) = \frac{1}{5~\textrm{H}} \int_{0}^{t} \left[120~\textrm{V}~\textrm{e}^{-400\tau}\right]\,d\tau~u(t)\text{.} \end{equation*}
    🔗
    Now we can complete the integration and solve for \(i(t)\text{.}\)
    🔗
    \begin{align*} i(t) \amp= \frac{1}{5~\textrm{H}} \int_{0}^{t} \left[120~\textrm{V}~\textrm{e}^{-400\tau}\right]\,d\tau~u(t)\\ \amp= \frac{120~\textrm{V}}{5~\textrm{H}} \int_{0}^{t} \left[\textrm{e}^{-400\tau}\right]\,d\tau~u(t)\\ \amp= \left(24~\textrm{A/s}\right)\left(\frac{1}{400}~\textrm{s}\right) \left|\textrm{e}^{-400\tau}\right|_{0}^{t}~u(t)\\ \amp= -0.06~\textrm{A} \left[\textrm{e}^{-400t} - \textrm{e}^{0}\right]~u(t)\\ \amp= -0.06~\textrm{A} \left[\textrm{e}^{-400t} - 1\right]~u(t)\\ \amp= 0.06~\textrm{A} \left[1 - \textrm{e}^{-400t}\right]~u(t) \end{align*}
    🔗
    🔗
    🔗

    Subsection 1.6.3 Ramp Function

    The ramp function is a signal whose value is zero when the argument is negative, and then has a constant linear upward slope when the argument is positive. The ramp function comes from integrating the step function, as expressed in (1.6.9).
    🔗
    \begin{equation} r(t) = \int_{-\infty}^{t} u(\tau) \, d\tau\tag{1.6.9} \end{equation}
    🔗
    The equation used to express the ramp function is given in (1.6.10), where \(A\) represents the slope of the ramp and \(\tau\) describes the time that the ramp function initiates.
    🔗
    \begin{equation} r(t) = A(t-\tau)u(t-\tau)\tag{1.6.10} \end{equation}
    🔗
    The graphical depiction of a ramp function is shown in Figure 1.6.11.
    🔗

    Example 1.6.12 Calculating current from ramp function charge.

    The charge entering a circuit element is shown in Figure 1.6.13. Use it to calculate the current.
    🔗
    Current is equal to the time derivative of charge. The time derivative is plotted in Figure 1.6.14.
    🔗
    The equation defining the current is given in (1.6.11).
    🔗
    \begin{equation} i(t) = 0.5~\textrm{mA}~u(t) - 1.5~\textrm{mA}~u(t-2) + 1.\overline{3}~\textrm{mA}~u(t-4) - 0.\overline{3}~\textrm{mA}~u(t-7)\tag{1.6.11} \end{equation}
    🔗
    🔗
    🔗

    Subsection 1.6.4 Rectangular Pulse

    A rectangular pulse describes a signal that is initially zero, takes on a particular value for a finite interval of time, and then returns instantaneously to zero. It is different from the step function in that the step function never returns to zero again. A rectangular pulse is especially relevant in electrical engineering as it can be used to describe periodic square waves that are commonly used as clock sources in computer processors. The mathematical equation for a rectangular pulse is given in (1.6.12), where \(A\) defines the amplitude of the pulse, \(\tau\) defines the width of the pulse, and \(\lambda\) defines the center of the pulse.
    🔗
    \begin{equation} f(t) = A \textrm{rect} \left(\frac{t-\lambda}{\tau}\right)\tag{1.6.12} \end{equation}
    🔗
    A rectangular pulse is depicted graphically in Figure 1.6.15.
    🔗

    Example 1.6.16 Plotting a signal composed of rectangular pulses.

    Plot \(f(t) = -3\textrm{rect}((t+5)/2) + 2\textrm{rect}((t-5)/4)\text{.}\) The first term has an amplitude of \(A = -3\text{,}\) a width of \(\tau = 2~\textrm{s}\text{,}\) and is centered at \(\lambda = -5~\textrm{s}\text{.}\) The second term has an amplitude of \(A = 2\text{,}\) a width of \(\tau = 4~\textrm{s}\text{,}\) and is centered at \(\lambda = 5~\textrm{s}.\)
    🔗
    The graph is shown in Figure 1.6.17.
    🔗
    🔗
    🔗

    Subsection 1.6.5 Triangular Pulse

    The triangular pulse is defined as a function that is zero, linearly ramps up to a particular value, and then linearly ramps down to zero again. As the rectangular pulse is to the step function; the triangular pulse is to the ramp function. The equation for a triangular pulse is given in (1.6.13), where \(A\) describes the amplitude of the pulse, \(\tau\) is the half-width of the pulse, and \(\lambda\) is the center of the pulse. Note that the definitions for the width of a rectangular and triangular pulse are different!
    🔗
    \begin{equation} f(t) = A \textrm{tri} \left(\frac{t-\lambda}{\tau}\right)\tag{1.6.13} \end{equation}
    🔗
    A triangular pulse is shown graphically in Figure 1.6.18.
    🔗

    Example 1.6.19 Deriving the equation of a rectangular and triangular waveform.

    Derive the equation corresponding to \(f(t)\text{,}\) as graphed in Figure 1.6.20.
    🔗
    The function is composed of a rectangular pulse and a triangular pulse. The rectangular pulse has an amplitude of \(A = 2\text{,}\) is centered at \(\lambda = 0~\textrm{s}\text{,}\) and has a width of \(\tau = 6~\textrm{s}\text{.}\) The triangular pulse has an amplitude of \(A = 3\text{,}\) is centered at \(\lambda = 0~\textrm{s}\text{,}\) and has a half-width of \(\tau = 3~\textrm{s}\text{.}\) The equation representing this function is expressed in (1.6.14).
    🔗
    \begin{equation} f(t) = 2\textrm{rect}(t/6) + 3\textrm{tri}(t/3)\tag{1.6.14} \end{equation}
    🔗
    🔗
    🔗

    Subsection 1.6.6 Exponential Decay

    The exponential function is ubiquitous in engineering. Specifically, a decaying exponential is found as the solution to many engineering problems. (A rising exponential function is not stable as it would eventually require an infinite amount of energy to sustain.) An exponential is defined in (1.6.15), where \(A\) describes the initial amplitude of the exponential function, \(\tau\) is the time at which the exponential begins its decay, and \(\alpha\) describes how quickly the exponential decays to zero.
    🔗
    \begin{equation} f(t) = A\mathrm{e}^{-\alpha(t-\tau)}u(t-\tau)\tag{1.6.15} \end{equation}
    🔗
    A decaying exponential function is depicted graphically in Figure 1.6.21.
    🔗
    🔗

    Subsection 1.6.7 Damped Sinusoid

    A damped sinusoid describes the behavior of almost all harmonic motion (such as a mass on a spring, a door swinging open and closed on a hinge, or a second-order circuit). A damped sinusoid is defined as a sinusoidal signal multiplied by a decaying exponential, as described in (1.6.16).
    🔗
    \begin{equation} f(t) = A\mathrm{e}^{-\alpha(t-\tau)}\sin(\omega (t-\tau))u(t-\tau)\tag{1.6.16} \end{equation}
    🔗
    In (1.6.16), all of the terms are the same as those given for the exponential decay. \(\omega\) defines the angular frequency of the sinusoidal wave. A damped sinusoid is shown graphically in Figure 1.6.22.
    🔗
