    Section 11.1 The Laplace Transform

    The Laplace transform converts a time-domain function (a function that is represented by the variable \(t\)) into the \(s\)-domain. The variable \(s\) is a complex variable defined by (11.1.1). As discussed in Subsection 9.2.2 of this book (although we did not formally use the variable \(s\) yet at that point), \(s\) relates to the location of a pole or zero on the complex axis. The real part (\(\sigma\)) relates to decaying exponential terms and the imaginary part (\(\omega\)) relates to oscillatory (sinusoidal) terms. Phasor analysis performed a similar transformation where \(\sigma = 0\) (the circuits were purely sinusoidal).
    🔗
    \begin{equation} s = \sigma + j\omega\tag{11.1.1} \end{equation}
    🔗
    The Laplace transform is used to simplify the analysis of circuits containing energy-storage elements such as capacitors and inductors. As was the case in phasor analysis, using the Laplace transform converts calculus to algebra.
    🔗
    The Laplace transform is defined in (11.1.2).
    🔗
    \begin{equation} \Laplace\{f(t)\} = \int_{0^-}^\infty f(t)\textrm{e}^{-st}\,dt\tag{11.1.2} \end{equation}
    🔗
    This textbook will not rigorously derive Laplace transforms for various elementary functions. Instead, Laplace transforms used for several frequently-used time-varying functions are given in Table 11.1.1. These transforms will be directly applied to functions in the time domain to convert them to the \(s\)-domain without requiring the direct use of (11.1.2) (which frequently necessitates the use of integration by parts). The reader is encouraged to derive the equations themselves if they would like to convince themselves of their veracity.
    🔗

    Example 11.1.2 Laplace transform.

    Derive the Laplace transform of
    🔗
    \begin{equation*} f(t) = \textrm{e}^{-10t}~u(t)\text{.} \end{equation*}
    🔗
    The Laplace transform is
    🔗
    \begin{equation*} F(s) = \frac{1}{s+10}\text{.} \end{equation*}
    🔗
    🔗
    The Laplace transform has many properties that can also be used to transform more complicated functions into the \(s\)-domain. These properties include multiplication, addition, and differentiation, and are included in Table 11.1.3. (While Laplace transforms are especially important in many applications (such as signal processing), their focus will be limited to analysis of linear circuits in this textbook. As a result, some Laplace transform properties (convolution, for example) will not be covered in this textbook.)
    🔗
    Using Table 11.1.1 and Table 11.1.3, Laplace transforms of every time-domain function derived in this book can be computed.
    🔗
    For the most part, the circuit analysis in this book will not use the Laplace transform directly. Instead, circuits will be analyzed in the \(s\)-domain, and then the inverse Laplace transform (introduced in Section 11.2) will be used to derive a time-domain function. The two examples below therefore demonstrate the reverse process to what we will mostly utilize in this book.
    🔗

    Example 11.1.4 Laplace transform.

    Derive the Laplace transform of the voltage dropped over a circuit element. The time-domain response has been derived as
    🔗
    \begin{equation*} v(t) = \left[40~\textrm{V} + \textrm{e}^{-10t}\left(2~\textrm{V}~\cos(20t) + 1~\textrm{V}~\sin(20t)\right)\right]~u(t)\text{.} \end{equation*}
    🔗
    Use the addition and subtraction property to analyze each individual term. (Note that units are being dropped from this point forward.)
    🔗
    \begin{equation*} V(s) = \Laplace\{40~u(t)\} + \Laplace\{2\textrm{e}^{-10t}~\cos(20t)~u(t)\} + \Laplace\{\textrm{e}^{-10t}~\sin(20t)~u(t)\} \end{equation*}
    🔗
    Use the multiplication property to factor out coefficients.
    🔗
    \begin{equation*} V(s) = 40\Laplace\{u(t)\} + 2\Laplace\{\textrm{e}^{-10t}~\cos(20t)~u(t)\} + \Laplace\{\textrm{e}^{-10t}~\sin(20t)~u(t)\} \end{equation*}
    🔗
    Use Table 11.1.1 to calculate the Laplace transform.
    🔗
    \begin{equation*} V(s) = 40\frac{1}{s} + 2\frac{(s+10)}{(s+10)^2+20^2} + \frac{20}{(s+10)^2+20^2} \end{equation*}
    🔗
    Find a common denominator for all terms and multiply through.
    🔗
    \begin{equation*} V(s) = \frac{40\left[(s+10)^2+400\right] + 2(s+10)s + 20s}{s\left[(s+10)^2+400\right]} \end{equation*}
    🔗
    Simplify so there is a simple polynomial in both the numerator and the denominator. Factor the denominator so that the order of the polynomial is two.
    🔗
    \begin{equation*} V(s) = \frac{42s^2 + 840s + 20000}{s(s^2 + 20s + 500)} \end{equation*}
    🔗
    🔗

    Example 11.1.5 Laplace transform of a differential equation.

    Derive the Laplace transform of the current described by the differential equation in Example 7.5.22. The differential equation is
    🔗
    \begin{equation*} 0 = \frac{d^2i(t)}{dt^2} + 250\frac{di(t)}{dt} + 10500i(t)\text{.} \end{equation*}
    🔗
    The initial current \(i(0) = 0.1~\textrm{A}\) and the first derivative of the current is zero.
    🔗
    Use the addition and subtraction property to analyze each individual term.
    🔗
    \begin{equation*} 0 = \Laplace\{ \frac{d^2i(t)}{dt^2}\} + \Laplace\{250\frac{di(t)}{dt}\} + \Laplace\{10500i(t)\} \end{equation*}
    🔗
    Use the multiplication property to factor out coefficients.
    🔗
    \begin{equation*} 0 = \Laplace\{ \frac{d^2i(t)}{dt^2}\} + 250\Laplace\{\frac{di(t)}{dt}\} + 10500\Laplace\{i(t)\} \end{equation*}
    🔗
    Use the derivative and second derivative properties to find an equation in terms of \(I(s)\text{.}\)
    🔗
    \begin{equation*} 0 = s^2I(s) - si(0) - i'(0) + 250\left[sI(s) -i(0)\right] + 10500I(s) \end{equation*}
    🔗
    Plug in the initial conditions and simplify to calculate \(I(s)\text{.}\)
    🔗
    \begin{align*} 0 \amp= s^2I(s) - 0.1s + 250\left[sI(s) -0.1\right] + 10500I(s)\\ 0.1s + 25 \amp= s^2I(s) + 250sI(s) + 10500I(s)\\ I(s) \amp= \frac{0.1s + 25}{s^2 + 250s + 10500} \end{align*}
    🔗
