    Answer.
    12.7 V
    🔗
    🔗
    Solution.
    Draw the circuit with only the voltage source activated. Deactivate the current source by replacing it with an open.
    🔗
    Use the voltage divider rule to calculate \(V_{X1}\text{.}\)
    🔗
    \begin{align*} V_{X1} \amp= 13~\textrm{V}\left(\frac{560~\Omega}{390~\Omega+560~\Omega}\right)\\ \amp= 7.66~\textrm{V} \end{align*}
    🔗
    Draw the circuit with only the current source activated. Deactivate the voltage source by replacing it with a short.

    🔗
    \begin{align*} V_{X2} \amp= (560~\Omega//390~\Omega)(0.022~\textrm{A})\\ \amp= (229.89~\Omega)(0.022~\textrm{mA})\\ \amp= 5.06~\textrm{V} \end{align*}

    2.

    Use superposition to calculate \(V_X\) in the circuit shown in Figure 3.8.4.
    🔗
    Answer.
    −3.64 V
    🔗
    🔗
    Solution.
    Draw the circuit with only the voltage source activated. Deactivate the current source by replacing it with an open.
    🔗
    Combine all resistors except for the one that drops \(V_X\) in series and re-draw (this step can be skipped if you note that all resistors are in series and the voltage divider rule can be applied without combining any resistors).
    🔗
    Use the voltage divider rule to calculate \(V_{X1}\text{.}\) Note that the sign is negative because the voltage drop \(V_{X1}\) opposes the direction of the voltage source.
    🔗
    \begin{align*} V_{X1} \amp= -20~\textrm{V}\left(\frac{700~\Omega}{1300~\Omega+700~\Omega}\right)\\ \amp= -7~\textrm{V} \end{align*}
    🔗
    Draw the circuit with only the current source activated. Deactivate the voltage source by replacing it with a short.
    🔗
    Combine resistors in series except for the one that drops \(V_X\) and re-draw. (This means the 100 Ω, 200 Ω, and 600 Ω resistors will be combined into a single equivalent resistance of 900 Ω.)
    🔗
    Use the current divider rule to calculate the current through the branch containing the 700 Ω resistor and 900 Ω resistor.
    🔗
    \begin{align*} I \amp= 24~\textrm{mA}\left(\frac{400~\Omega//(700~\Omega+900~\Omega)}{700~\Omega+900~\Omega}\right)\\ \amp= 24~\textrm{mA}\left(\frac{400~\Omega//1600~\Omega}{1600~\Omega}\right)\\ \amp= 24~\textrm{mA}\left(\frac{320~\Omega}{1600~\Omega}\right)\\ \amp= 4.8~\textrm{mA} \end{align*}

    🔗

    🔗
    Add the two values to calculate the voltage \(V_X\text{.}\)
    🔗
    \begin{align*} V_X \amp= V_{X1} + V_{X2}\\ \amp= -7~\textrm{V} + 3.36~\textrm{V}\\ \amp= -3.64~\textrm{V} \end{align*}

    5.

    Use superposition to calculate \(V_X\) in the circuit shown in Figure 3.8.26.
    🔗
    Answer.
    4.1 V
    🔗
    🔗
    Solution.
    Draw the circuit with only the current source activated. Deactivate the voltage source by replacing it with a short. The dependent source cannot be removed from the circuit.
    🔗
    Because resistors adjacent to each source contain either a voltage drop or current of interest, source transformation is not a useful tool to solve this circuit. Instead, mesh analysis will be used. The circuit is re-drawn with each mesh current defined. (Note that some component values have been hidden so that the mesh labels can be read.)
    🔗
    All subsequent units are in V, A, and Ω and will be omitted from the mesh equations to make them easier to read. The two central meshes have equations derived below.
    🔗
    \begin{align*} (I_A - 12) + I_A + (I_A - I_B) \amp= 0\\ (I_B - I_A) + I_B + (I_B - (-0.4I_{X1})) \amp= 0 \end{align*}
    🔗
    An equation must be derived to relate the controlling current to the mesh currents.
    🔗
    \begin{equation*} I_{X1} = 12-I_A \end{equation*}
    🔗
    The three equations can be expressed in a matrix. The left column contains coefficients of \(I_A\text{,}\) the middle-left column contains coefficients of \(I_B\text{,}\) the middle-right column contains coefficients of \(I_{X1}\text{,}\) and the right column contains constants.
    🔗
    \begin{equation*} \begin{bmatrix} 3 \amp -1 \amp 0 \amp 12 \\ -1 \amp 3 \amp 0.4 \amp 0 \\ 1 \amp 0 \amp 1 \amp 12 \end{bmatrix} \end{equation*}
    🔗
    The matrix is shown in reduced row echelon form below.
    🔗
    \begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp 4.105\\ 0 \amp 1 \amp 0 \amp 0.315\\ 0 \amp 0 \amp 1 \amp 7.895 \end{bmatrix} \end{equation*}
    🔗
    \(V_{X1}\) is a function of mesh current \(I_B\text{.}\) Read the middle row to determine that \(I_B = 0.315~\textrm{mA}\text{.}\) Use Ohm’s law to calculate \(V_{X1}\text{.}\)
    🔗
    \begin{align*} V_{X1} \amp= (0.315~\textrm{mA})(1~\textrm{k}\Omega)\\ \amp= 0.315~\textrm{V} \end{align*}
    🔗
    Draw the circuit with only the voltage source activated. Deactivate the current source by replacing it with an open. The dependent source cannot be removed from the circuit.
    🔗
    For the same reason as above, mesh analysis will be used to calculate \(V_{X2}\text{.}\) The circuit is re-drawn below to define the mesh currents. (Note that some component values have been hidden so that the mesh labels can be read.)
    🔗
    The KVL equations for each mesh are derived below.
    🔗
    \begin{align*} I_A + I_A + (I_A - I_B) + 18 \amp= 0\\ -18 + (I_B - I_A) + I_B + (I_B - (-0.4I_{X2})) \amp= 0 \end{align*}
    🔗
    Derive a dependent source equation.
    🔗
    \begin{equation*} I_{X2} = -I_A \end{equation*}
    🔗
    The three equations can be expressed in a matrix. The left column contains coefficients of \(I_A\text{,}\) the middle-left column contains coefficients of \(I_B\text{,}\) the middle-right column contains coefficients of \(I_{X1}\text{,}\) and the right column contains constants.
    🔗
    \begin{equation*} \begin{bmatrix} 3 \amp -1 \amp 0 \amp -18 \\ -1 \amp 3 \amp 0.4 \amp 18 \\ 1 \amp 0 \amp 1 \amp 0 \end{bmatrix} \end{equation*}
    🔗
    The matrix is shown in reduced row echelon form below.
    🔗
    \begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp -4.737\\ 0 \amp 1 \amp 0 \amp 3.789\\ 0 \amp 0 \amp 1 \amp 4.737 \end{bmatrix} \end{equation*}
    🔗
    \(V_{X2}\) is a function of mesh current \(I_B\text{.}\) Read the middle row to determine that \(I_B = 3.789~\textrm{mA}\text{.}\) Use Ohm’s law to calculate \(V_{X1}\text{.}\)
    🔗
    \begin{align*} V_{X2} \amp= (3.789~\textrm{mA})(1~\textrm{k}\Omega)\\ \amp= 3.789~\textrm{V} \end{align*}
    🔗
    Add the two values to calculate the voltage \(V_X\text{.}\)
    🔗
    \begin{align*} V_X \amp= V_{X1} + V_{X2}\\ \amp= 0.315~\textrm{V} + 3.789~\textrm{V}\\ \amp= 4.1~\textrm{V} \end{align*}

    13.

    Derive the Thévenin equivalent circuit between nodes a and b in the circuit shown in Figure 3.8.66.
    🔗
    Answer.
    🔗
    Solution.
    First, calculate the open-circuit voltage between nodes a and b. This solution method treats the left and right circuits as independent circuits. The left circuit will be used to calculate \(V_a\text{,}\) the right circuit will be used to calculate \(V_b\text{,}\) and the relationship \(V_{ab} = V_a - V_b\) will be used to calculate the Thévenin equivalent voltage. (Why not use mesh analysis? Solving for the mesh currents is not terribly useful in this case as the voltage divider rule will need to be used on the left side of the circuit regardless, and the current through the right side of the circuit can be calculated relatively easily without having to use mesh analysis.)
    🔗
    The circuit is drawn below with the quantities \(V_a\) and \(V_b\) explicitly labeled.
    🔗
    Use the voltage divider rule to calculate \(V_a\text{.}\)
    🔗
    \begin{align*} V_a \amp= 6~\textrm{V}\left(\frac{5~\textrm{k}\Omega}{3~\textrm{k}\Omega+5~\textrm{k}\Omega}\right)\\ \amp= 3.75~\textrm{V} \end{align*}
    🔗
    The current \(I_X\) needs to be known to solve the right side of the circuit. Use Ohm’s law to calculate this value.
    🔗
    \begin{align*} I_X \amp= \frac{6~\textrm{V}}{3~\textrm{k}\Omega+5~\textrm{k}\Omega}\\ \amp= 0.75~\textrm{mA} \end{align*}
    🔗
    Now analyze the right side of the circuit. Use Ohm’s law to calculate \(V_b\text{.}\) Note that the sign is negative as the current flows from low to high potential as far as \(V_b\) is defined.
    🔗
    \begin{align*} V_b \amp= -4I_X(1~\textrm{k}\Omega)\\ \amp= -(4)(0.75~\textrm{mA})(1~\textrm{k}\Omega)\\ \amp= -3~\textrm{V} \end{align*}
    🔗
    The Thévenin equivalent voltage can now be calculated.
    🔗
    \begin{align*} V_{TH} \amp= V_{ab} = V_a - V_b\\ \amp= 3.75~\textrm{V} - (-3~\textrm{V})\\ \amp= 3.75~\textrm{V} + 3~\textrm{V}\\ \amp= 6.75~\textrm{V} \end{align*}
    🔗
    Because this circuit contains a dependent source, the short-circuit current needs to be calculated to calculate the Thévenin equivalent resistance. This circuit contains only one independent source, which means that superposition cannot be used. There are no reductions in the circuit that can be done without eliminating important quantities we need to know. (We cannot combine the two resistors in parallel without eliminating the branch through which we need to measure \(I_{SC}\text{.}\)) Mesh analysis is therefore the easiest method to use to solve for \(I_{SC}\text{.}\) The circuit is drawn below. (Note: some of the component labels have been hidden so that the mesh current labels can be read.)
    🔗
    All mesh equations will be expressed with units of V, mA, and kΩ and will be omitted from each equation to make them easier to read. First, use KVL around the left mesh.
    🔗
    \begin{equation*} -6 + 3I_A + 5(I_A - I_B) = 0 \end{equation*}
    🔗
    Next, use KVL around the center mesh.
    🔗
    \begin{equation*} 5(I_B - I_A) + 1(I_B - I_C) = 0 \end{equation*}
    🔗
    The right mesh contains a current source that is not shared with any other mesh. Mesh current \(I_C\) has the same direction as the source current. Therefore, \(I_C = 4I_X\text{.}\)
    🔗
    Finally, use the left mesh to relate the controlling current \(I_X\) with branch current \(I_A\text{.}\) These two values are equal in both magnitude and direction: \(I_X = I_A\text{.}\)
    🔗
    The four equations can be expressed in a matrix. The left column contains coefficients of \(I_A\text{,}\) the next column contains coefficients of \(I_B\text{,}\) the next column contains coefficients of \(I_C\text{,}\) the next column contains coefficients of \(I_X\text{,}\) and the right column contains constants.
    🔗
    \begin{equation*} \begin{bmatrix} 8 \amp -5 \amp 0 \amp 0 \amp 6\\ -5 \amp 6 \amp -1 \amp 0 \amp 0\\ 0 \amp 0 \amp 1 \amp -4 \amp 0\\ 1 \amp 0 \amp 0 \amp -1 \amp 0 \end{bmatrix} \end{equation*}
    🔗
    The matrix is shown in reduced row echelon form below.
    🔗
    \begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0 \amp 12\\ 0 \amp 1 \amp 0 \amp 0 \amp 18\\ 0 \amp 0 \amp 1 \amp 0 \amp 48\\ 0 \amp 0 \amp 0 \amp 1 \amp 12 \end{bmatrix} \end{equation*}
    🔗
    Because the branch current \(I_{SC}\) is contained within a single mesh, the short-circuit current is equal to that mesh current. In other words, \(I_{SC} = I_B\text{.}\) Therefore, \(I_{SC}\) is equal to 18 mA.
    🔗
    Use Ohm’s law to calculate the Thévenin equivalent resistance.
    🔗
    \begin{align*} R_{TH} \amp= \frac{V_{TH}}{I_{SC}}\\ \amp= \frac{6.75~\textrm{V}}{18~\textrm{mA}}\\ \amp= 0.375~\textrm{k}\Omega\\ \amp= 375~\Omega \end{align*}
