    Section 7.7 Non-Constant Input Non-Homogeneous Second-Order Circuits

    In general, the solution to the differential equation for a second-order circuit is \(v(t) = v_G(t) + v_P(t)\text{,}\) where \(v_G(t)\) is the general solution, which was introduced in Section 7.5. \(v_P(t)\) is the particular solution. It was introduced in Section 7.6 in the context of constant-input non-homogeneous circuits.
    🔗
    It is possible for a second-order circuit to be connected to a variable input source (rather than a constant-input source) in the final circuit configuration. In this case, the particular solution will no longer be equal to the final steady-state value of the voltage or current. The particular solution for commonly used sources is given in Table 7.7.1.
    🔗
    The procedure for solving these types of circuits follows.
    🔗
    1. Derive the differential equation corresponding to the circuit.
      🔗
      🔗
    2. Calculate the damping parameter, resonant frequency, and roots of the general solution.
      🔗
      🔗
    3. Calculate the initial conditions of the circuit (including the first derivative of the initial condition).
      🔗
      🔗
    4. Refer to Table 7.7.1 to find the format for the particular solution. Plug \(v_P(t)\) or \(i_P(t)\) into the differential equation to calculate the coefficients (\(K_1\text{,}\) \(K_2\text{,}\) etc.) of the particular solution.
      🔗
      🔗
    5. Calculate the general solution coefficients (\(A_1\) and \(A_2\) or \(B_1\) and \(B_2\)) using the following two equations:
      🔗
      • \(\displaystyle v(0) = v_P(0) + v_G(0)\)
        🔗
        🔗
      • \(\displaystyle v'(0) = v'_P(0) + v'_G(0)\)
        🔗
        🔗
      🔗
    🔗
    This method is cumbersome and not ideal for solving this type of circuit. A better method will be introduced in Chapter 11.
    🔗

    Subsection 7.7.1 Examples

    Example 7.7.2 Polynomial input non-homogeneous second-order circuit (symbolic).

    Calculate \(i(t)\) for the circuit below.
    🔗
    The source does not supply any current until \(t = 0\text{,}\) therefore, the initial conditions will be zero.
    🔗
    Analyze the circuit when \(t \gt 0\) to derive a differential equation for the circuit. (Because the time is greater than zero, the step function term can be eliminated from the source.)
    🔗
    Perform KCL at either node.
    🔗
    \begin{equation*} I_S t = \frac{v(t)}{R} + i(t) + C\frac{dv(t)}{dt} \end{equation*}
    🔗
    Use (6.3.1) to replace \(v(t)\) terms with \(i(t)\) terms. Reduce to standard form.
    🔗
    \begin{align*} I_S t \amp= \frac{1}{R}\left(L\frac{di(t)}{dt}\right) + i(t) + C\frac{d}{dt}\left(L\frac{di(t)}{dt}\right)\\ \amp= \frac{L}{R}\frac{di(t)}{dt} + i(t) + LC\frac{d^2i(t)}{dt^2}\\ \frac{I_S t}{LC} \amp= \frac{d^2i(t)}{dt^2} + \frac{1}{RC}\frac{di(t)}{dt} + \frac{1}{LC}i(t) \end{align*}
    🔗
    Note that this is a parallel RLC circuit, so the equation looks very similar to (7.4.4). In fact, the general solution is identical for all parallel RLC circuits.
    🔗
    The particular form of the solution will need to be derived. Consult Table 7.7.1. The source is a polynomial. We can be reasonably certain that 0 will not be a root of the general solution, as a root of zero implies that the circuit has a constant amplitude output, which is not realizable in a circuit containing any positive resistance. (Refer to Subsection 9.2.2 for more information on this topic.)
    🔗
    \begin{equation*} i_P(t) = K_1t + K_2 \end{equation*}
    🔗
    Plug the particular solution into the second-order equation to calculate the values of the coefficients \(K_1\) and \(K_2\text{.}\)
    🔗
    \begin{equation*} \frac{I_S t}{LC} = \frac{d^2}{dt^2}\left[ K_1t + K_2\right] + \frac{1}{RC}\frac{d}{dt}\left[ K_1t + K_2\right] + \frac{1}{LC}\left[ K_1t + K_2\right] \end{equation*}
    🔗
    Perform all of the derivatives.
    🔗
    \begin{equation*} \frac{I_S t}{LC} = \frac{1}{RC}\left[ K_1\right] + \frac{1}{LC}\left[ K_1t + K_2\right] \end{equation*}
    🔗
    Each side of the equation can be expressed as \(a_1 t + a_0\text{.}\) The coefficients on each side must be equal. This is how we will derive values for \(K_1\) and \(K_2\text{.}\) First, analyze the terms on each side of the equation multiplied by \(t\) and simplify. (Conveniently, this provides the solution for \(K_1\text{.}\))
    🔗
    \begin{align*} \frac{I_S t}{LC} \amp= \frac{1}{LC}K_1 t\\ K_1 \amp= I_S \end{align*}
    🔗
    Next, analyze the terms on each side of the equation that are not multiplied by \(t\) and simplify.
    🔗
    \begin{align*} 0 \amp= \frac{1}{RC}K_1 + \frac{1}{LC}K_2\\ \frac{1}{L}K_2 \amp= -\frac{1}{R}K_1\\ K_2 \amp= -\frac{L}{R}K_1\\ \amp= -\frac{L}{R}I_S \end{align*}
    🔗
    The particular solution is now known.
    🔗
    \begin{equation*} i_P(t) = I_S t -\frac{L}{R}I_S \end{equation*}
    🔗
    At this point, it is not possible to go any farther in the calculations due to the symbolic form of the solution. The circuit could be overdamped, underdamped, or critically damped. The general solution of the equation cannot be solved without specific component values. However, as noted, because this is a parallel RLC circuit, (7.4.5) will be used to calculate the damping parameter, and (7.4.6) will be used to calculate the resonant frequency. The initial first derivative will be calculated using (7.4.8).
    🔗
    🔗

    Example 7.7.5 Sinusoidal input non-homogeneous second-order circuit (numeric).

    Calculate \(i(t)\) for the circuit below. The switch is open for a very long time before closing at a time of zero seconds. The circuit parameters are \(v_S(t) = 5~\textrm{V}~\sin{(2\pi100t)}\text{,}\) \(R_S = 50~\Omega\text{,}\) \(R = 100~\Omega\text{,}\) \(C = 1~\mu\textrm{F}\text{,}\) and \(L = 100~\textrm{mH}\text{.}\)
    🔗
    The initial current will be zero, due to the lack of connection to the source. This current will be continuous with time because it’s in series with the inductor.
    🔗
    The voltage \(v(t)\) may not be continuous with time. At \(t=0^+\text{,}\) the voltage over the capacitor will be zero, the current through the inductor will be zero, and \(v_S(0)\) will be zero (this is because \(\sin(0)=0\)). This means that \(v(0^+)=0\text{,}\) as there are no sources connected to \(R\) at that time.
    🔗
    Analyze the circuit at \(t=0^+\) to derive the differential equation.
    🔗
    Perform KCL at the node connecting \(R_S\text{,}\) \(R\text{,}\) and \(C\) and simplify.
    🔗
    \begin{align} \frac{v_S(t) - v(t)}{R_S} \amp= \frac{v(t)}{R} + i(t)\tag{7.7.1}\\ \frac{v_S(t)}{R_S} \amp= \frac{v(t)}{R_S} + \frac{v(t)}{R} + i(t)\tag{7.7.2}\\ \amp= \left(\frac{1}{R_S}+\frac{1}{R}\right)v(t) + i(t)\tag{7.7.3} \end{align}
    🔗
    Perform KVL around the right-hand loop of the circuit.
    🔗
    \begin{equation} v(t) = \frac{1}{C}\int i(t) \,dt + L\frac{di(t)}{dt}\tag{7.7.4} \end{equation}
    🔗
    Plug (7.7.4) into (7.7.3) to eliminate all \(v(t)\) terms.
    🔗
    \begin{align*} \frac{v_S(t)}{R_S} \amp= \left(\frac{1}{R_S}+\frac{1}{R}\right)\left(\frac{1}{C}\int i(t) \,dt + L\frac{di(t)}{dt}\right) + i(t)\\ \amp= \left(\frac{1}{CR_S}+\frac{1}{CR}\right)\int i(t) \,dt + \left(\frac{L}{R_S}+\frac{L}{R}\right)\frac{di(t)}{dt} + i(t) \end{align*}
    🔗
    Take the first derivative of both sides of the equation to eliminate the integral. Then, reduce to standard form.
    🔗
    \begin{align*} \frac{1}{R_S}\frac{dv_S(t)}{dt} \amp= \left(\frac{1}{CR_S}+\frac{1}{CR}\right) i(t) + \left(\frac{L}{R_S}+\frac{L}{R}\right) \frac{d^2i(t)}{dt^2} + \frac{di(t)}{dt}\\ \frac{R}{L(R+R_S)}\frac{dv_S(t)}{dt} \amp= \frac{d^2i(t)}{dt^2} + \left(\frac{RR_S}{L(R+R_S)}\right)\frac{di(t)}{dt} + \left(\frac{1}{LC}\right)i(t) \end{align*}
    🔗
    Analyze the left-hand side of the differential equation. Plug in the known function for \(v_S(t)\) and take the derivative as required. The unit is removed from the equation for ease of reading. Base units will be used from this point out.
    🔗
    \begin{align*} \amp= \frac{R}{L(R+R_S)}\frac{d}{dt}\left(5~\sin{(2\pi100t)}\right)\\ \amp= \frac{R}{L(R+R_S)}\left(2\pi 500\cos{(2\pi100t)}\right) \end{align*}
    🔗
    The differential equation is as shown below.
    🔗
    \begin{equation*} \frac{R}{L(R+R_S)}\left(2\pi 500\cos{(2\pi100t)}\right) = \frac{d^2i(t)}{dt^2} + \left(\frac{RR_S}{L(R+R_S)}\right)\frac{di(t)}{dt} + \left(\frac{1}{LC}\right)i(t) \end{equation*}
    🔗
    Plug in component values using base units.
    🔗
    \begin{equation*} 6666.67\pi\cos(2\pi100t) = \frac{d^2i(t)}{dt^2} + 333.33\frac{di(t)}{dt} + \left(1\times10^7\right)i(t) \end{equation*}
    🔗
    Use (7.2.1) to calculate the damping parameter of the circuit and use (7.2.2) to calculate the resonant frequency of the circuit.
    🔗
    \begin{align*} \alpha \amp= \frac{333.33}{2}\\ \amp= 166.67~\textrm{Np/s}\\ \omega_0 \amp= \sqrt{1\times10^7}\\ \amp= 3162.28~\textrm{rad/s} \end{align*}
    🔗
    This circuit is underdamped. Use (7.2.5) to calculate the oscillation frequency of the circuit.
    🔗
    \begin{align*} \beta \amp= \sqrt{3162.28^2 - 166.67^2}\\ \amp= 3157.88~\textrm{rad/s} \end{align*}
    🔗
    It’s now time to derive the particular solution. Because the input is a sine wave, the particular solution will take the form given below.
    🔗
    \begin{equation*} i_P(t) = K_1\cos(2\pi100t) + K_2\sin(2\pi100t) \end{equation*}
    🔗
    Plug the particular solution into the differential equation. This process will allow us to calculate \(K_1\) and \(K_2\text{.}\)
    🔗
    \begin{align*} 6666.67\pi\cos(2\pi100t) \amp= \frac{d^2}{dt^2}\left[ K_1\cos(2\pi100t) + K_2\sin(2\pi100t)\right]\\ \amp + 333.33\frac{d}{dt}\left[ K_1\cos(2\pi100t) + K_2\sin(2\pi100t)\right]\\ \amp + \left(1\times10^7\right)\left[ K_1\cos(2\pi100t) + K_2\sin(2\pi100t)\right] \end{align*}
    🔗
    Differentiate the equation as needed to obtain a function containing entirely sines and cosines without derivatives. Each sine and cosine will be represented as having an argument of \(\omega t\) to keep the equations from getting too unwieldy.
    🔗
    \begin{align*} 6666.67\pi\cos(\omega t) \amp= \frac{d}{dt}\left[-\omega K_1 \sin(\omega t) + \omega K_2 \cos(\omega t)\right]\\ \amp + 333.33\left[-\omega K_1 \sin(\omega t) + \omega K_2 \cos(\omega t)\right]\\ \amp + \left(1\times10^7\right)\left[K_1\cos(\omega t) + K_2\sin(\omega t)\right]\\ 6666.67\pi\cos(\omega t) \amp= \left[-\omega^2 K_1 \cos(\omega t) - \omega^2 K_2 \sin(\omega t)\right]\\ \amp + 333.33\left[-\omega K_1 \sin(\omega t) + \omega K_2 \cos(\omega t)\right]\\ \amp + \left(1\times10^7\right)\left[K_1\cos(\omega t) + K_2\sin(\omega t)\right] \end{align*}
    🔗
    Collect all terms with cosines from both sides of the equation.
    🔗
    \begin{align*} 6666.67\pi\cos(\omega t) \amp= -\omega^2 K_1 \cos(\omega t)\\ \amp + 333.33\omega K_2 \cos(\omega t)\\ \amp + \left(1\times10^7\right)K_1\cos(\omega t) \end{align*}
    🔗
    All cosine terms cancel out. Replace all \(\omega\) values with \(2\pi 100\) to obtain one equation in terms of \(K_1\) and \(K_2\text{.}\)
    🔗
    \begin{equation*} 6666.67\pi = -40000\pi^2K_1 + 66666.67\pi K_2 + \left(1\times10^7\right)K_1 \end{equation*}
    🔗
    Collect all terms with sines from both sides of the equation.
    🔗
    \begin{align*} 0 \amp= - \omega^2 K_2 \sin(\omega t)\\ \amp -333.33\omega K_1 \sin(\omega t)\\ \amp+ \left(1\times10^7\right) K_2\sin(\omega t) \end{align*}
    🔗
    All sine terms cancel out. Replace all \(\omega\) values with \(2\pi 100\) to obtain a second equation in terms of \(K_1\) and \(K_2\text{.}\)
    🔗
    \begin{equation*} 0 = -40000\pi^2K_2 - 66666.67\pi K_1+\left(1\times10^7\right)K_2 \end{equation*}
    🔗
    The two equations can be expressed in a matrix. The left column contains coefficients of \(K_1\text{,}\) the middle column contains coefficients of \(K_2\text{,}\) and the right column contains constants.
    🔗
    \begin{equation*} \begin{bmatrix} 9.6052 \times 10^6 \amp 0.2094\times 10^6 \amp 0.0209\times 10^6\\ -0.2094\times 10^6 \amp 9.6052\times 10^6 \amp 0\\ \end{bmatrix} \end{equation*}
    🔗
    The matrix is shown in reduced row echelon form below.
    🔗
    \begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 2.18\times10^{-3}\\ 0 \amp 1 \amp 4.75\times10^{-5}\\ \end{bmatrix} \end{equation*}
    🔗
    This gives us the following two coefficients for the particular solution.
    🔗
    \begin{align*} K_1 \amp= 2.18\times10^{-3}~\textrm{A}\\ K_2 \amp= 4.75\times10^{-5}~\textrm{A} \end{align*}
    🔗
    The particular solution is now known.
    🔗
    \begin{equation*} i_P(t) = \left(2.18\times10^{-3}\right)\cos(2\pi100t) + \left(4.75\times10^{-5}\right)\sin(2\pi100t) \end{equation*}
    🔗
    Because the equation is underdamped, (7.6.6) can be used to derive an equation for \(i(t)\text{.}\)
    🔗
    \begin{align*} i(t) \amp= \left(2.18\times10^{-3}\right)\cos(2\pi100t) + \left(4.75\times10^{-5}\right)\sin(2\pi100t)\\ \amp+ \textrm{e}^{-166.67 t} \left[B_1\cos(3157.88 t) + B_2\sin(3157.88 t) \right] \end{align*}
    🔗
    The last step is to calculate the values of coefficients \(B_1\) and \(B_2\text{.}\) This is where the initial conditions \(i(0)\) and \(i'(0^+)\) are used. Both of these values are zero. First, use \(i(0)\) to obtain one equation in terms of \(B_1\) and \(B_2\text{.}\)
    🔗
    \begin{equation*} i(0) = 0 = \left(2.18\times10^{-3}\right) + B_1 \end{equation*}
    🔗
    Now, use \(i'(0)\) to obtain a second equation in terms of \(B_1\) and \(B_2\text{.}\) (Taking the derivative of the function will not be explicitly shown below.) We can calculate \(i'(0) = 0\) by analyzing (7.7.4) and noting that both \(v(t)\) and the voltage dropped over the capacitor (represented as the integral of \(i(t)\) in the equation) are equal to zero at \(t=0^+\text{.}\) Therefore, \(i'(0^+)=0\text{.}\)
    🔗
    \begin{equation*} i'(0^+) = 0 = 3157.88B_2 - 166.67B_1 + 0.0298451 \end{equation*}
    🔗
    Using both equations, the two coefficients can be calculated.
    🔗
    \begin{align*} B_1 \amp= -2.18\times10^{-3}~\textrm{A}\\ B_2 \amp= -1.25\times10^{-4}~\textrm{A} \end{align*}
    🔗
    Put everything together to express \(i(t)\text{.}\)
    🔗
    \begin{align*} i(t) \amp= \left[ \left(2.18\times10^{-3}\right)~\textrm{A}~\cos(2\pi100t) + \left(4.75\times10^{-5}\right)~\textrm{A}~\sin(2\pi100t) \right.\\ \amp+ \left.\textrm{e}^{-166.67 t} \left[\left(-2.18\times10^{-3}\right)~\textrm{A}~\cos(3157.88 t) - \left(1.25\times10^{-4}\right)~\textrm{A}~\sin(3157.88 t)\right] \right]~u(t) \end{align*}
