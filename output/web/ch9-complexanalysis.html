    Section 9.1 Complex Circuit Analysis Techniques

    All linear circuits can be analyzed using the following circuit analysis techniques. All of these techniques have been covered earlier in this textbook in the context of DC circuits. Phasors and impedances will be used to implement these tools to solve AC circuits. All sources will be converted into phasor quantities and all passive circuit elements will be converted into impedances.
    🔗
    Because all of these concepts have already been covered, the discussions that follow will not be exhaustive as those that were included in Chapter 2 and Chapter 3.
    🔗

    Subsection 9.1.1 Complex Voltage Divider

    For any number of impedances connected in series with a voltage source, the complex voltage divider rule uses the complex form of Ohm’s law (defined in (8.2.1)) to calculate the voltage dropped over any of the impedances.
    🔗
    Given \(n\) impedances in series with a source voltage of \(\vec{V_S}\text{,}\) the voltage drop over the \(k^\textrm{th}\) impedance (where \(k \lt n\)) is defined in (9.1.1).
    🔗
    \begin{equation} \vec{V_k} = \vec{V_S} \left(\frac{\vec{Z_k}}{\vec{Z_1}+\vec{Z_2}+\vec{Z_3}+...+\vec{Z_k}+...+\vec{Z_n}}\right)\tag{9.1.1} \end{equation}
    🔗

    Example 9.1.1 Complex voltage divider.

    Calculate \(v_{out}(t)\) in the circuit below. The source is equal to \(v_{AC}(t) = 150~\textrm{V}~\cos(2\pi 60 t + 60 \pi/180)\text{.}\)
    🔗
    Use (8.2.4) to calculate the impedance of the capacitor.
    🔗
    \begin{equation*} \frac{1}{j(2\pi60)(25 \times 10^{-6})} = -j106.10~\Omega \end{equation*}
    🔗
    Use (8.2.5) to calculate the impedance of each inductor.
    🔗
    \begin{align*} j(2\pi 60)(0.065) \amp= j24.5044~\Omega\\ j(2\pi 60)(0.210) \amp= j79.1681~\Omega \end{align*}
    🔗
    Convert the voltage source into a phasor.
    🔗
    \begin{align*} \vec{V_{AC}} \amp= 150\cos{60}+j150\sin{60}~\textrm{V}\\ \amp= 75 + j129.90~\textrm{V} \end{align*}
    🔗
    The 55 Ω resistor is connected in series with the j24.5 Ω impedance.
    🔗
    \begin{equation*} (55~\Omega) + (j24.5044~\Omega) = 55 + j24.5044~\Omega \end{equation*}
    🔗
    The 105 Ω resistor is connected in series with the j79.2 Ω impedance.
    🔗
    \begin{equation*} (105~\Omega) + (j79.1681~\Omega) = 105 + j79.1681~\Omega \end{equation*}
    🔗
    The −j106.1 Ω impedance is connected in parallel with the 105+j79.2 Ω impedance.
    🔗
    \begin{equation*} \frac{(-j106.10~\Omega)(105 + j79.1681)}{(-j106.10~\Omega)+(105 + j79.1681)} = 100.60 -j80.297~\Omega \end{equation*}
    🔗
    Use the voltage divider rule to calculate \(\vec{V_{out}}\text{.}\)
    🔗
    \begin{align*} \vec{V_{out}} \amp= (75 + j129.90~\textrm{V})\left(\frac{100.60 -j80.297~\Omega}{(55 + j24.50~\Omega)+(100.60 -j80.297~\Omega)}\right)\\ \amp= 87.9786 + j76.8285~\textrm{V}\\ \amp= 116.8026~\textrm{V} \angle 41.1295^\circ \end{align*}
    🔗
    Convert the output to a time-varying signal.
    🔗
    \begin{equation*} v_{out}(t) = 117~\textrm{V}~\cos{(2\pi60 t+41.1\pi/180)} \end{equation*}
    🔗
    🔗
    🔗

    Subsection 9.1.2 Complex Current Divider

    For any number of impedances connected in parallel with a current source, the complex current divider rule uses the complex form of Ohm’s law (defined in (8.2.1)) to calculate the current through any of the impedances.
    🔗
    Given \(n\) impedances in parallel with a source current of \(\vec{I_S}\text{,}\) the current through the \(k^\textrm{th}\) impedance (where \(k \lt n\)) is defined in (9.1.2).
    🔗
    \begin{equation} \vec{I_k} = \vec{I_S}\left(\frac{\vec{Z_{EQ}}}{\vec{Z_k}}\right)\tag{9.1.2} \end{equation}
    🔗

    Example 9.1.6 Complex current divider.

    Use the current divider rule to calculate each of the currents as shown. The source is equal to \(i_{AC}(t) = 10~\textrm{A}~\cos(2\pi 50 t+120\pi/180)\text{.}\)
    🔗
    Use (8.2.4) to calculate the impedance of the capacitor.
    🔗
    \begin{equation*} \frac{1}{j(2\pi50)(470\times10^{-6})} = -j6.77~\Omega \end{equation*}
    🔗
    Use (8.2.5) to calculate the impedance of the inductor.
    🔗
    \begin{equation*} j2\pi50(0.025) = j7.85~\Omega \end{equation*}
    🔗
    Convert the current source to phasor form.
    🔗
    \begin{align*} \vec{I_{AC}} \amp= 10\cos{120^\circ} + j10\sin{120^\circ}~\textrm{A}\\ \amp= -5+j8.66~\textrm{A} \end{align*}
    🔗
    The 5 Ω resistor and j7.85 Ω impedance are connected in series.
    🔗
    Refer to Example 2.6.4 for solving a current divider circuit with three meshes. We will need to calculate the equivalent impedance as seen by the −j6.77 Ω impedance to calculate the branch currents. This impedance will be referred to as \(\vec{Z'}\text{.}\)
    🔗
    \begin{align*} \vec{Z'} \amp= \frac{(-j6.77)(5+j7.85~\Omega)}{(-j6.77)+(5+j7.85~\Omega)}\\ \amp= 8.7635 - j8.6680~\Omega \end{align*}
    🔗
    The 3 Ω resistor and 8.76−j8.67 Ω impedance are connected in series.
    🔗
    Calculate the equivalent impedance of this circuit.
    🔗
    \begin{equation*} \frac{(8~\Omega)(11.7635 - j8.6680~\Omega)}{(8~\Omega)+(11.7635 - j8.6680~\Omega)} = 5.2841 - j1.1911~\Omega \end{equation*}
    🔗
    Use the current divider rule to calculate \(\vec{I_1}\) and \(\vec{I_2}\text{.}\)
    🔗
    \begin{align*} \vec{I_1} \amp= (-5+j8.66~\textrm{A})\frac{5.2841 - j1.1911~\Omega}{8~\Omega}\\ \amp= -2.0131 + j6.4647~\textrm{A}\\ \amp= 6.7709~\textrm{A} \angle 107.2968^\circ\\ \vec{I_2} \amp= (-5+j8.66~\textrm{A})\frac{5.2841 - j1.1911~\Omega}{11.76-j8.67~\Omega}\\ \amp= -2.9869 + j2.1956~\textrm{A}\\ \amp= 3.7070~\textrm{A} \angle 143.6815^\circ \end{align*}
    🔗
    Convert both of these values into time-varying signals.
    🔗
    \begin{align*} i_1(t) \amp= 6.77~\textrm{A}~\cos(2\pi50t+107\pi/180)\\ i_2(t) \amp= 3.71~\textrm{A}~\cos(2\pi50t+144\pi/180) \end{align*}
    🔗
    Re-draw the circuit. Current \(\vec{I_2}\) can be used to represent a source supplying the −j6.77 Ω and 5+j7.85 Ω impedances.
    🔗
    The equivalent impedance of this circuit was previously calculated as \(\vec{Z'}\text{.}\)
    🔗
    Use the current divider rule to calculate \(\vec{I_3}\) and \(\vec{I_4}\text{.}\)
    🔗
    \begin{align*} \vec{I_3} \amp= (-2.99+j2.20~\textrm{A})\frac{8.7635 - j8.6680~\Omega}{-j6.77~\Omega}\\ \amp= -6.6638 - j1.0549~\textrm{A}\\ \amp= 6.7468~\textrm{A} \angle -171.0044^\circ\\ \vec{I_4} \amp= (-2.99+j2.20~\textrm{A})\frac{8.7635 - j8.6680~\Omega}{5+j7.85~\Omega}\\ \amp= 3.6769 + j3.2505~\textrm{A}\\ \amp= 4.9077~\textrm{A} \angle 41.4772^\circ \end{align*}
    🔗
    Convert both of these values into time-varying signals.
    🔗
    \begin{align*} i_3(t) \amp= 6.75~\textrm{A}~\cos(2\pi50t-171\pi/180)\\ i_4(t) \amp= 4.91~\textrm{A}~\cos(2\pi50t+41.5\pi/180) \end{align*}
    🔗

    Subsection 9.1.3 Complex KCL and KVL Analysis

    Kirchhoff’s current and voltage laws still hold in a phasor-transformed circuit. KCL states that the sum of all branch currents entering a node is equal to zero. KVL states that the sum of all voltage drops in a loop is equal to zero.
    🔗
    Together, KCL and KVL can be used to solve for every branch current in a circuit. Those branch currents can be multiplied by impedance to calculate voltage drops over every circuit element. By analyzing nodes and loops in a circuit, a number of equations (using KCL, KVL, and Ohm’s law) can be found. If there are \(n\) unknown branch currents in the circuit, \(n\) linearly independent equations will be needed. A matrix can then be used to solve for the unknowns.
    🔗
    The equations that are derived to generate the matrix defining the circuit will now contain complex coefficients. Not all graphing calculators are capable of solving a matrix with complex coefficients. The TI-89 is capable of solving complex matrices. Otherwise, programs such as Matlab or websites such as Wolfram Alpha are capable of doing such calculations.
    🔗

    Example 9.1.13 Complex KCL / KVL analysis.

    Calculate all branch currents in the following circuit. The source values are \(i_{AC}(t) = 4~\textrm{A}~\cos(2\pi 100t + 20\pi/180)\) and \(v_{AC}(t) = 20~\textrm{V}~\cos(2\pi 100t + 45\pi/180)\text{.}\)
    🔗
    Use (8.2.4) to calculate the impedance of both capacitors.
    🔗
    \begin{align*} \frac{1}{j(2\pi 100)(20 \times 10^{-6})} \amp= -j79.5775~\Omega\\ \frac{1}{j(2\pi 100)(25 \times 10^{-6})} \amp= -63.6620~\Omega \end{align*}
    🔗
    Use (8.2.5) to calculate the impedance of both inductors.
    🔗
    \begin{align*} j(2\pi 100)(0.025) \amp= j15.7080~\Omega\\ j(2\pi 100)(0.1) \amp= j62.8319~\Omega \end{align*}
    🔗
    Phasor transform both sources.
    🔗
    \begin{align*} \vec{I_{AC}} \amp= 4~\cos{20^\circ}+j4~\sin{20^\circ}~\textrm{A}\\ \amp= 3.7588 + j1.3681~\textrm{A}\\ \vec{V_{AC}} \amp= 20~\cos{45^\circ}+j20~\sin{45^\circ}~\textrm{V}\\ \amp= 14.1421 + j14.1421~\textrm{V} \end{align*}
    🔗
    The 50 Ω resistor is connected in series with the j15.7 Ω impedance. The 100 Ω resistor is connected in series with the −j63.7 Ω impedance.
    🔗
    The circuit has two linearly independent perfect nodes. One of them connects the 50+j15.7 Ω impedance, current source, 20 Ω resistor, and −j79.6 Ω impedance. The other connects the −j79.6 Ω impedance, j62.8 Ω impedance, and 100−j63.7 Ω impedance. Perform KCL at both of these nodes.
    🔗
    \begin{align*} \vec{I_1} + \vec{I_2} + \vec{I_3} \amp= \vec{I_{AC}}\\ \vec{I_2} + \vec{I_4} - \vec{I_5} \amp= 0 \end{align*}
    🔗
    The circuit has three linearly independent perfect loops. One of them includes the 50+j15.7 Ω impedance, 20 Ω resistor, and voltage source. Another one includes the voltage source, the j62.8 Ω impedance, and the 100−j63.7 Ω impedance. The third includes the 20 Ω resistor, j62.8 Ω impedance, and −j79.6 Ω impedance. Perform KVL around each of these loops. The units used in the equations below are A, V, and Ω.
    🔗
    \begin{align*} -(50+j15.71)\vec{I_1} + (20)\vec{I_3} + \vec{V_{AC}} \amp= 0\\ -\vec{V_{AC}} + (j62.83)\vec{I_4} + (100-j63.66)\vec{I_5} \amp= 0\\ (-j79.58)\vec{I_2} - (j62.83)\vec{I_4} - (20)\vec{I_3} \amp= 0 \end{align*}
    🔗
    The five equations can be expressed in a matrix. The left column contains coefficients of \(\vec{I_1}\text{,}\) then \(\vec{I_2}\text{,}\) \(\vec{I_3}\text{,}\) and \(\vec{I_4}\text{,}\) and \(\vec{I_5}\text{.}\) The right column contains constants.
    🔗
    \begin{equation*} \begin{bmatrix} 1 \amp 1 \amp 1 \amp 0 \amp 0 \amp 3.76+j1.37\\ 0 \amp 1 \amp 0 \amp 1 \amp -1 \amp 0\\ -(50+j15.7) \amp 0 \amp 20 \amp 0 \amp 0 \amp -(14.1+j14.1)\\ 0 \amp 0 \amp 0 \amp j62.8 \amp 100-j63.7 \amp 14.1+j14.1\\ 0 \amp (-j79.6) \amp -20 \amp -(j62.8) \amp 0 \amp 0 \end{bmatrix} \end{equation*}
    🔗
    Solve for each current by calculating the reduced row echelon form of the matrix.
    🔗
    \begin{align*} \vec{I_1} \amp= 1.15 + j0.13~\textrm{A}\\ \amp= 1.1616~\textrm{A} \angle 6.4752^\circ\\ \vec{I_2} \amp= 0.53 + j0.71~\textrm{A}\\ \amp= 0.8857~\textrm{A} \angle 53.3111^\circ\\ \vec{I_3} \amp= 2.08 + j0.53~\textrm{A}\\ \amp= 2.1413~\textrm{A} \angle 14.2440^\circ\\ \vec{I_4} \amp= -0.84 - j0.24~\textrm{A}\\ \amp= 0.8713~\textrm{A} \angle -164.0878^\circ\\ \vec{I_5} \amp= -0.31 + j0.47~\textrm{A}\\ \amp= 0.5635~\textrm{A} \angle 123.2253^\circ \end{align*}
    🔗
    Convert each branch current to a time-dependent function.
    🔗
    \begin{align*} i_1(t) \amp= 1.16~\textrm{A}~\cos{(2\pi100t + 6.48\pi/180)}\\ i_2(t) \amp= 0.886~\textrm{A}~\cos{(2\pi100t + 53.3\pi/180)}\\ i_3(t) \amp= 2.14~\textrm{A}~\cos{(2\pi100t + 14.2\pi/180)}\\ i_4(t) \amp= 0.871~\textrm{A}~\cos{(2\pi100t -164\pi/180)}\\ i_5(t) \amp= 0.564~\textrm{A}~\cos{(2\pi100t + 123\pi/180)} \end{align*}
    🔗
    🔗

    Subsection 9.1.4 Complex Mesh Analysis

    Mesh analysis can also be used in phasor-transformed circuits. KCL and KVL are used to solve for mesh currents. The mesh analysis method steps, outlined in Subsection 2.8.2, are exactly the same in a phasor-transformed circuit.
    🔗

    Example 9.1.17 Complex mesh analysis.

    Calculate all mesh currents as well as \(\vec{V_X}\) in the following circuit. The voltage source has a value of \(v_{AC}(t) = 330~\textrm{V}~\cos(2\pi 250 t - 50\pi/180)\text{.}\) The proportionality constant of the VCCS has a unit of A/V.
    🔗

    Subsection 9.1.5 Complex Superposition

    Superposition applies to all linear circuits. If a linear circuit has \(n\) independent sources, then \(n\) subcircuits can be created, each with one of the independent sources activated and all others deactivated. Add the properties of each of the subcircuits together to find the total value of the property.
    🔗
    To deactivate a voltage source, replace the voltage source with a short circuit (corresponding to 0 V). To deactivate a current source, replace the current source with an open circuit (corresponding to 0 A). Any dependent sources that exist in the circuit cannot be eliminated and must be present in all subcircuits.
    🔗

    Subsection 9.1.6 Complex Source Transformation

    In a phasor-transformed circuit, source transformation can be used to convert an AC current source into an AC voltage source and vice versa. The transformation process changes the source type and the impedance location, but results in an equivalent circuit. The goal of source transformation is usually to reduce a circuit by changing the position of the source and an impedance. This can lead to further reductions using series and parallel combinations of impedances.
    🔗
    Two equivalent circuits will have identical voltage drops over the load (depicted as \(\vec{V}\) in Figure 9.1.30) as well as identical currents flowing into the load (depicted as \(\vec{I}\) in Figure 9.1.30).
    🔗
    A voltage source with a value of \(\vec{V_S}\) in series with an impedance with a value of \(\vec{Z_S}\) can be transformed into an equivalent circuit with a current source in parallel with that same impedance. Ohm’s law is used to calculate the value of the current source, which is equal to \(\vec{V_S/Z_S}\text{.}\) This is depicted schematically in Figure 9.1.31.
    🔗
    A current source with a value of \(\vec{I_S}\) in parallel with an impedance with a value of \(\vec{Z_S}\) can be transformed into an equivalent circuit with a voltage source in series with that same impedance. Ohm’s law is used to calculate the value of the voltage source, which is equal to \(\vec{I_S Z_S}\text{.}\) This is depicted schematically in Figure 9.1.32.
    🔗
    In either case (converting a voltage source to a current source, or vice versa), the position of the impedance changes but the value of the impedance remains unchanged.
    🔗
    As noted in Section 3.2, this process is not limited to independent sources. It is possible to conduct source transformation with any kind of power source used in a linear circuit.
    🔗

    Subsection 9.1.7 Complex Thévenin’s and Norton’s Theorems

    The phasor-transformed version of Thévenin’s theorem states that any linear circuit (regardless of the complexity) can be represented by an equivalent circuit that contains a voltage source in series with an impedance. This is depicted in Figure 9.1.40.
    🔗
    The Thévenin equivalent voltage (\(\vec{V_{TH}}\)) is equal to the open-circuit voltage between the output terminals. The Thévenin equivalent impedance (\(\vec{Z_{TH}}\)) is solved using the procedure described in Section 3.5, using complex (rather than resistive) circuit analysis techniques.
    🔗

    Example 9.1.41 Complex Thévenin equivalent circuit.

    Derive a Thévenin equivalent circuit for the circuit shown below. The source voltage is \(v_{AC}(t) = 3~\textrm{V}~\cos(2\pi 100t)\text{.}\) The proportionality constant of the VCCS has a unit of A/V.
    🔗
    Use (8.2.4) to calculate the impedance of both capacitors.
    🔗
    \begin{align*} \frac{1}{j(2\pi100)(22 \times 10^{-6})} \amp= -j72.3432~\Omega\\ \frac{1}{j(2\pi100)(47 \times 10^{-6})} \amp= -j33.8628~\Omega \end{align*}
    🔗
    Convert the voltage source to a phasor.
    🔗
    \begin{align*} \vec{V_{AC}} \amp= 3~\cos{0^\circ} + j3~\sin{0^\circ}~\textrm{V}\\ \amp= 3~\textrm{V} \end{align*}
    🔗
    KCL can be used to derive two equations to solve for \(\vec{V_{TH}}\text{,}\) which is equal to the voltage dropped over the 68 Ω resistor. Units of V, A, and Ω will be used in all subsequent equations. First, perform KCL at the node connecting the 47 Ω resistor, −j72.3 Ω impedance, and −j33.9 Ω impedance.
    🔗
    \begin{align*} \frac{\vec{V_{AC}} - \vec{V_X}}{47} \amp= \frac{\vec{V_X}}{-j72.3} + \frac{\vec{V_X}-\vec{V_{TH}}}{-j33.9}\\ \frac{3}{47} \amp= \frac{\vec{V_X}}{47} + \frac{\vec{V_X}}{-j72.3} + \frac{\vec{V_X}-\vec{V_{TH}}}{-j33.9}\\ \amp= \vec{V_X} \left(\frac{1}{47} + \frac{1}{-j72.3} + \frac{1}{-j33.9}\right) + \vec{V_{TH}} \left(-\frac{1}{-j33.9}\right) \end{align*}
    🔗
    Next, perform KCL at the node connecting the −j33.9 Ω impedance, VCCS, and 68 Ω resistor.
    🔗
    \begin{align*} \frac{\vec{V_X}-\vec{V_{TH}}}{-j33.9} \amp= 0.3\vec{V_X} + \frac{\vec{V_{TH}}}{68}\\ 0 \amp= \frac{\vec{V_X}}{-j33.9} - \frac{\vec{V_{TH}}}{-j33.9} - 0.3\vec{V_X} - \frac{\vec{V_{TH}}}{68}\\ \amp= \vec{V_X} \left(\frac{1}{-j33.9} - 0.3\right) + \vec{V_{TH}}\left(-\frac{1}{-j33.9} - \frac{1}{68}\right) \end{align*}
    🔗
    The two equations can be expressed in a matrix. The left column contains coefficients of \(\vec{V_X}\text{,}\) the middle column contains coefficients of \(\vec{V_{TH}}\text{,}\) and the right column contains constants.
    🔗
    \begin{equation*} \begin{bmatrix} 0.0213 + j0.0434 \amp -j0.0295 \amp 0.0638\\ -0.3 + j0.0295 \amp -0.0147 - j0.0295 \amp 0 \end{bmatrix} \end{equation*}
    🔗
    The matrix is shown in reduced row echelon form below.
    🔗
    \begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0.1853 - j0.0945\\ 0 \amp 1 \amp 0.2040 + j1.8893 \end{bmatrix} \end{equation*}
    🔗
    The Thévenin equivalent voltage can be converted to time-varying form.
    🔗
    \begin{align*} \vec{V_{TH}} \amp= 0.2040 + j1.8893~\textrm{V}\\ \amp= 1.9003~\textrm{V} \angle 83.8388^\circ\\ v_{th}(t) \amp= 1.9~\textrm{V}~\cos(2\pi100t + 83.8\pi/180) \end{align*}
    🔗
    Because there is a dependent source, the short-circuit current must be calculated to determine the value of the Thévenin equivalent impedance. The 68 Ω resistor is shorted and can be removed from the circuit.
    🔗
    KCL can be used to derive two equations to solve for \(\vec{I_{SC}}\text{.}\) Units of V, A, and Ω will be used in all subsequent equations. First, perform KCL at the node connecting the 47 Ω resistor, −j72.3 Ω impedance, and −j33.9 Ω impedance.
    🔗
    \begin{align*} \frac{\vec{V_{AC}} - \vec{V_X}}{47} \amp= \frac{\vec{V_X}}{-j72.3} + \frac{\vec{V_X}}{-j33.9}\\ \frac{3}{47} \amp= \frac{\vec{V_X}}{47} + \frac{\vec{V_X}}{-j72.3} + \frac{\vec{V_X}}{-j33.9}\\ \amp= \vec{V_X} \left(\frac{1}{47} + \frac{1}{-j72.3} + \frac{1}{-j33.9}\right) \end{align*}
    🔗
    Next, perform KCL at the node connecting the −j33.9 Ω impedance, VCCS, and short.
    🔗
    \begin{align*} \frac{\vec{V_X}}{-j33.9} \amp= 0.3\vec{V_X} + \vec{I_{SC}}\\ 0 \amp= \frac{\vec{V_X}}{-j33.9} - 0.3\vec{V_X} - \vec{I_{SC}}\\ \amp= \vec{V_X} \left(\frac{1}{-j33.9} - 0.3\right) + \vec{I_{SC}}\left(-1\right) \end{align*}
    🔗
    The two equations can be expressed in a matrix. The left column contains coefficients of \(\vec{V_X}\text{,}\) the middle column contains coefficients of \(\vec{I_{SC}}\text{,}\) and the right column contains constants.
    🔗

    🔗

    🔗

    🔗
    Use Ohm’s law to calculate the Thévenin equivalent impedance.
    🔗

    Norton’s theorem states that any linear circuit, regardless of the level of complexity, can be represented by an equivalent circuit that contains a current source in parallel with an impedance. This is depicted in Figure 9.1.46.

The Norton equivalent impedance (\(\vec{Z_N}\)) is solved using the procedure described in Section 3.6, using complex (rather than resistive) circuit analysis techniques.
