    Solution.

    7.

    Calculate \(\vec{V}\) given the circuit diagram shown in Figure 9.6.14.
    🔗
    Answer.
    \begin{equation*} -31.2 + j28.7~\textrm{V} \end{equation*}
    🔗
    🔗
    Solution.
    The j5 Ω impedance is connected in parallel with the −j6 Ω impedance.
    🔗
    \begin{equation*} \frac{(j5~\Omega)(-j6~\Omega)}{(j5~\Omega)+(-j6~\Omega)} = j30~\Omega \end{equation*}
    🔗
    Define each branch current.
    🔗
    There are three unknown branch currents. Therefore, three equations will need to be derived.
    🔗
    There are two perfect nodes in this circuit. However, using both will generate linearly dependent equations. Perform KCL at the node located where the 8 Ω, 10 Ω, and 5 Ω resistors connect. All units used in subsequent equations in this problem are V, A, and Ω.
    🔗
    \begin{equation*} \vec{I_1}-\vec{I_2}-\vec{I_3} = 0 \end{equation*}
    🔗
    Any two of the three circuit loops can be used with KCL to derive the other two equations. The first KVL equation below analyzes the left loop of the circuit, and the second KVL equation below analyzes the right loop of the circuit.
    🔗
    \begin{align*} 8\vec{I_1} + 10\vec{I_2} \amp= 80 \angle 120^\circ\\ -10\vec{I_2} + (5+j30)\vec{I_3} \amp= 0 \end{align*}
    🔗
    The three equations can be expressed in a matrix. The left column contains coefficients of \(\vec{I_1}\text{,}\) the middle-left column contains coefficients of \(\vec{I_2}\text{,}\) the middle-right column contains coefficients of \(\vec{I_3}\text{,}\) and the right column contains constants.
    🔗
    \begin{equation*} \begin{bmatrix} 1 \amp -1 \amp -1 \amp 0 \\ 8 \amp 10 \amp 0 \amp 80 \angle 120^\circ \\ 0 \amp -10 \amp 5+j30 \amp 0 \end{bmatrix} \end{equation*}
    🔗
    The branch current that needs to be known to solve for \(\vec{V}\) is \(\vec{I_3}\text{.}\) This value is
    🔗
    \begin{equation*} \vec{I_3} = 0.9551 + j1.0414~\textrm{A}\text{.} \end{equation*}
    🔗
    Use Ohm’s law to calculate \(\vec{V}\text{.}\)
    🔗
    \begin{align*} \vec{V} \amp= (0.9551 + j1.0414~\textrm{A})(j30~\Omega)\\ \amp= -31.2 + j28.7~\textrm{V} \end{align*}
