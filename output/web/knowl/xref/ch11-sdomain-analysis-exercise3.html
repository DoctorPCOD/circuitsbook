Exercise 13.

Use \(s\)-domain analysis to calculate \(V(s)\) and \(v(t)\) of the circuit shown in Figure 11.4.6. The switch is in position a for a very long time before moving to position b at a time of zero seconds. The component values are: \(V_{S1} = 6~\textrm{V}\text{,}\) \(V_{S2} = 20~\textrm{V}\text{,}\) \(R_1 = 4~\Omega\text{,}\) \(R_2 = 2~\Omega\text{,}\) \(C = 50~\mu\textrm{F}\text{,}\) and \(L = 1~\textrm{mH}\text{.}\)
🔗
Answer.
\begin{align*} V(s) \amp= \frac{2s^2 + 28000s + 4 \times 10^8}{s (s^2+14000s + 6 \times 10^7 )}\\ v(t) \amp= \left[6.67~\textrm{V} + \textrm{e}^{-7000t}\left(-4.67~\textrm{V}~\cos(3316.63t) - 9.85~\textrm{V}~\sin(3316.63t)\right)\right] \end{align*}
🔗
🔗
Solution.
Calculate the initial conditions of the circuit.
🔗
\begin{align*} i(0) \amp= \frac{V_{S1}}{R_1+R_2}\\ \amp= 1~\textrm{A}\\ v(0) \amp= V_{S1}\left(\frac{R_2}{R_1+R_2}\right)\\ \amp= 2~\textrm{V} \end{align*}
🔗
Transform the circuit into the \(s\)-domain.
🔗
Perform KCL to find an equation in terms of \(V(s)\text{.}\) Then, solve for \(V(s)\) and normalize.
🔗
\begin{align*} \frac{\frac{V_{S2}}{s}+\frac{LV_{S1}}{R_1+R_2} - V(s)}{R_1+sL} \amp= \frac{V(s)}{R_2} + \frac{V(s)-\frac{V_{S1}R_2}{s(R_1+R_2)}}{\frac{1}{sC}}\\ \frac{V_{S2}}{s} + \frac{LV_{S1}}{R_1+R_2} \amp= V(s) + (R_1+sL)\left[\frac{V(s)}{R_2} + sCV(s) - \frac{CV_{S1}R_2}{R_1+R_2}\right]\\ \amp= V(s) + \frac{R_1}{R_2}V(s) + \frac{sL}{R_2}V(s) + sCR_1V(s) + s^2LCV(s) \\ \amp- \frac{CV_{S1}R_1R_2}{R_1+R_2} - \frac{sLCV_{S1}R_2}{R_1+R_2}\\ \frac{V_{S2}}{s} + \frac{LV_{S1}}{R_1+R_2} + \frac{CV_{S1}R_1R_2}{R_1+R_2} + \frac{sLCV_{S1}R_2}{R_1+R_2} \amp= (LC)s^2V(s) + \left[\frac{L}{R_2} + CR_1\right]sV(s) + \left[\frac{R_1+R_2}{R_2}\right]V(s)\\ \left[\frac{V_{S1}R_2}{R_1+R_2}\right]s + \left[\frac{LV_{S1}+CV_{S1}R_1R_2}{LC(R_1+R_2)}\right] + \left[\frac{V_{S2}}{LC}\right]\frac{1}{s} \amp= s^2V(s) + \left[\frac{1}{CR_2} + \frac{R_1}{L}\right]sV(s) + \left[\frac{R_1+R_2}{LCR_2}\right]V(s)\\ \left[\frac{V_{S1}R_2}{R_1+R_2}\right]s^2 + \left[\frac{LV_{S1}+CV_{S1}R_1R_2}{LC(R_1+R_2)}\right]s + \left[\frac{V_{S2}}{LC}\right] \amp= s\left(s^2V(s) + \left[\frac{1}{CR_2} + \frac{R_1}{L}\right]sV(s) + \left[\frac{R_1+R_2}{LCR_2}\right]V(s)\right)\\ V(s) \amp= \frac{\left[\frac{V_{S1}R_2}{R_1+R_2}\right]s^2 + \left[\frac{LV_{S1}+CV_{S1}R_1R_2}{LC(R_1+R_2)}\right]s + \left[\frac{V_{S2}}{LC}\right]}{s\left(s^2+\left[\frac{1}{R_2C}+\frac{R_1}{L}\right]s + \left[\frac{R_1+R_2}{LCR_2}\right]\right)} \end{align*}
🔗
Plug in component values using base units.
🔗
\begin{equation*} V(s) = \frac{2s^2 + 28000s + 4\textrm{E}8}{s\left(s^2+14000s + 6\textrm{E}7\right)} \end{equation*}
🔗
Factor the denominator of \(V(s)\text{.}\)
🔗
\begin{equation*} V(s) = \frac{2s^2 + 28000s + 4\textrm{E}8}{s(s+7000+j3166.6)(s+7000-j3166.6)} \end{equation*}
🔗
The partial fraction expansion will take the form shown below.
🔗
\begin{equation*} V(s) = \frac{K_1}{s} + \frac{K_2}{(s+7000+j3166.6)} + \frac{K_3}{(s+7000-j3166.6)} \end{equation*}
🔗
To calculate coefficient \(K_1\text{,}\) multiply both sides of the equation by \((s)\) and solve at \(s=0\text{.}\)
🔗
\begin{align*} \frac{(2s^2 + 28000s + 4\textrm{E}8)(s)}{s(s+7000+j3316.6)(s+7000-j3316.6)}\Big|_{s=0} \amp= \frac{K_1(s)}{s}\Big|_{s=0} + \frac{K_2(s)}{(s+7000+j3316.6)}\Big|_{s=0} + \frac{K_3(s)}{(s+7000-j3316.6)}\Big|_{s=0}\\ \frac{2s^2 + 28000s + 4\textrm{E}8}{(s+7000+j3316.6)(s+7000-j3316.6)}\Big|_{s=0} \amp= K_1\Big|_{s=0} + \frac{K_2(s)}{(s+7000+j3316.6)}\Big|_{s=0} + \frac{K_3(s)}{(s+7000-j3316.6)}\Big|_{s=0}\\ \frac{2(0)^2 + 28000(0) + 4\textrm{E}8}{(0+7000+j3316.6)(0+7000-j3316.6)} \amp= K_1 + \frac{K_2(0)}{(0+7000+j3316.6)} + \frac{K_3(0)}{(0+7000-j3316.6)}\\ \frac{400000000}{60000000} \amp= K_1 + 0 + 0\\ K_1 \amp= 6.6667~\textrm{V} \end{align*}
🔗
To calculate coefficient \(K_2\text{,}\) multiply both sides of the equation by \((s+7000+j3316.6)\) and solve at \(s=-7000-j3316.6\text{.}\)
🔗
\begin{align*} \frac{(2s^2 + 28000s + 4\textrm{E}8)(s+7000+j3316.6)}{s(s+7000+j3316.6)(s+7000-j3316.6)}\Big|_{s=-7000-j3316.6} \amp= \frac{K_1(s+7000+j3316.6)}{s}\Big|_{s=-7000-j3316.6} + \frac{K_2(s+7000+j3316.6)}{(s+7000+j3316.6)}\Big|_{s=-7000-j3316.6} + \frac{K_3(s+7000+j3316.6)}{(s+7000-j3316.6)}\Big|_{s=-7000-j3316.6}\\ \frac{2s^2 + 28000s + 4\textrm{E}8}{s(s+7000-j3316.6)}\Big|_{s=-7000-j3316.6} \amp= \frac{K_1(s+7000+j3316.6)}{s}\Big|_{s=-7000-j3316.6} + K_2\Big|_{s=-7000-j3316.6} + \frac{K_3(s+7000+j3316.6)}{(s+7000-j3316.6)}\Big|_{s=-7000-j3316.6}\\ \frac{2(-7000-j3316.6)^2 + 28000(-7000-j3316.6) + 4\textrm{E}8}{(-7000-j3316.6)((-7000-j3316.6)+7000-j3316.6)} \amp= \frac{K_1((-7000-j3316.6)+7000+j3316.6)}{(-7000-j3316.6)} + K_2 + \frac{K_3((-7000-j3316.6)+7000+j3316.6)}{((-7000-j3316.6)+7000-j3316.6)}\\ \frac{280000000}{-2.2\textrm{E}7 + j4.6433\textrm{E}7} \amp= \frac{K_1(0)}{(-7000-j3316.6)} + K_2 + \frac{K_3(0)}{((-7000-j3316.6)+7000-j3316.6)}\\ K_2 \amp= -2.3333 - j4.9247 \end{align*}
🔗
\(K_3\) is equal to the complex conjugate of \(K_2\text{.}\)
🔗
\begin{equation*} K_3 = -2.3333 + j4.9247 \end{equation*}
🔗
The expanded form of \(V(s)\) is given below.
🔗
\begin{equation*} V(s) = \frac{6.67}{s} + \frac{-2.333-j4.925}{(s+7000+j3316.6)} + \frac{-2.333+j4.925}{(s+7000-j3316.6)} \end{equation*}
🔗
Consult Table 11.1.1 to derive the time-domain function.
🔗
\begin{equation*} v(t) = \left[6.67~\textrm{V} + \textrm{e}^{-7000t}\left(-4.67~\textrm{V}~\cos(3316.63t) - 9.85~\textrm{V}~\sin(3316.63t)\right)\right]~u(t) \end{equation*}
