Example 2.6.4 Current divider with a three-mesh circuit.

Calculate \(I_{OUT}\) in the circuit shown below.
🔗
The current divider rule cannot immediately be applied to calculate \(I_{OUT}\text{.}\) This is because the resistors are not all in parallel with the current source. However, the current divider rule can be applied directly to calculate \(I_X\text{,}\) provided that the equivalent resistance seen by \(R_1\) is calculated. This creates a circuit with two resistances in parallel with the current source.
🔗
The equivalent resistance seen by \(R_1\) is equal to
🔗
\begin{equation*} R_2 + (R_3 // R_4). \end{equation*}
🔗
Now, the current divider rule can be used to calculate \(I_X\text{.}\)
🔗
\begin{equation*} I_X = I_S\left(\frac{R_1 // (R_2 + (R_3 // R_4))}{R_2+(R_3//R_4)}\right) \end{equation*}
🔗
Now that \(I_X\) is known, the circuit can be re-drawn to represent \(I_X\) as a source in parallel with resistors \(R_3\) and \(R_4\text{.}\)
🔗
Use the current divider rule to calculate the output voltage.
🔗
\begin{align*} I_{OUT} \amp= I_X\left(\frac{R_3//R_4}{R_4}\right)\\ \amp= I_S\left(\frac{R_1 // (R_2 + (R_3 // R_4))}{R_2+(R_3//R_4)}\right)\left(\frac{R_3//R_4}{R_4}\right) \end{align*}
🔗
This process can be repeatedly iterated if there are four or more meshes in a circuit.
