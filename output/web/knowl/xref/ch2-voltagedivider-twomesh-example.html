Example 2.5.5 Voltage divider with a two-mesh circuit.

Calculate \(V_{OUT}\) in the circuit shown below.
🔗
The voltage divider rule cannot immediately be applied to calculate \(V_{OUT}\text{.}\) This is because the resistors are not all in series with the voltage source \(V_S\text{.}\) However, the voltage divider rule can be applied directly to calculate \(V_X\text{,}\) provided that the equivalent resistance seen by \(R_2\) is calculated. This creates a circuit with two resistances in series with the voltage source.
🔗
The equivalent resistance seen by \(R_2\) is equal to
🔗
\begin{equation*} R_2 // (R_3 + R_4). \end{equation*}
🔗
Now, the voltage divider rule can be used to calculate \(V_X\text{.}\)
🔗
\begin{equation*} V_X = V_S\left(\frac{R_2 // (R_3 + R_4)}{R_1 + (R_2 // (R_3 + R_4))}\right) \end{equation*}
🔗
Now that \(V_X\) is known, the circuit can be re-drawn to represent \(V_X\) as a source in series with resistors \(R_3\) and \(R_4\text{.}\)
🔗
Use the voltage divider rule to calculate the output voltage.
🔗
\begin{align*} V_{OUT} \amp= V_X\left(\frac{R_4}{R_3 + R_4}\right)\\ \amp= V_S\left(\frac{R_2 // (R_3 + R_4)}{R_1 + (R_2 // (R_3 + R_4))}\right)\left(\frac{R_4}{R_3 + R_4}\right) \end{align*}
🔗
This process can be repeatedly iterated if there are three or more meshes in a circuit.
