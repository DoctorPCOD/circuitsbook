Exercise 18.

Calculate \(I_X\) in the circuit shown in Figure 2.10.40.
🔗
Answer.
6.67 mA
🔗
🔗
Solution.
There are two approaches to solve this problem. The first is to define a voltage drop over the 100 Ω resistor and then use KCL at the node connecting the 1 kΩ, 100 Ω, and 1 kΩ resistors. The second is to use a set of matrix equations to solve for \(I_X\text{.}\)
🔗
Let’s start with the first approach. The circuit has been re-drawn to define the unknown voltage (let’s call it \(V_X\)) and label the node of interest.
🔗
The branch currents through the two 1 kΩ resistors can be defined as flowing into node A. (This is an arbitrary choice.) The current through the left 1 kΩ resistor (let’s call it \(I_{L}\)) can be calculated in terms of \(V_X\text{.}\)
🔗
\begin{equation*} I_L = \frac{5~\textrm{V} - V_X}{1~\textrm{k}\Omega} \end{equation*}
🔗
The current through the right 1 kΩ resistor (let’s call it \(I_{R}\)) can also be calculated in terms of \(V_X\text{.}\)
🔗
\begin{equation*} I_R = \frac{3~\textrm{V} - V_X}{1~\textrm{k}\Omega} \end{equation*}
🔗
Branch current \(I_X\) is defined as flowing out of node A. This current can be calculated in terms of \(V_X\text{.}\) (Note the unit of the 100 Ω resistor has been converted to kΩ to be consistent with the other branch current calculations.)
🔗
\begin{equation*} I_X = \frac{V_X}{0.1~\textrm{k}\Omega} \end{equation*}
🔗
Use KCL between \(I_L\text{,}\) \(I_R\text{,}\) and \(I_X\) at node A. This allows us to calculate \(V_X\text{.}\)
🔗
\begin{align*} 0 \amp= I_L + I_R - I_X\\ \amp= \frac{5~\textrm{V} - V_X}{1~\textrm{k}\Omega} + \frac{3~\textrm{V} - V_X}{1~\textrm{k}\Omega} - \frac{V_X}{0.1~\textrm{k}\Omega}\\ \amp= 5~\textrm{V} - V_X + 3~\textrm{V} - V_X - \frac{V_X}{0.1}\\ \amp= 5~\textrm{V} - V_X + 3~\textrm{V} - V_X - 10V_X\\ \amp= 8~\textrm{V} - 12V_X\\ 12V_X \amp= 8~\textrm{V}\\ V_X \amp= 0.667~\textrm{V} \end{align*}
🔗
Use Ohm’s law to calculate \(I_X\text{.}\) (Note that the unit of current will me mA due to the use of V and kΩ.)
🔗
\begin{align*} I_X \amp= \frac{0.667~\textrm{V}}{0.1~\textrm{k}\Omega}\\ \amp= 6.67~\textrm{mA} \end{align*}
🔗
Now let’s use the second approach to solve for \(I_X\text{.}\) We will explicitly define branch currents to use in our calculations. The circuit is re-drawn with these branch currents defined below. (The direction of each branch current is chosen arbitrarily.)
🔗
As there are three unknowns (\(I_1\text{,}\) \(I_2\text{,}\) and \(I_X\)), we will need to derive three equations. All units are in V, mA, and kΩ and will be omitted from the KCL and KVL equations to make them easier to read.
🔗
Node A is a perfect node. Using KCL at this node we obtain one equation.
🔗
\begin{equation*} I_1 - I_2 - I_X = 0 \end{equation*}
🔗
The left mesh is a perfect loop. Using KVL around this loop (starting in the lower left and moving clockwise), we obtain a second equation.
🔗
\begin{equation*} -5 + 1I_1 + 0.1I_X = 0 \end{equation*}
🔗
The right mesh is a perfect loop. Using KVL around this loop (starting in the lower left and moving clockwise), we obtain the third equation.
🔗
\begin{equation*} -0.1I_X + 1I_2 + 3 = 0 \end{equation*}
🔗
The three equations can be expressed in a matrix. The left column contains coefficients of \(I_1\text{,}\) the middle-left column contains coefficients of \(I_2\text{,}\) the middle-right column contains coefficients of \(I_X\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp -1 \amp -1 \amp 0\\ 1 \amp 0 \amp 0.1 \amp 5\\ 0 \amp 1 \amp -0.1 \amp -3 \end{bmatrix} \end{equation*}
🔗
The matrix is shown in reduced row echelon form below.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp 4.33\\ 0 \amp 1 \amp 0 \amp -2.33\\ 0 \amp 0 \amp 1 \amp 6.67 \end{bmatrix} \end{equation*}
🔗
Read the last row to determine that \(I_X = 6.67~\textrm{mA}\text{.}\)
