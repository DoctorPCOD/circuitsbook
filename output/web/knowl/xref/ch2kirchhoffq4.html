Exercise 19.

Calculate \(V_X\) in the circuit shown in Figure 2.10.43.
🔗
Answer.
1.08 V
🔗
🔗
Solution.
KCL and KVL equations will be used to derive branch currents. Then, Ohm’s law will be used to relate the branch current through the 1 kΩ resistor to calculate \(V_X\text{.}\) There are three branches, so the circuit will be re-drawn to define each branch current (the directions have been selected arbitrarily). The perfect node in the circuit is also labeled on the circuit diagram.
🔗
As there are three unknowns (\(I_1\text{,}\) \(I_2\text{,}\) and \(I_3\)), we will need to derive three equations. All units are in V, mA, and kΩ and will be omitted from the KCL and KVL equations to make them easier to read.
🔗
Node a is a perfect node. Using KCL at this node we obtain one equation.
🔗
\begin{equation*} I_1 - I_2 - I_3 = 0 \end{equation*}
🔗
The left mesh is a perfect loop. Using KVL around this loop (starting in the lower left and moving clockwise), we obtain a second equation.
🔗
\begin{equation*} -10 + 0.1I_1 + 0.05I_2 = 0 \end{equation*}
🔗
The right mesh is a perfect loop. Using KVL around this loop (starting in the lower left and moving clockwise), we obtain the third equation.
🔗
\begin{equation*} -0.05I_2 + 2 + 0.2I_3 + 1I_3 = 0 \end{equation*}
🔗
The three equations can be expressed in a matrix. The left column contains coefficients of \(I_1\text{,}\) the middle-left column contains coefficients of \(I_2\text{,}\) the middle-right column contains coefficients of \(I_3\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp -1 \amp -1 \amp 0\\ 0.1 \amp 0.05 \amp 0 \amp 10\\ 0 \amp -0.05 \amp 1.2 \amp -2 \end{bmatrix} \end{equation*}
🔗
The matrix is shown in reduced row echelon form below.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp 67.03\\ 0 \amp 1 \amp 0 \amp 65.95\\ 0 \amp 0 \amp 1 \amp 1.08 \end{bmatrix} \end{equation*}
🔗
Read the last row to determine that \(I_3 = 1.08~\textrm{mA}\text{.}\) Use Ohm’s law to calculate \(V_X\text{.}\)
🔗
\begin{align*} V_X \amp= (1.08~\textrm{mA})(1~\textrm{k}\Omega)\\ \amp= 1.08~\textrm{V} \end{align*}
