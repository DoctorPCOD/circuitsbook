Exercise 23.

Calculate mesh current \(I_X\) in the circuit shown in Figure 2.10.49. Assume that each mesh contains at least one linear circuit element.
🔗
Answer.
\begin{equation*} I_X = -I_2 - I_4 - I_5 - I_7 \end{equation*}
🔗
🔗
Solution.
Note that all of the numbered mesh currents are also branch currents. The only mesh current that isn’t a branch current is in the center (\(I_X\)). Use the relationship between branch and mesh currents to calculate \(I_X\text{.}\) Note that \(I_X\) is defined in an opposing direction to all adjacent mesh currents, which is why the signs of each numbered mesh current is negative.
