Exercise 25.

Use mesh analysis to calculate \(V_X\) in the circuit shown in Figure 2.10.51.
🔗
Answer.
12.2 V
🔗
🔗
Solution.
Redraw the circuit to define the mesh currents. (Note that some parameter values have been removed to make it easier to read the mesh current labels.)
🔗
All subsequent units are in V, A, and Ω and will be omitted from the mesh equations to make them easier to read.
🔗
The left mesh does not contain any current sources. The KCL equation corresponding to the left mesh is:
🔗
\begin{equation*} -20 + 10I_A + 20(I_A-I_B) = 0 \end{equation*}
🔗
The middle and right meshes share a current source. This is a supermesh. KVL will be done around the supermesh, and the relationship between the branch and mesh currents will be used to derive the two equations for these two meshes.
🔗
\begin{align*} 20(I_B-I_A) + 60I_B + 10I_C \amp= 0\\ I_C - I_B \amp= 0.008 \end{align*}
🔗
The three equations can be expressed in a matrix. The left column contains coefficients of \(I_A\text{,}\) the middle-left column contains coefficients of \(I_B\text{,}\) the middle-right column contains coefficients of \(I_C\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 30 \amp -20 \amp 0 \amp 20\\ -20 \amp 80 \amp 10 \amp 0\\ 0 \amp 1 \amp -1 \amp -0.008 \end{bmatrix} \end{equation*}
🔗
The matrix is shown in reduced row echelon form below.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0.782\\ 0 \amp 1 \amp 0 \amp 0.173\\ 0 \amp 0 \amp 1 \amp 0.181 \end{bmatrix} \end{equation*}
🔗
Read the top row to determine that \(I_A = 0.782~\textrm{A}\text{,}\) and read the second row to determine that \(I_B = 0.173~\textrm{A}\text{.}\) Use the relationship between mesh and branch currents to calculate the branch current through the 20 Ω resistor.
🔗
\begin{align*} I_{20} \amp= I_A - I_B\\ \amp= 0.782~\textrm{A} - 0.173~\textrm{A}\\ \amp= 0.609~\textrm{A} \end{align*}
🔗
Use Ohm’s law to calculate \(V_X\text{.}\)
🔗
\begin{align*} V_X \amp= (0.609~\textrm{A})(20~\Omega)\\ \amp= 12.2~\textrm{V} \end{align*}
