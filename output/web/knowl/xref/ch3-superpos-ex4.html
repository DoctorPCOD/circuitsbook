Exercise 4.

Use superposition to calculate \(V_X\) in the circuit shown in Figure 3.8.15. The unit of the proportionality constant on the VCCS is A/V.
🔗
Answer.
50 V
🔗
🔗
Solution.
Draw the circuit with only the voltage source activated. Deactivate the current source by replacing it with an open. The dependent source cannot be removed from the circuit.
🔗
Because there are no voltages over or branch currents through any of the resistors close to the sources, source transformation will be a beneficial way to solve this circuit. (It’s also possible to use KCL/KVL or mesh analysis. Try those methods for additional practice.)
🔗
Convert the voltage source to a current source and re-draw the circuit.
🔗
The two current sources are in parallel and can be combined. Two of the 10 Ω resistors are in parallel and can be combined. The circuit is re-drawn below.
🔗
Convert the current source into a voltage source. Calculate the value of the transformed source.
🔗
\begin{align*} V_S \amp= [(4 + 0.3V_{X1})~\textrm{A}](5~\Omega)\\ \amp= 20~\textrm{V} + 1.5V_{X1} \end{align*}
🔗
Use the voltage divider rule to calculate \(V_{X1}\text{.}\)
🔗
\begin{align*} V_{X1} \amp= (20~\textrm{V} + 1.5V_{X1})\left(\frac{10~\Omega}{5~\Omega+10~\Omega+10~\Omega}\right)\\ \amp= (20~\textrm{V} + 1.5V_{X1})\left(\frac{10~\Omega}{25~\Omega}\right)\\ \amp= (20~\textrm{V} + 1.5V_{X1})(0.4)\\ \amp= 8~\textrm{V} + 0.6V_{X1}\\ 0.4V_{X1} \amp= 8~\textrm{V}\\ V_{X1} \amp= 20~\textrm{V} \end{align*}
🔗
Draw the circuit with only the current source activated. Deactivate the voltage source by replacing it with a short. The dependent source cannot be removed from the circuit.
🔗
Combine the two 10 Ω resistors that are in parallel.
🔗
Source transformation of the dependent source will be a useful method to solve this circuit, for the same reason that was explained above. (Source transformation on the independent source would not be helpful because it would modify the position of the resistor in parallel with the source while not modifying the placement of \(V_{X2}\text{.}\)) The source transformed circuit is shown below.
🔗
Combine the two series resistors.
🔗
Perform another source transformation on the dependent source.
🔗
Because the two current sources are in parallel, they can be combined into an equivalent source. The two resistors can also be combined in parallel.
🔗
Use Ohm’s law to calculate \(V_{X2}\text{.}\)
🔗
\begin{align*} V_{X2} \amp= [(2 + 0.1V_{X2})~\textrm{A}](6~\Omega)\\ \amp= 12~\textrm{V} + 0.6V_{X2}\\ 0.4V_{X2} \amp= 12~\textrm{V}\\ V_{X2} \amp= 30~\textrm{V} \end{align*}
🔗
Add the two values to calculate the voltage \(V_X\text{.}\)
🔗
\begin{align*} V_X \amp= V_{X1} + V_{X2}\\ \amp= 20~\textrm{V} + 30~\textrm{V}\\ \amp= 50~\textrm{V} \end{align*}
