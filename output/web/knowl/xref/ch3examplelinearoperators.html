Example 3.0.2 Identifying linear operators.

Identify which (if any) of the following operators are linear.
🔗
  1. \(\displaystyle \ln\)
    🔗
    🔗
  2. \(\displaystyle \frac{d}{dt}\)
    🔗
    🔗
  3. \(\displaystyle \int dt\)
    🔗
    🔗
🔗
Operator 1 is not linear:
🔗
\begin{equation*} \ln(f(at_1 + bt_2)) \neq a\ln(f(t_1)) + b\ln(f(t_2)) \end{equation*}
🔗
Verify by applying to a linear function \(f(t) = 2t\text{.}\) Let \(a = 5\) and \(b = 2\text{.}\)
🔗
\begin{align*} \ln(f(5t_1 + 2t_2)) \amp=\\ \amp= \ln(2(5t_1+2t_2))\\ \amp= \ln(10t_1 + 4t_2)\\ 5\ln(f(t_1)) + 2\ln(f(t_2))\amp=\\ \amp= 5\ln(2t_1) + 2\ln(2t_2)\\ \amp= \ln((2t_1)^5) + \ln((2t_2)^2)\\ \amp= \ln(((2t_1)^5)(2t_2)^2)\\ \amp= \ln((32t_1^5)(4t_2^2))\\ \amp= \ln(128t_1^5t_2^2) \end{align*}
🔗
Operator 2 is linear:
🔗
\begin{equation*} \frac{d}{dt}f(at_1 + bt_2) = a\frac{d}{dt}f(t_1) + b\frac{d}{dt}f(t_2) \end{equation*}
🔗
Verify by applying to a linear function \(f(t) = 2t\text{.}\) Let \(a = 5\) and \(b = 2\text{.}\)
🔗
\begin{align*} \frac{d}{dt}f(5t_1 + 2t_2) \amp=\\ \amp= \frac{d}{dt}f(5t_1 + 2t_2)\\ \amp= \frac{d}{dt}[2(5t_1 + 2t_2)]\\ \amp= \frac{d}{dt}(10t_1 + 4t_2)\\ \amp= \frac{d}{dt}(10t_1) + \frac{d}{dt}(4t_2)\\ \amp= 10\frac{d}{dt}t_1 + 4\frac{d}{dt}t_2\\ 5\frac{d}{dt}f(t_1) + 2\frac{d}{dt}f(t_2) \amp=\\ \amp= 5\frac{d}{dt}(2t_1) + 2\frac{d}{dt}(2t_2)\\ \amp= 10\frac{d}{dt}t_1 + 4\frac{d}{dt}t_2 \end{align*}
🔗
Operator 3 is linear:
🔗
\begin{equation*} \int f(at_1 + bt_2)\,dt = a\int f(t_1)\,dt + b\int f(t_2)\,dt \end{equation*}
🔗
Verify by applying to a linear function \(f(t) = 2t\text{.}\) Let \(a = 5\) and \(b = 2\text{.}\)
🔗
\begin{align*} \int f(5t_1 + 2t_2)\,dt \amp=\\ \amp= \int 2(5t_1 + 2t_2)\,dt\\ \amp= \int (10t_1 + 4t_2)\,dt\\ \amp= \int (10t_1)\,dt + \int (4t_2)\,dt\\ \amp= 10 \int t_1\,dt + 4 \int t_2\,dt\\ 5\int f(t_1)\,dt + 2\int f(t_2)\,dt \amp=\\ \amp= 5\int 2t_1\,dt + 2 \int 2t_2\,dt\\ \amp= 10\int t_1\,dt + 4 \int t_2\,dt \end{align*}
