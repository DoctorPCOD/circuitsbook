Exercise 14.

Derive the Thévenin equivalent circuit between nodes a and b in the circuit shown in Figure 3.8.70.
🔗
Answer.
🔗
Solution.
Mesh analysis is the easiest way to solve this circuit. Superposition cannot be used as there is only one independent source. Source transformation cannot be used on the independent source without eliminating the branch through which \(I_X\) needs to be measured. However, source transformation can be used on the dependent source and will reduce the number of meshes from three to two. Convert the dependent current source to a dependent voltage source.
🔗
\begin{equation*} (800~\Omega)(4I_X) = (3200~\textrm{V/A})I_X \end{equation*}

\begin{equation*} -2 + 200I_A + 100(I_A-I_B) = 0 \end{equation*}

Use KCL around the right mesh to derive the second equation.
🔗
\begin{equation*} 100(I_B - I_A) + 1200I_B + 3200I_X + 200I_B = 0 \end{equation*}
🔗
Derive an equation relating the controlling current to the mesh currents.
🔗
\begin{equation*} I_X = I_A - I_B \end{equation*}
🔗
The three equations can be expressed in a matrix. The left column contains coefficients of \(I_A\text{,}\) the middle-left column contains coefficients of \(I_B\text{,}\) the middle-right column contains coefficients of \(I_X\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 300 \amp -100 \amp 0 \amp 2\\ -100 \amp 1500 \amp 3200 \amp 0\\ -1 \amp 1 \amp 1 \amp 0 \end{bmatrix} \end{equation*}
🔗
The matrix is shown in reduced row echelon form below.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0.017\\ 0 \amp 1 \amp 0 \amp 0.031\\ 0 \amp 0 \amp 1 \amp -0.014 \end{bmatrix} \end{equation*}
🔗
The Thévenin equivalent voltage is equal to the voltage dropped over the 200 Ω resistor. Use Ohm’s law to calculate this voltage.
🔗
\begin{align*} V_{TH} \amp= (200~\Omega)(I_B)\\ \amp= (200~\Omega)(0.031~\textrm{A})\\ \amp= 6.2~\textrm{V} \end{align*}

🔗
The short-circuit current is equal to mesh current \(I_B\text{.}\) Use Ohm’s law to calculate the Thévenin equivalent resistance.
🔗
\begin{align*} R_{TH} \amp= \frac{V_{TH}}{I_{SC}}\\ \amp= \frac{6.2~\textrm{V}}{0.024~\textrm{A}}\\ \amp= 260~\Omega \end{align*}
