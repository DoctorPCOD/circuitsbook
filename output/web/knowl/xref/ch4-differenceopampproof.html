Derivation

Use a voltage divider at the non-inverting node to calculate the node voltage, which will be called \(V_P\text{.}\)
🔗
\begin{equation*} V_P = \left(\frac{R_I}{R_2+R_I}\right)V_2 \end{equation*}
🔗
Use KCL at the inverting node to calculate the output voltage.
🔗
\begin{align*} \frac{V_1-V_P}{R_1} \amp= \frac{V_P-V_{OUT}}{R_F}\\ -\frac{V_{OUT}}{R_F} \amp= \frac{V_1}{R_1} - \frac{V_P}{R_1} - \frac{V_P}{R_F}\\ \amp= \frac{V_1}{R_1} - \frac{(R_F+R_1)V_P}{R_1R_F}\\ \amp= \frac{V_1}{R_1} - \left(\frac{R_F+R_1}{R_1R_F}\right)\left(\frac{R_I}{R_2+R_I}\right)\\ V_{OUT} \amp= -\left(\frac{R_F}{R_1}\right)V_1 + \left(\frac{R_F+R_1}{R_1}\right)\left(\frac{R_I}{R_2+R_I}\right)V_2 \end{align*}
