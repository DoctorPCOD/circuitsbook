Exercise 13.

Calculate the current through and power consumed by the 220 Ω load resistor in the circuit shown in Figure 4.8.17. (Express this current as a positive value if it flows from \(V_{OUT}\) to ground, and negative if it flows from ground to \(V_{OUT}\text{.}\)) Then, calculate the current sourced by the op-amp. (Express this current as a positive value if the op-amp sources the current, and as a negative value if the op-amp sinks the current.)
🔗
Answer.
\begin{align*} I_{LOAD} \amp= 6.36~\textrm{mA}\\ P_{LOAD} \amp= 8.9~\textrm{mW}\\ I_{SOURCE} \amp= 26.4~\textrm{mA} \end{align*}
🔗
🔗
Solution.
The op-amp circuit is a non-inverting op-amp. Apply (4.5.3) and (4.5.1) to calculate \(V_{OUT}\text{.}\)
🔗
\begin{align*} V_{OUT} \amp= (0.6~\textrm{V})\left(1+\frac{40~\Omega}{30~\Omega}\right)\\ \amp= 1.4~\textrm{V} \end{align*}
🔗
Use Ohm’s law to calculate the current through the 220 Ω load resistor.
🔗
\begin{align*} I_{LOAD} \amp= \frac{1.6~\textrm{V}}{0.22~\textrm{k}\Omega}\\ \amp= 6.36~\textrm{mA} \end{align*}
🔗
Use (2.4.5) to calculate the power consumed by the resistor.
🔗
\begin{align*} P_{LOAD} \amp= (6.36~\textrm{mA})^2(0.22~\textrm{k}\Omega)\\ \amp= (40.5~\textrm{mA}^2)(0.22~\textrm{k}\Omega)\\ \amp= 8.9~\textrm{mW} \end{align*}
🔗
The circuit diagram below is drawn with current directions.
🔗
Use KCL at the op-amp output node to calculate \(I_{SOURCE}\text{.}\)
🔗
\begin{align*} I_{SOURCE} \amp= I_X + 6.36~\textrm{mA}\\ \amp= \frac{1.4~\textrm{V} - 0.6~\textrm{V}}{0.04~\textrm{k}\Omega} + 6.36~\textrm{mA}\\ \amp= 20~\textrm{mA} + 6.36~\textrm{mA}\\ \amp= 26.4~\textrm{mA} \end{align*}
