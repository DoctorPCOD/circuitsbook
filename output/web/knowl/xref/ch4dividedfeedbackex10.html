Exercise 10.

Calculate the output voltage and source gains of the circuit shown in Figure 4.8.11.
🔗
Answer.
\begin{align*} V_{OUT} \amp= 4~\textrm{V}\\ G_1 \amp= 3\\ G_2 \amp= 2.5 \end{align*}
🔗
🔗
Solution.
This circuit doesn’t fit any of the standard op-amp circuit templates (inverting, non-inverting, summing, or difference amplifier). Therefore, the assumptions of an op-amp circuit (no input current, virtual node) can be applied with any useful circuit laws and theorems to calculate these parameters. Because there is a connection between the input of the left op-amp and the output of the right op-amp, cascading op-amp properties cannot be used to calculate the overall circuit gain.
🔗
This solution will use superposition to solve the circuit. Adding the two subcircuit values of \(V_{OUT}\) will yield the overall value of \(V_{OUT}\text{,}\) and each subcircuit can be used to calculate the individual source gain.
🔗
Deactivate source \(V_2\) and draw the circuit diagram to calculate \(G_1\) and \(V_{OUT,1}\text{.}\)
🔗
Perform KCL at the inverting input of the left op-amp. This node voltage will be referred to as \(V_X\text{.}\) The left op-amp’s output voltage will be referred to as \(V_Y\text{.}\)
🔗
\begin{align*} \frac{0.5~\textrm{V}-V_X}{2~\textrm{k}\Omega} \amp= \frac{V_X-V_Y}{4~\textrm{k}\Omega} + \frac{V_X-V_{OUT,1}}{2~\textrm{k}\Omega}\\ 0.25~\textrm{V} - 0.5V_X \amp= 0.25V_X - 0.25V_Y + 0.5V_X - 0.5V_{OUT,1}\\ 0.25~\textrm{V} \amp= 1.25V_X - 0.25V_Y - 0.5V_{OUT,1} \end{align*}
🔗
Perform KCL at the non-inverting input of the left op-amp.
🔗
\begin{align*} \frac{0-V_X}{2~\textrm{k}\Omega} \amp= \frac{V_X-V_{OUT,1}}{3~\textrm{k}\Omega}\\ -0.5V_X \amp= 0.33V_X - 0.33V_{OUT,1}\\ 0 \amp= 0.83V_X - 0.33V_{OUT,1} \end{align*}
🔗
Perform KCL at the inverting input of the right op-amp.
🔗
\begin{align*} \frac{V_Y}{2~\textrm{k}\Omega} \amp= \frac{0-V_{OUT,1}}{3~\textrm{k}\Omega}\\ 0.5V_Y \amp= -0.33V_{OUT,1}\\ 0 \amp= 0.5V_Y + 0.33V_{OUT,1} \end{align*}
🔗
The three equations can be expressed in a matrix. The left column contains coefficients of \(V_X\text{,}\) the middle-left column contains coefficients of \(V_Y\text{,}\) the middle-right column contains coefficients of \(V_{OUT,1}\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 1.25 \amp -0.25 \amp -0.5 \amp 0.25 \\ 0.83 \amp 0 \amp -0.33 \amp 0 \\ 0 \amp 0.5 \amp 0.33 \amp 0 \end{bmatrix} \end{equation*}
🔗
The matrix is shown in reduced row echelon form below.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0.6\\ 0 \amp 1 \amp 0 \amp 1.0\\ 0 \amp 0 \amp 1 \amp 1.5 \end{bmatrix} \end{equation*}
🔗
\(V_{OUT,1}\) is therefore equal to 1.5 V. The source gain from source \(V_1\) can now be calculated.
🔗
\begin{align*} G_1 \amp= \frac{1.5~\textrm{V}}{0.5~\textrm{V}}\\ \amp= 3 \end{align*}
🔗
Deactivate source \(V_1\) and draw the circuit diagram to calculate \(G_2\) and \(V_{OUT,2}\text{.}\)
🔗
Perform KCL at the inverting input of the left op-amp. This node voltage will be referred to as \(V_X\text{.}\) The left op-amp’s output voltage will be referred to as \(V_Y\text{.}\)
🔗
\begin{align*} \frac{0-V_X}{2~\textrm{k}\Omega} \amp= \frac{V_X-V_Y}{4~\textrm{k}\Omega} + \frac{V_X-V_{OUT}}{2~\textrm{k}\Omega}\\ -0.5V_X \amp= 0.25V_X - 0.25V_Y + 0.5V_X - 0.5V_{OUT,2}\\ 0 \amp= 1.25V_X - 0.25V_Y - 0.5V_{OUT,2} \end{align*}
🔗
Perform KCL at the non-inverting input of the left op-amp.
🔗
\begin{align*} \frac{0-V_X}{2~\textrm{k}\Omega} \amp= \frac{V_X-V_{OUT,2}}{3~\textrm{k}\Omega}\\ -0.5V_X \amp= 0.33V_X - 0.33V_{OUT,2}\\ 0 \amp= 0.83V_X - 0.33V_{OUT,2} \end{align*}
🔗
Perform KCL at the inverting input of the right op-amp.
🔗
\begin{align*} \frac{V_Y-1~\textrm{V}}{2~\textrm{k}\Omega} \amp= \frac{1~\textrm{V}-V_{OUT}}{3~\textrm{k}\Omega}\\ 0.5V_Y - 0.5~\textrm{V} \amp= 0.33~\textrm{V} - 0.33V_{OUT,2}\\ 0.83~\textrm{V} \amp= 0.5V_Y + 0.33V_{OUT,2} \end{align*}
🔗
The three equations can be expressed in a matrix. The left column contains coefficients of \(V_X\text{,}\) the middle-left column contains coefficients of \(V_Y\text{,}\) the middle-right column contains coefficients of \(V_{OUT,2}\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 1.25 \amp -0.25 \amp -0.5 \amp 0 \\ 0.83 \amp 0 \amp -0.33 \amp 0 \\ 0 \amp 0.5 \amp 0.33 \amp 0.83 \end{bmatrix} \end{equation*}
🔗
The matrix is shown in reduced row echelon form below.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp 1.0\\ 0 \amp 1 \amp 0 \amp 0.0\\ 0 \amp 0 \amp 1 \amp 2.5 \end{bmatrix} \end{equation*}
🔗
\(V_{OUT,2}\) is therefore equal to 2.5 V. The source gain from source \(V_2\) can now be calculated.
🔗
\begin{align*} G_2 \amp= \frac{2.5~\textrm{V}}{1~\textrm{V}}\\ \amp= 2.5 \end{align*}
🔗
Use superposition to calculate \(V_{OUT}\text{.}\)
🔗
\begin{align*} V_{OUT} \amp= V_{OUT,1} + V_{OUT,2}\\ \amp= 1.5~\textrm{V} + 2.5~\textrm{V}\\ \amp= 4~\textrm{V} \end{align*}
