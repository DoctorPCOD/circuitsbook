Exercise 20.

Calculate an expression for \(v(t)\) and \(i(t)\) given the circuit shown in Figure 5.8.56. The switch is open for a very long time before closing at a time of zero seconds. The circuit parameters are: \(I_S = 360~\mu\textrm{A}\text{,}\) \(C = 14~\mu\textrm{F}\text{,}\) \(k = 2\text{,}\) \(R_1 = 5~\textrm{k}\Omega\text{,}\) \(R_2 = 10~\textrm{k}\Omega\text{,}\) \(R_3 = 2~\textrm{k}\Omega\text{,}\) and \(R_4 = 3~\textrm{k}\Omega\text{.}\)
🔗
Answer.
\begin{align*} v(t) \amp= -0.348~\textrm{V}~\left[1-\textrm{e}^{-73.8t}\right]~u(t)\\ i(t) \amp= -0.36~\textrm{mA}~\textrm{e}^{-73.8t}~u(t) \end{align*}
🔗
🔗
Solution.
The initial voltage drop over the capacitor will be zero because it is disconnected from any sources. Analyze the circuit in the final steady-state condition to calculate \(v(\infty)\text{.}\)
🔗
Resistors \(R_3\) and \(R_4\) are connected in parallel. The equivalent resistance will be denoted on the circuit diagram symbolically as \(R_X\text{.}\)
🔗
\begin{align*} R_X \amp= \frac{(2~\textrm{k}\Omega)(3~\textrm{k}\Omega)}{2~\textrm{k}\Omega+3~\textrm{k}\Omega}\\ \amp= 1.2~\textrm{k}\Omega \end{align*}
🔗
Source transformation will not be helpful as it will modify the position of \(V_X\) in the circuit. Superposition is not valid as there is only one independent source. Mesh analysis will therefore be the simplest method for solving this circuit. The circuit is re-drawn below to depict the two mesh currents.
🔗
Units of kΩ, mA, and V will be used in deriving each mesh analysis equation. Mesh current \(I_A\) is equal to source current \(I_S\text{.}\) The second equation can be derived by performing KVL around the right-hand mesh. The third equation relates the controlling voltage \(V_X\) to each mesh current.
🔗
\begin{align*} I_A \amp= 0.360\\ 5(I_B - I_A) + 2V_X + 1.2I_B + 10I_B \amp= 0\\ 5(I_A - I_B) \amp= V_X \end{align*}
🔗
The three equations can be expressed in a matrix. The left column contains coefficients of \(I_A\text{,}\) the middle-left column contains coefficients of \(I_B\text{,}\) the middle-right column contains coefficients of \(V_X\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0.360\\ -5 \amp 16.2 \amp 2 \amp 0\\ 5 \amp -5 \amp -1 \amp 0 \end{bmatrix} \end{equation*}
🔗
The matrix is shown in reduced row echelon form below.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0.360\\ 0 \amp 1 \amp 0 \amp -0.290\\ 0 \amp 0 \amp 1 \amp 3.25 \end{bmatrix} \end{equation*}
🔗
Use Ohm’s law over \(R_X\) to calculate \(v(\infty)\text{.}\) The mesh current \(I_B\) is equal to the branch current through that resistor.
🔗
\begin{align*} v(\infty) \amp= (-0.290~\textrm{mA})(1.2~\textrm{k}\Omega)\\ \amp= -0.348~\textrm{V} \end{align*}
🔗
There are two methods for deriving \(\tau\text{.}\) The first is deriving a Thévenin equivalent circuit seen by the capacitor. This circuit is shown below.
🔗
The Thévenin equivalent voltage is equal to \(v(\infty)\text{.}\) Thévenin equivalent resistance cannot be directly calculated due to the presence of a dependent source. Short nodes a and b to calculate the short-circuit current. Note that when nodes a and b are shorted, resistor \(R_X\) is shorted out of the circuit. Mesh analysis is the preferred method to solve for this quantity for the same reasons as above. The short-circuit current will be equal to the mesh current through the right-hand mesh.
🔗
Units of kΩ, mA, and V will be used in deriving each mesh analysis equation. Mesh current \(I_A\) is equal to source current \(I_S\text{.}\) The second equation can be derived by performing KVL around the right-hand mesh. The third equation relates the controlling voltage \(V_X\) to each mesh current.
🔗
\begin{align*} I_A \amp= 0.360\\ 5(I_B - I_A) + 2V_X + 10I_B \amp= 0\\ 5(I_A - I_B) \amp= V_X \end{align*}
🔗
The three equations can be expressed in a matrix. The left column contains coefficients of \(I_A\text{,}\) the middle-left column contains coefficients of \(I_B\text{,}\) the middle-right column contains coefficients of \(V_X\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0.360\\ -5 \amp 15 \amp 2 \amp 0\\ 5 \amp -5 \amp -1 \amp 0 \end{bmatrix} \end{equation*}
🔗
The matrix is shown in reduced row echelon form below.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0.360\\ 0 \amp 1 \amp 0 \amp -0.360\\ 0 \amp 0 \amp 1 \amp 3.60 \end{bmatrix} \end{equation*}
🔗
The short-circuit current is equal to -0.36 mA. Use Ohm’s law to calculate the Thévenin equivalent resistance. (The “smell test” for this calculation is that both the Thévenin equivalent voltage and short-circuit current values are negative, so the Thévenin equivalent resistance will be positive.) This is equal to the equivalent resistance as seen by the capacitor.
🔗
\begin{align*} R_{TH} \amp= \frac{V_{TH}}{I_{SC}}\\ \amp= \frac{-0.348~\textrm{V}}{-0.36~\textrm{mA}}\\ \amp= 0.967~\textrm{k}\Omega \end{align*}
🔗
Use (5.7.6) to calculate \(\tau\text{.}\)
🔗
\begin{align*} \tau \amp= RC\\ \amp= (967~\Omega)(14 \times 10^{-6}~\textrm{F})\\ \amp= 0.014~\textrm{s} \end{align*}
🔗
The second method to calculating \(\tau\) is to derive a differential equation for the circuit. This will be done in symbolic form using the diagram shown below. Numerical quantities for each symbolic value will not be plugged in until the very last step of the derivation.
🔗
Use KCL to relate each of the branch currents to the source current.
🔗
\begin{align} I_S \amp= I_1 + I_2\tag{5.8.1}\\ I_2 \amp= I_3 + i(t)\tag{5.8.2}\\ I_S \amp= I_1 + I_3 + i(t)\tag{5.8.3} \end{align}
🔗
Use Ohm’s law on each branch to derive the differential equation in terms of \(v(t)\text{.}\)
🔗
\begin{align} I_1 \amp= \frac{V_X}{R_1}\tag{5.8.4}\\ I_3 \amp= \frac{v(t)}{R_X}\tag{5.8.5}\\ i(t) \amp= C \frac{dv(t)}{dt}\tag{5.8.6} \end{align}
🔗
Plug (5.8.4), (5.8.5), and (5.8.6) into (5.8.3).
🔗
\begin{equation} I_S = \frac{V_X}{R_1} + \frac{v(t)}{R_X} + C \frac{dv(t)}{dt}\tag{5.8.7} \end{equation}
🔗
Use KVL around the center mesh to calculate \(V_X\) in terms of \(v(t)\text{.}\) Note that the current through \(R_2\) will be equal to \(I_2\text{.}\) (If you are not convinced of this, consider the relationship between branch and mesh currents in circuit elements in a mesh not shared by other meshes.)
🔗
\begin{equation} V_X = kV_X + v(t) + I_2R_2\tag{5.8.8} \end{equation}
🔗
Plug (5.8.2) into (5.8.8) and solve for \(V_X\text{.}\)
🔗
\begin{align} V_X \amp= kV_X + v(t) + R_2(I_3 + i(t))\tag{5.8.9}\\ \amp= kV_X + v(t) + R_2(\frac{v(t)}{R_X} + C \frac{dv(t)}{dt})\tag{5.8.10}\\ (1-k)V_X \amp= v(t) + \frac{R_2}{R_X}v(t) + R_2C\frac{dv(t)}{dt}\tag{5.8.11}\\ V_X \amp= \left(\frac{1+\frac{R_2}{R_x}}{1-k}\right)v(t) + \left(\frac{R_2C}{1-k}\right)\frac{dv(t)}{dt}\tag{5.8.12} \end{align}
🔗
Plug (5.8.12) into (5.8.7) and put into standard form. The last equation contains numerical values. Base units were used to express each quantity.
🔗
\begin{align*} I_S \amp= \frac{1}{R_1}\left[v(t)\left(\frac{1+\frac{R_2}{R_x}}{1-k}\right) + \frac{CR_2}{1-k}\frac{dv(t)}{dt}\right] + \frac{v(t)}{R_X} + C\frac{dv(t)}{dt}\\ \amp= v(t)\left[\frac{1+\frac{R_2}{R_X}}{R_1(1-k)} + \frac{1}{R_X}\right] + \frac{dv(t)}{dt}\left[C + \frac{CR_2}{R_1(1-k)}\right]\\ \amp= v(t)\left[\frac{1+\frac{R_2}{R_X}}{R_1(1-k)} + \frac{1}{R_X}\right] + \frac{dv(t)}{dt}\left[\frac{C(R_1(1-k)+R_2)}{R_1(1-k)}\right]\\ \frac{I_SR_1(1-k)}{C(R_1(1-k)+R_2)} \amp= \frac{dv(t)}{dt} + \left[\frac{1+\frac{R_2}{R_X}}{C(R_1(1-k)+R_2)} + \frac{R_1(1-k)}{R_XC(R_1(1-k)+R_2)}\right]v(t)\\ -25.71 \amp= \frac{dv(t)}{dt} + 73.8v(t) \end{align*}
🔗
Calculate \(\tau\) by taking the reciprocal of \(a_0\text{.}\)
🔗
\begin{align*} \tau \amp= \frac{1}{73.8~\textrm{s}^{-1}}\\ \amp= 0.014~\textrm{s} \end{align*}
🔗
This value agrees with the value calculated using the Thévenin equivalence method, as expected.
🔗
Use (5.7.12) to derive an equation for \(v(t)\text{.}\)
🔗
\begin{align*} v(t) \amp= v(\infty)\left[1-\textrm{e}^{-\frac{t}{\tau}}\right]u(t)\\ \amp= -0.348~\textrm{V}~\left[1-\textrm{e}^{-73.8t}\right]~u(t) \end{align*}
🔗
Use (5.7.13) to derive an equation for \(i(t)\text{.}\) Recall that the equivalent resistance as seen by the capacitor is 0.967 kΩ. (If you did not solve for \(\tau\) using the Thévenin equivalence method, use (5.7.6) with the value of \(\tau\) derived from the differential equation and solve for \(R\text{.}\))
🔗
\begin{align*} i(t) \amp= \frac{v(\infty)}{R}~\textrm{e}^{-\frac{t}{\tau}}~u(t)\\ \amp= \frac{-0.348~\textrm{V}}{0.967~\textrm{k}\Omega}~\textrm{e}^{-73.8t}~u(t)\\ \amp= -0.36~\textrm{mA}~\textrm{e}^{-73.8t}~u(t) \end{align*}
