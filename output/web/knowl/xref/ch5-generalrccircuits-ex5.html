Exercise 25.

Derive equations for \(v(t)\) and \(i(t)\) for the circuit shown in Figure 5.8.93. The switch is open for a very long time before closing at a time of zero seconds. The circuit parameters are: \(V_{S1} = 8~\textrm{V}\text{,}\) \(V_{S2} = 20~\textrm{V}\text{,}\) \(k_i = 4\text{,}\) \(R_1 = 20~\Omega\text{,}\) \(R_2 = 60~\Omega\text{,}\) \(R_3 = 40~\Omega\text{,}\) and \(C = 2~\textrm{mF}\text{.}\)
🔗
Answer.
\begin{align*} v(t) \amp= \left[5.68~\textrm{V} - 2.68~\textrm{V}~\textrm{e}^{-79.2t} \right]~u(t) + 3~\textrm{V}~u(-t)\\ i(t) \amp= 0.425~\textrm{A}~\textrm{e}^{-79.2t}~u(t) \end{align*}
🔗
🔗
Solution.
First, analyze the circuit in the initial steady-state condition to calculate \(v(0)\text{.}\) The capacitor can be treated as an open circuit. Source \(V_{S2}\) is disconnected from the circuit at this time.
🔗
KCL will be used at the node connecting \(R_1\text{,}\) \(R_2\text{,}\) and the CCCS. Source transformation will not meaningfully reduce the difficulty of solving this circuit (this is because branch current \(I_X\) through resistor \(R_2\) can’t be eliminated, so resistor \(R_2\) could not be combined in parallel with \(R_1\) after a source transformation). Superposition cannot be used because there is only one independent source. Mesh analysis could be used, but requires more steps to solve.
🔗
The KCL equation is solved below for \(v(0)\text{.}\) Note that due to Ohm’s law, \(I_X = v(0) / R_2\text{.}\)
🔗
\begin{align*} \frac{V_{S1} - v(0)}{R_1} \amp= \frac{v(0)}{R_2} + k_iI_X\\ \amp= \frac{v(0)}{R_2} + k_i\frac{v(0)}{R_2}\\ \frac{V_{S1}}{R_1} \amp= \frac{v(0)}{R_1} + \frac{(1+k_i)v(0)}{R_2}\\ \frac{R_2V_{S1}}{R_1R_2} \amp= \frac{R_2v(0)}{R_1R_2} + \frac{R_1(1+k_i)v(0)}{R_1R_2}\\ R_2V_{S1} \amp= R_2v(0) + R_1(1+k_i)v(0)\\ \amp= v(0) \left(R_2 + R_1(1+k_i)\right)\\ v(0) \amp= \frac{V_{S1}R_2}{R_2+(1+k_i)R_1}\\ \amp= 3~\textrm{V} \end{align*}
🔗
Next, analyze the circuit in the final steady-state condition. The capacitor will be treated as an open.
🔗
KCL is still the simplest method for solving this circuit. The KCL equation is solved below for \(v(\infty)\text{.}\) From Ohm’s law, we know that \(I_X = v(\infty)/R_2\text{.}\)
🔗
\begin{align*} \frac{V_{S1} - v(\infty)}{R_1} \amp= \frac{v(\infty)}{R_2} + k_iI_X + \frac{v(\infty) - V_{S2}}{R_3}\\ \amp= \frac{v(\infty)}{R_2} + k_i \frac{v(\infty)}{R_2} + \frac{v(\infty) - V_{S2}}{R_3}\\ \frac{V_{S1}}{R_1} + \frac{V_{S2}}{R_3} \amp= \frac{v(\infty)}{R_1} + \frac{(1+k_1)v(\infty)}{R_2} + \frac{v(\infty)}{R_3}\\ \frac{R_2R_3V_{S1}}{R_1R_2R_3} + \frac{R_1R_2V_{S2}}{R_1R_2R_3} \amp= \frac{R_2R_3v(\infty)}{R_1R_2R_3} + \frac{R_1R_3(1+k_1)v(\infty)}{R_1R_2R_3}\\ \amp+ \frac{R_1R_2v(\infty)}{R_1R_2R_3}\\ R_2R_3V_{S1} + R_1R_2V_{S2} \amp= R_2R_3v(\infty) + R_1R_3(1+k_1)v(\infty)\\ \amp+ R_1R_2v(\infty)\\ \amp= v(\infty)\left(R_2R_3 + R_1R_3(1+k_1) + R_1R_2\right)\\ v(\infty) \amp= \frac{R_2R_3V_{S1} + R_1R_2V_{S2}}{R_2R_3 + R_1R_3(1+k_1) + R_1R_2}\\ \amp= 5.6842~\textrm{V} \end{align*}
🔗
The first possible way to calculate \(\tau\) is to derive a Thévenin equivalent circuit as seen by the capacitor.
🔗
The open-circuit voltage is equal to \(v(\infty)\text{.}\) Short nodes a and b to calculate the short-circuit current.
🔗
Resistor \(R_2\) is shorted out and does not contribute to the circuit. This means that branch current \(I_X\) will be equal to zero, and the CCCS will not contribute any current to the circuit. The reduced equivalent circuit is depicted below.
🔗
Source transformation is slightly easier than superposition in solving this circuit, although both methods can be used. Feel free to try this circuit using superposition and verify that you obtain the same result. Convert both voltage sources into current sources. The circuit is redrawn below.
🔗
Both resistors are shorted out of the circuit. The reduced circuit diagram is shown below.
🔗
The short-circuit current is therefore equal to the sum of both current sources.
🔗
\begin{align*} I_{SC} \amp= \frac{V_{S1}}{R_1} + \frac{V_{S2}}{R_3}\\ \amp= \frac{8~\textrm{V}}{20~\Omega} + \frac{20~\textrm{V}}{40~\Omega}\\ \amp= 0.4~\textrm{A} + 0.5~\textrm{A}\\ \amp= 0.9~\textrm{A} \end{align*}
🔗
Use Ohm’s law to calculate the Thévenin equivalent resistance. This is equal to the equivalent resistance as seen by the capacitor.
🔗
\begin{align*} R_{TH} \amp= \frac{5.6842~\textrm{V}}{0.9~\textrm{A}}\\ \amp= 6.3158~\Omega \end{align*}
🔗
Use (5.7.5) to calculate \(\tau\text{.}\)
🔗
\begin{align*} \tau \amp= (6.31~\Omega)(2 \times 10^{-3}~\textrm{F})\\ \amp= 0.0126~\textrm{s} \end{align*}
🔗
The second approach to calculating \(\tau\) is to derive a differential equation for the circuit. Symbolic values will be used in this analysis until the standard form of the differential equation has been derived. Analyze the circuit at \(t = 0^+\text{.}\)
🔗
Source transformation will be helpful in deriving the differential equation. It makes KCL very simple to perform as all branches will be in parallel with each other and share a common voltage.
🔗
Combine all three current sources into a single source. \(R_1\) and \(R_3\) can be combined in parallel and will be depicted as \(R_X\) in the diagram below. Resistor \(R_2\) cannot be combined as it has a branch current \(I_X\) that is needed to derive the differential equation.
🔗
Use KCL to relate the current through all four branches.
🔗
\begin{equation} \frac{V_{S1}}{R_1} + \frac{V_{S2}}{R_3} - k_iI_X = \frac{v(t)}{R_X} + \frac{v(t)}{R_2} + C\frac{dv(t)}{dt}\tag{5.8.12} \end{equation}
🔗
Use Ohm’s law to derive an equation for \(I_X\) in terms of \(v(t)\text{.}\)
🔗
\begin{equation} I_X = \frac{v(t)}{R_2}\tag{5.8.13} \end{equation}
🔗
Plug (5.8.13) into (5.8.12). Then, solve for the differential equation in standard form. The last line shows the equation in numerical form; base units were used to express each quantity.
🔗
\begin{align*} \frac{V_{S1}}{R_1} + \frac{V_{S2}}{R_3} - k_i\left(\frac{v(t)}{R_2}\right) \amp= \frac{v(t)}{R_X} + \frac{v(t)}{R_2} + C\frac{dv(t)}{dt}\\ \frac{V_{S1}}{R_1} + \frac{V_{S2}}{R_3} \amp= k_i\left(\frac{v(t)}{R_2}\right) + \frac{v(t)}{R_X} + \frac{v(t)}{R_2} + C\frac{dv(t)}{dt}\\ \amp= \left(\frac{1}{R_X} + \frac{k_i}{R_2} + \frac{1}{R_2}\right)v(t) + C\frac{dv(t)}{dt}\\ \frac{V_{S1}}{CR_1} + \frac{V_{S2}}{CR_3} \amp= \frac{dv(t)}{dt} + \left(\frac{1}{CR_X} + \frac{k_i}{CR_2} + \frac{1}{CR_2}\right)v(t)\\ 450 \amp= \frac{dv(t)}{dt} + 79.16v(t) \end{align*}
🔗
Calculate \(\tau\) by taking the reciprocal of \(a_0\text{.}\)
🔗
\begin{align*} \tau \amp= \frac{1}{79.16~\textrm{s}^{-1}}\\ \amp= 0.0126~\textrm{s} \end{align*}
🔗
This value agrees with the value calculated using the Thévenin equivalence method, as expected.
🔗
Use (5.7.12) to derive an equation for \(v(t)\text{.}\)
🔗
\begin{equation*} v(t) = \left[5.68~\textrm{V} - 2.68~\textrm{V}~\textrm{e}^{-79.2t} \right]~u(t) + 3~\textrm{V}~u(-t) \end{equation*}
🔗
Use (5.7.13) to derive an equation for \(i(t)\text{.}\) Recall that the equivalent resistance as seen by the capacitor is 6.31 Ω. (If you did not solve for \(\tau\) using the Thévenin equivalence method, use (5.7.5) with the value of \(\tau\) derived from the differential equation and solve for \(R\text{.}\))
🔗
\begin{align*} i(t) \amp= \frac{2.68~\textrm{V}}{6.31~\Omega} \textrm{e}^{-79.2t}~u(t)\\ \amp= 0.425~\textrm{A}~\textrm{e}^{-79.2t}~u(t) \end{align*}
