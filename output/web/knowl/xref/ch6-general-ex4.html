Exercise 24.

Derive equations for \(i(t)\) and \(v(t)\) given the circuit shown in Figure 6.6.102. The switch has been open for a very long time before closing at a time of zero seconds. The parameter values are \(V_{S1} = 5~\textrm{V}\text{,}\) \(V_{S2} = 10~\textrm{V}\text{,}\) \(R_1 = 20~\Omega\text{,}\) \(R_2 = 20~\Omega\text{,}\) \(R_3 = 20~\Omega\text{,}\) \(L = 500~\textrm{mH}\text{,}\) and \(g_m = 0.5~\textrm{A/V}\text{.}\)
🔗
Answer.
\begin{align*} i(t) \amp= \left(0.229~\textrm{A} + 0.294~\textrm{A}~\textrm{e}^{-43.6t}\right)~u(t) + 0.423~\textrm{A}~u(-t)\\ v(t) \amp= -4.23~\textrm{V}~\textrm{e}^{-43.6t}~u(t) \end{align*}
🔗
🔗
Solution.
Analyze the circuit in its initial steady-state condition. The inductor can be replaced by a short.
🔗
It is not beneficial to combine resistors \(R_2\) and \(R_3\) because the voltage drop over \(R_2\) dictates the value of the voltage-controlled current source. For this reason, it’s also not advantageous to perform source transformation to solve the circuit. KCL and KVL can be used to obtain two equations in terms of two unknowns (\(i(0)\) and \(v_X(0)\)). First, perform KCL at the node connecting the three branches of the circuit. (Note that the voltage dropped over \(R_1\) is equal to \(R_1i(0)\text{.}\))
🔗
\begin{equation*} \frac{V_{S2} - R_1i(0)}{R_2 + R_3} = g_mv_X(0) + i(0) \end{equation*}
🔗
Perform KVL around the entire outer loop of the circuit. (Note that the current through resistors \(R_2\) and \(R_3\) is equal to \(v_X(0) / R_2\text{.}\))
🔗
\begin{equation*} V_{S2} = -\frac{v_X(0)}{R_2}(R_2 + R_3) + R_1i(0) \end{equation*}
🔗
Plug numerical quantities into each equation. The units used for each equation below are V, A, and Ω and are not explicitly shown.
🔗
\begin{gather*} \frac{10-20i(0)}{40} = 0.5v_X(0) + i(0)\\ 10 = -\frac{40}{20}v_X(0) + 20i(0) \end{gather*}
🔗
The two equations can be expressed in a matrix. The left column contains coefficients of \(i(0)\text{,}\) the middle column contains coefficients of \(v_X(0)\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 1.5 \amp 0.5 \amp 0.25 \\ 20 \amp -2 \amp 10 \end{bmatrix} \end{equation*}
🔗
The matrix is shown in reduced row echelon form below.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0.4231\\ 0 \amp 1 \amp -0.7692\\ \end{bmatrix} \end{equation*}
🔗
This means that \(i(0) = 0.423~\textrm{A}\text{.}\)
🔗
Analyze the circuit in the final steady-state condition to calculate \(i(\infty)\text{.}\) The inductor can be replaced by a short.
🔗
For the same reasons as above, source transformation is not advantageous in solving this circuit. KCL and KVL can again be used instead. Perform KCL at the node connecting \(R_1\text{,}\) \(R_2\text{,}\) and the voltage-controlled current source. (Note that the voltage dropped over \(R_1\) is equal to \(R_1i(\infty)\text{.}\))
🔗
\begin{equation*} \frac{V_{S1} - R_1i(\infty)}{R_2} = g_mv_X(\infty) + i(\infty) \end{equation*}
🔗
Perform KVL around the loop containing \(V_{S1}\) and resistors \(R_1\) and \(R_2\text{.}\)
🔗
\begin{equation*} V_{S1} = -v_X(\infty) + R_1i(\infty) \end{equation*}
🔗
Plug numerical quantities into each equation. The units used for each equation below are V, A, and Ω and are not explicitly shown.
🔗
\begin{gather*} \frac{5-20i(\infty)}{20} = 0.5v_X(\infty) + i(\infty)\\ 5 = -v_X(\infty) + 20i(\infty) \end{gather*}
🔗
The two equations can be expressed in a matrix. The left column contains coefficients of \(i(\infty)\text{,}\) the middle column contains coefficients of \(v_X(\infty)\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 2 \amp 0.5 \amp 0.25 \\ 20 \amp -1 \amp 5 \end{bmatrix} \end{equation*}
🔗
The matrix is shown in reduced row echelon form below.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0.2292\\ 0 \amp 1 \amp -0.4167\\ \end{bmatrix} \end{equation*}
🔗
This means that \(i(\infty) = 0.229~\textrm{A}\text{.}\)
🔗
To calculate the equivalent resistance as seen by the inductor, two methods can be used. The first is to derive the Thévenin equivalent circuit as seen by the inductor.
🔗
Mesh analysis is likely the most effective method for solving this circuit. The circuit is re-drawn below to show the two mesh currents.
🔗
Relate branch current \(I_A\) to the value of the current source contained entirely within that single mesh.
🔗
\begin{equation*} I_A = -g_mv_X(t) \end{equation*}
🔗
Perform KVL around the right-hand loop.
🔗
\begin{equation*} -V_{S1} + R_3I_B + V_{S2} = 0 \end{equation*}
🔗
Derive an equation relating the controlling voltage to the mesh currents.
🔗
\begin{equation*} v_X(t) = I_AR_2 \end{equation*}
🔗
Plug numerical quantities into each of the equations. The units used for each equation below are V, A, and Ω and are not explicitly shown.
🔗
\begin{align*} I_A \amp= -0.5v_X(t)\\ -5 + 20I_B + 10 \amp= 0\\ v_X(t) \amp= 20I_A \end{align*}
🔗
The three equations can be expressed in a matrix. The left column contains coefficients of \(I_A\text{,}\) the middle-left column contains coefficients of \(I_B\text{,}\) the middle-right column contains coefficients of \(v_X(t)\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0.5 \amp 0\\ 0 \amp 20 \amp 0 \amp -5\\ -20 \amp 0 \amp 1 \amp 0 \end{bmatrix} \end{equation*}
🔗
The matrix is shown in reduced row echelon form below.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0\\ 0 \amp 1 \amp 0 \amp -0.25\\ 0 \amp 0 \amp 1 \amp 0 \end{bmatrix} \end{equation*}
🔗
Use KVL around the entire outer loop of the circuit to calculate the open-circuit voltage. (Note that resistor \(R_1\) does not contribute to the open-circuit voltage, as it has no current flowing through it.)
🔗
\begin{align*} V_{OC} \amp= v_X(t) + I_BR_3 + V_{S2}\\ \amp= 0 + (20~\Omega)(-0.25~\textrm{A}) + 10~\textrm{V}\\ \amp= 5~\textrm{V} \end{align*}
🔗
Short the two terminals to derive the short-circuit current.
🔗
Again, mesh analysis is the most direct method for solving this circuit. The mesh currents are shown below. (Note that some component values have been hidden so they don’t overlap with mesh current labels.)
🔗
Relate the voltage-controlled current source to mesh currents \(I_A\) and \(I_B\text{.}\)
🔗
\begin{equation*} g_mv_X(t) = I_A - I_B \end{equation*}
🔗
Perform KVL around the supermesh consisting of meshes A and B.
🔗
\begin{equation*} R_2I_B + V_{S1} + R_1I_A = 0 \end{equation*}
🔗
Perform KVL around the right-hand mesh.
🔗
\begin{equation*} -V_{S1} + R_3I_C + V_{S2} = 0 \end{equation*}
🔗
Derive an equation relating the controlling voltage to the mesh currents.
🔗
\begin{equation*} v_X(t) = R_2I_B \end{equation*}
🔗
Plug numerical quantities into each of the equations. The units used for each equation below are V, A, and Ω and are not explicitly shown.
🔗
\begin{align*} 0.5v_X(t) \amp= I_A - I_B\\ 20I_B + 5 + 20I_A \amp= 0\\ -5 + 20I_C + 10 \amp= 0\\ v_X(t) \amp= 20I_B \end{align*}
🔗
The four equations can be expressed in a matrix. The left column contains coefficients of \(I_A\text{,}\) the next column contains coefficients of \(I_B\text{,}\) the next column contains coefficients of \(I_C\text{,}\) the next column contains coefficients of \(v_X(t)\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp -1 \amp 0 \amp -0.5 \amp 0\\ 20 \amp 20 \amp 0 \amp 0 \amp -5\\ 0 \amp 0 \amp 20 \amp 0 \amp -5\\ 0 \amp 20 \amp 0 \amp -1 \amp 0 \end{bmatrix} \end{equation*}
🔗
The matrix is shown in reduced row echelon form below.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0 \amp -0.2292\\ 0 \amp 1 \amp 0 \amp 0 \amp -0.0208\\ 0 \amp 0 \amp 1 \amp 0 \amp -0.25\\ 0 \amp 0 \amp 0 \amp 1 \amp -0.4167 \end{bmatrix} \end{equation*}
🔗
The short-circuit current is equal to \(-I_A\text{,}\) which is 0.229 A. Use Ohm’s law to calculate the Thévenin equivalent resistance.
🔗
\begin{align*} R_{TH} \amp= \frac{5~\textrm{V}}{0.2292~\textrm{A}}\\ \amp= 21.8182~\Omega \end{align*}
🔗
Use (6.5.4) to calculate \(\tau\text{.}\)
🔗
\begin{align*} \tau \amp= \frac{0.5~\textrm{H}}{21.8182~\Omega}\\ \amp= 0.0229~\textrm{s} \end{align*}
🔗
The second method for solving the circuit is to derive the differential equation.
🔗
Use KCL at the node connecting \(R_2\text{,}\) \(L\text{,}\) and the voltage-controlled current source.
🔗
\begin{align} \frac{v_X(t)}{R_2} + g_mv_X(t) + i(t) \amp= 0\tag{6.6.10}\\ \left(\frac{1}{R_2}+g_m\right)v_X(t) + i(t) \amp= 0\tag{6.6.11} \end{align}
🔗
Use KVL around the loop consisting of \(V_{S1}\text{,}\) \(R_2\text{,}\) \(L\text{,}\) and \(R_1\) to derive an equation for \(v_X(t).\) (Note that the voltage dropped over \(R_1\) is equal to \(R_1i(t)\text{.}\))
🔗
\begin{align} V_{S1} \amp= -v_X(t) + L\frac{di(t)}{dt} + R_1i(t)\tag{6.6.12}\\ v_X(t) \amp= L\frac{di(t)}{dt} + R_1i(t) - V_{S1}\tag{6.6.13} \end{align}
🔗
Plug (6.6.13) into (6.6.11) and reduce to standard form.
🔗
\begin{align*} \left(\frac{1}{R_2}+g_m\right)\left(L\frac{di(t)}{dt} + R_1i(t) - V_{S1}\right) + i(t) \amp= 0\\ \left(\frac{L}{R_2} + Lg_m\right)\frac{di(t)}{dt} + \left(\frac{R_1}{R_2} + R_1g_m + 1\right) i(t) - \left(\frac{V_{S1}}{R_2} + V_{S1}g_m\right) \amp= 0\\ \left(\frac{L}{R_2} + Lg_m\right)\frac{di(t)}{dt} + \left(\frac{R_1}{R_2} + R_1g_m + 1\right) i(t) \amp= \left(\frac{V_{S1}}{R_2} + V_{S1}g_m\right)\\ \frac{di(t)}{dt} + \frac{\left(\frac{R_1}{R_2} + R_1g_m + 1\right)}{\left(\frac{L}{R_2} + Lg_m\right)} i(t) \amp= \frac{\left(\frac{V_{S1}}{R_2} + V_{S1}g_m\right)}{\left(\frac{L}{R_2} + Lg_m\right)} \end{align*}
🔗
Plug in numerical quantities, using base units for each value.
🔗
\begin{equation*} \frac{di(t)}{dt} + 43.64i(t) = 10 \end{equation*}
🔗
This value agrees with the value calculated using the Thévenin equivalence method, as expected.
🔗
Use (6.5.13) to derive an equation for \(i(t)\text{.}\)
🔗
\begin{equation*} i(t) = \left(0.229~\textrm{A} + 0.194~\textrm{A}~\textrm{e}^{-43.6t}\right)~u(t) + 0.423~\textrm{A}~u(-t) \end{equation*}
🔗
Use (6.5.14) to derive an equation for \(v(t)\text{.}\) Recall that the equivalent resistance as seen by the capacitor is 21.8182 Ω. (If you did not solve for \(\tau\) using the Thévenin equivalence method, use (6.5.4) with the value of \(\tau\) derived from the differential equation and solve for \(R\text{.}\))
🔗
\begin{equation*} v(t) = -4.23~\textrm{V}~\textrm{e}^{-43.6t}~u(t) \end{equation*}
