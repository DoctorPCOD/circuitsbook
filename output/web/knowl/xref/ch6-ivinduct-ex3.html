Exercise 9.

A 50 mH inductor has current as shown in Figure 6.6.29. Derive the piecewise functions for \(i(t)\text{,}\) \(v(t)\text{,}\) and \(p(t)\text{.}\) Assume that current is zero for all time before 0 ms.
🔗
Answer.
\begin{align*} i(t) \amp= \begin{cases} 2000~\textrm{mA/s}~t \amp \text{if } 0~\textrm{ms} \leq t \lt 5~\textrm{ms}\\ -4000~\textrm{mA/s}~t + 30~\textrm{mA} \amp \text{if } 5~\textrm{ms} \leq t \lt 7.5~\textrm{ms}\\ 0 \amp \text{else} \end{cases}\\ v(t) \amp= \begin{cases} 0.1~\textrm{V} \amp \text{if } 0~\textrm{ms} \leq t \lt 5~\textrm{ms}\\ -0.2~\textrm{V} \amp \text{if } 5~\textrm{ms} \leq t \lt 7.5~\textrm{ms}\\ 0 \amp \text{else} \end{cases}\\ p(t) \amp= \begin{cases} 200~\textrm{mW/s}~t \amp \text{if } 0~\textrm{ms} \leq t \lt 5~\textrm{ms}\\ 800~\textrm{mW/s}~t - 6~\textrm{mW} \amp \text{if } 5~\textrm{ms} \leq t \lt 7.5~\textrm{ms}\\ 0 \amp \text{else} \end{cases} \end{align*}
🔗
🔗
Solution.
Between 0 ms and 5 ms, the current increases from 0 mA to 10 mA. This represents a slope of
🔗
\begin{equation*} \frac{10~\textrm{mA}-0~\textrm{mA}}{0.005~\textrm{s}-0~\textrm{s}} = 2000~\textrm{mA/s}\text{.} \end{equation*}
🔗
The function \(i(t)\) is therefore equal to \(2000~\textrm{mA/s}~t\) during this interval of time.
🔗
Use (6.3.1) to calculate the voltage during this time interval.
🔗
\begin{equation*} 0.05~\textrm{H}\frac{d}{dt}(2~\textrm{A/s}~t) = 0.05~\textrm{H}(2~\textrm{A/s}) = 0.1~\textrm{V} \end{equation*}
🔗
Use (2.4.4) to calculate the power consumed by the inductor during this time period.
🔗
\begin{equation*} (0.1~\textrm{V})(2000~\textrm{mA/s}~t) = 200~\textrm{mW/s}~t \end{equation*}
🔗
Between 5 ms and 7.5 ms, the current decreases from 10 mA to 0 mA. This represents a slope of
🔗
\begin{equation*} \frac{0~\textrm{mA}-10~\textrm{mA}}{0.075~\textrm{s}-0.005~\textrm{s}} = -4000~\textrm{mA/s}\text{.} \end{equation*}
🔗
If this function originated at zero, the y-intercept would be 10 mA, representing a function of \(-4000~\textrm{mA/s}~t + 10~\textrm{mA}\text{.}\) However, the function is shifted by 5 ms (or 0.005 s). The function \(i(t)\) is therefore equal to \(-4000~\textrm{mA/s}~(t-0.005)+10~\textrm{mA} = -4000~\textrm{mA/s}~t + 30~\textrm{mA}\) during this interval of time.
🔗
Use (6.3.1) to calculate the voltage during this time interval.
🔗
\begin{equation*} 0.05~\textrm{H}\frac{d}{dt}(-4~\textrm{A/s}~t + 0.03~\textrm{A}) = 0.05~\textrm{H}(-4~\textrm{A/s}) = -0.2~\textrm{V} \end{equation*}
🔗
Use (2.4.4) to calculate the power consumed by the inductor during this time period.
🔗
\begin{equation*} (-0.2~\textrm{V})(-4000~\textrm{mA/s}~t + 30~\textrm{mA}) = 800~\textrm{mW/s}~t - 6~\textrm{mW} \end{equation*}
