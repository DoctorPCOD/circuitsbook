Exercise 17.

Derive an equation for \(v(t)\) given the circuit shown in Figure 7.8.60. The switch is in position b for a very long time before moving to position a at a time of zero seconds. The component values are \(V_m = 16~\textrm{V}\text{,}\) \(a = 2~\textrm{rad/s}\text{,}\) \(V_S = 8~\textrm{V}\text{,}\) \(R = 10~\Omega\text{,}\) \(R_S = 20~\Omega\text{,}\) \(L = 500~\textrm{mH}\text{,}\) and \(C = 20~\textrm{mF}\text{.}\)
🔗
Answer.
\begin{equation*} v(t) = \left[25~\textrm{V}~\textrm{e}^{-2t} - 17~\textrm{V}~\textrm{e}^{-10t} - 120~\textrm{V/s}~t~\textrm{e}^{-10t}\right]~u(t) + 8~\textrm{V}~u(-t) \end{equation*}
🔗
🔗
Solution.
Analyze the circuit in its initial steady-state configuration to calculate the initial conditions. The inductor can be replaced by a short and the capacitor can be replaced by an open.
🔗
The initial voltage is equal to 8 V. Note that the initial value of the current through the inductor will be 0 A, due to the fact that the circuit is open. Both of these values are continuous with time.
🔗
Analyze the circuit at \(t = 0^+\) to derive the differential equation.
🔗
This is a series RLC circuit, so we should expect the characteristic equation to resemble what we derived in Section 7.3. Knowing that the current through the circuit is defined by (5.3.1), we can simply perform KVL around the entire circuit loop. Then, reduce until the differential equation is in standard form.
🔗
\begin{align*} V_m~\textrm{e}^{-at} \amp= RC\frac{dv(t)}{dt} + L\frac{d}{dt}\left(C \frac{dv(t)}{dt}\right) + v(t)\\ \amp= RC\frac{dv(t)}{dt} + LC\frac{d^2v(t)}{dt^2} + v(t)\\ \frac{V_m~\textrm{e}^{-at}}{LC} \amp= \frac{d^2v(t)}{dt^2} + \frac{R}{L}\frac{dv(t)}{dt} + \frac{1}{LC}v(t) \end{align*}
🔗
Plug in parameter values, using base units.
🔗
\begin{equation*} 1600~\textrm{e}^{-2t} = \frac{d^2v(t)}{dt^2} + 20\frac{dv(t)}{dt} + 100v(t) \end{equation*}
🔗
Use (7.2.1) to calculate the damping parameter and use (7.2.2) to calculate the resonant frequency.
🔗
\begin{align*} \alpha \amp= 10~\textrm{Np/s}\\ \omega_0 \amp= 10~\textrm{rad/s} \end{align*}
🔗
The circuit is critically damped.
🔗
The particular solution has a format of \(v_P(t) = K~\textrm{e}^{-at}\text{,}\) where \(a = 2\text{.}\) Plug this into the differential equation and solve to calculate \(K\text{.}\)
🔗
\begin{align*} 1600~\textrm{e}^{-2t} \amp= \frac{d}{dt^2}\left(K~\textrm{e}^{-2t}\right) + 20\frac{d}{dt}\left(K~\textrm{e}^{-2t}\right) + 100\left(K~\textrm{e}^{-2t}\right)\\ \amp= 4K~\textrm{e}^{-2t} + 20(-2)K~\textrm{e}^{-2t} + 100K~\textrm{e}^{-2t}\\ 1600 \amp= 4K - 40K + 100K\\ K \amp= 25~\textrm{V} \end{align*}
🔗
The equation for \(v(t)\) has the following form.
🔗
\begin{equation*} v(t) = \left[25~\textrm{V}~\textrm{e}^{-2t} + A_1~\textrm{e}^{-10t} + A_2t~\textrm{e}^{-10t}\right]~u(t) + 8~\textrm{V}~u(-t) \end{equation*}
🔗
Use \(v(0^+)\) and \(v'(0^+)\) to calculate \(A_1\) and \(A_2\text{.}\) The first derivative is defined by (7.3.8), which will be equal to zero.
🔗
\begin{align*} v(0^+) = 8~\textrm{V} \amp= 25~\textrm{V} + A_1\\ A_1 \amp= -17~\textrm{V}\\ v'(t) \amp= -50~\textrm{e}^{-2t} - 10A_1~\textrm{e}^{-10t} + \textrm{e}^{-10t}(A_2-10A_2t)\\ v'(0^+) = 0 \amp= -50 - 10A_1 + A_2\\ \amp= -50 - (10)(-17) + A_2\\ \amp= -50 + 170 + A_2\\ A_2 \amp= -120~\textrm{V/s} \end{align*}
🔗
Plug all of the values into the equation for \(v(t)\text{.}\)
🔗
\begin{equation*} v(t) = \left[25~\textrm{V}~\textrm{e}^{-2t} - 17~\textrm{V}~\textrm{e}^{-10t} - 120~\textrm{V/s}~t~\textrm{e}^{-10t}\right]~u(t) + 8~\textrm{V}~u(-t) \end{equation*}
