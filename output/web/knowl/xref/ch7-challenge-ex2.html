Exercise 18.

Derive an equation for \(v(t)\) given the circuit shown in Figure 7.8.63. The switch is open for a very long time before closing at a time of zero seconds. The circuit parameters are: \(V_{AC}(t) = 10~\textrm{V}~\sin(2\pi40t)\text{,}\) \(R_S = 10~\Omega\text{,}\) \(R = 10~\Omega\text{,}\) \(L = 0.5~\textrm{H}\text{,}\) and \(C = 2~\textrm{mF}\text{.}\)
🔗
Answer.
\begin{equation*} v(t) = \biggl[-0.080~\textrm{V}~\sin(2\pi40t) + \textrm{e}^{-5t}\left(0.644~\textrm{V}~\sin{31.2t}\right)\biggr]~u(t) \end{equation*}
🔗
🔗
Solution.
The initial value of \(v(t)\) will be zero due to the lack of any source in the initial steady-state condition. The initial current through the inductor will also be zero. Both of these values are continuous with time.
🔗
The voltage over the resistor \(v_X(t)\) may not be continuous with time. At \(t=0^+\text{,}\) the value of the source, \(V_{AC}(0)\text{,}\) will be equal to zero. (This is because \(\sin{0} = 0\text{.}\)) Therefore, \(v_X(0^+)\) will also be equal to zero.
🔗
Analyze the circuit at \(t=0^+\) to derive the differential equation.
🔗
Perform KCL at the node connecting \(R_S\text{,}\) \(R\text{,}\) and \(L\text{.}\) Combine like terms.
🔗
\begin{align} \frac{V_{AC}(t) - v_X(t)}{R_S} \amp= \frac{v_X(t)}{R} + C\frac{dv(t)}{dt}\tag{7.8.42}\\ \frac{V_{AC}(t)}{R_S} \amp= \frac{v_X(t)}{R_S} + \frac{v_X(t)}{R} + C\frac{dv(t)}{dt}\tag{7.8.43}\\ \amp= \left(\frac{1}{R_S} + \frac{1}{R}\right)v_X(t) + C\frac{dv(t)}{dt}\tag{7.8.44} \end{align}
🔗
Perform KVL around the right-hand loop of the circuit. Note that the current through the inductor is equal to \(C\frac{dv(t)}{dt}\text{.}\)
🔗
\begin{equation} v_X(t) = LC\frac{d^2v(t)}{dt^2} + v(t)\tag{7.8.45} \end{equation}
🔗
Plug (7.8.45) into (7.8.44) and simplify to standard form.
🔗
\begin{align*} \frac{V_{AC}(t)}{R_S} \amp= \left(\frac{1}{R_S} + \frac{1}{R}\right)\left(LC\frac{d^2v(t)}{dt^2} + v(t)\right)+ C\frac{dv(t)}{dt}\\ \amp= \frac{R+R_S}{RR_S}\left(LC\frac{d^2v(t)}{dt^2} + v(t)\right)+ C\frac{dv(t)}{dt}\\ \amp= \frac{(R+R_S)LC}{RR_S}\frac{d^2v(t)}{dt^2} + C\frac{dv(t)}{dt} + \frac{R+R_S}{RR_S}v(t)\\ \frac{V_{AC} R}{LC(R+R_S)} \amp= \frac{d^2v(t)}{dt^2} + \frac{RR_S}{L(R+R_S)}\frac{dv(t)}{dt} + \frac{1}{LC}v(t)\\ 5000 \sin{(2\pi 40 t)} \amp= \frac{d^2v(t)}{dt^2} + 10\frac{dv(t)}{dt} + 1000 \end{align*}
🔗
Use (7.2.1) to calculate the damping parameter, and use (7.2.2) to calculate the resonant frequency.
🔗
\begin{align*} \alpha \amp= 5~\textrm{Np/s}\\ \omega_0 \amp= 31.6228~\textrm{rad/s} \end{align*}
🔗
This circuit is underdamped. Use (7.2.5) to calculate the oscillation frequency of the circuit.
🔗
\begin{align*} \beta \amp= \sqrt{31.6228^2 - 5^2}\\ \amp= 31.225~\textrm{rad/s} \end{align*}
🔗
Use (7.8.44) to calculate \(v'(0^+)\text{.}\) Because \(v(0^+)\text{,}\) \(V_{AC}(0^+)\text{,}\) and \(v_X(0^+)\) are all equal to zero, \(v'(0^+)\) will also be equal to zero.
🔗
Refer to Table 7.7.1 to determine the form of the particular solution.
🔗
\begin{equation*} v_P(t) = K_1\sin(2\pi40t) + K_2\cos(2\pi40t) \end{equation*}
🔗
Plug the particular solution into the differential equation and combine like terms.
🔗
\begin{align*} 5000\sin(2\pi40t) \amp= \frac{d^2}{dt^2}\left[K_1\sin(2\pi40t) + K_2\cos(2\pi40t)\right]\\ \amp+ 10 \frac{d}{dt}\left[K_1\sin(2\pi40t) + K_2\cos(2\pi40t)\right]\\ \amp+ 1000\left[K_1\sin(2\pi40t) + K_2\cos(2\pi40t)\right]\\ \amp= -6400\pi^2\left[K_1\sin(2\pi40t) + K_2\cos(2\pi40t)\right]\\ \amp+ 800\pi\left[K_1\cos(2\pi40t) - K_2\sin(2\pi40t)\right]\\ \amp+ 1000\left[K_1\sin(2\pi40t) + K_2\cos(2\pi40t)\right]\\ \amp= \sin(2\pi40t)\left[-6400\pi^2K_1 - 800\pi K_2 + 1000K_1\right]\\ \amp+ \cos(2\pi40t)\left[-6400\pi^2K_2 + 800\pi K_1 + 1000K_2\right] \end{align*}
🔗
All of the sine terms can be used to generate one equation relating \(K_1\) and \(K_2\text{.}\)
🔗
\begin{align*} 5000\sin(2\pi40t) \amp= \sin(2\pi40t)\left[-6400\pi^2K_1 - 800\pi K_2 + 1000K_1\right]\\ 5000 \amp= -6400\pi^2K_1 - 800\pi K_2 + 1000K_1\\ \amp= (-6400\pi^2 + 1000)K_1 + (-800\pi)K_2 \end{align*}
🔗
All of the cosine terms can be used to generate a second equation relating \(K_1\) and \(K_2\text{.}\)
🔗
\begin{align*} 0 \amp= \cos(2\pi40t)\left[-6400\pi^2K_2 + 800\pi K_1 + 1000K_2\right]\\ \amp= -6400\pi^2K_2 + 800\pi K_1 + 1000K_2\\ \amp= (800\pi)K_1 + (-6400\pi^2+1000)K_2 \end{align*}
🔗
The two equations can be expressed in a matrix. The left column contains coefficients of \(K_1\text{,}\) the middle column contains coefficients of \(K_2\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} -6400\pi^2+1000 \amp -800\pi \amp 5000\\ 800\pi \amp -6400\pi^2+1000 \amp 0 \end{bmatrix} \end{equation*}
🔗
The matrix is shown in reduced row echelon form below.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp -0.0803\\ 0 \amp 1 \amp -0.0032\\ \end{bmatrix} \end{equation*}
🔗
The coefficient \(K_2\) can be rounded to zero. The particular form of the solution is now known.
🔗
\begin{equation*} v_P(t) = -0.080~\textrm{V}~\sin(2\pi40t) \end{equation*}
🔗
The equation for \(v(t)\) has the following form.
🔗
\begin{align*} v(t) \amp= \biggl[-0.080~\textrm{V}~\sin(2\pi40t)\\ \amp+ \textrm{e}^{-5t}\left(B_1 \cos{31.225t} + B_2\sin{31.225t}\right)\biggr]~u(t) \end{align*}
🔗
Use \(v(0^+)\) and \(v'(0^+)\) to calculate \(B_1\) and \(B_2\text{.}\) Start with \(v(0^+)\text{.}\)
🔗
\begin{align*} 0 \amp= \left[-0.080~\textrm{V}~\sin(0) + \textrm{e}^{0}\left(B_1 \cos{0} + B_2\sin{0}\right)\right]\\ B_1 \amp= 0~\textrm{V} \end{align*}
🔗
The equation for \(v(t)\) now has the following form.
🔗
\begin{equation*} v(t) = \left[-0.080~\textrm{V}~\sin(2\pi40t) + \textrm{e}^{-5t}\left(B_2\sin{31.225t}\right)\right]~u(t) \end{equation*}
🔗
Take the first derivative of the above expression, and set equal to \(v(0^+)\) at a time of \(t=0^+\) to calculate \(B_2\text{.}\)
🔗
\begin{align*} \frac{dv(t)}{dt} \amp= -5B_2\sin{31.225t} + 31.225B_2~\textrm{e}^{-5t}\cos{31.225t}\\ \amp- 20.1062\cos{(2\pi 40t)}\\ v'(0^+) = 0 \amp= -5B_2\sin{0} + 31.225B_2~\textrm{e}^{0}\cos{0} - 20.1062\cos{0}\\ 0 \amp= 31.225B_2 - 20.1062\\ 31.225B_2 \amp= 20.1062\\ B_2 \amp= 0.6439~\textrm{V} \end{align*}
🔗
The equation for \(v(t)\) is now known.
🔗
\begin{equation*} v(t) = \left[-0.080~\textrm{V}~\sin(2\pi40t) + \textrm{e}^{-5t}\left(0.644~\textrm{V}~\sin{31.2t}\right)\right]~u(t) \end{equation*}
