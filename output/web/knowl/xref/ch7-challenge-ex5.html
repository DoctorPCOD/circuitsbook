Exercise 16.

Derive an equation for \(i(t)\) given the circuit shown in Figure 7.8.58. The switch is in position a for a very long time before moving to position b at a time of zero seconds. The component values are \(V_S = 10~\textrm{V}\text{,}\) \(R_S = 4~\Omega\text{,}\) \(R = 2~\Omega\text{,}\) \(r_m = 0.5~\textrm{V/A}\text{,}\) \(L = 5~\textrm{mH}\text{,}\) and \(C = 200~\mu\textrm{F}\text{.}\)
🔗
Answer.
\begin{equation*} i(t) = 2000~\textrm{A/s}~t~\textrm{e}^{-1000t}~u(t) \end{equation*}
🔗
🔗
Solution.
In the initial steady-state, the inductor, resistor \(R\text{,}\) and CCVS will not be connected to a source. This means that \(i(0)\) is equal to zero. That value is continuous with time. The capacitor will be an open connected in parallel to \(V_S\text{.}\) This means that \(v_C(0) = V_S\text{.}\) This value is also continuous with time.
🔗
In the final steady-state, none of the circuit elements will be connected to a source. This means that the particular solution is equal to zero and the circuit is homogeneous.
🔗
Analyze the circuit at \(t=0^+\) to derive the differential equation.
🔗
Perform KCL at the node connecting \(C\text{,}\) \(L\text{,}\) and the CCVS.
🔗
\begin{equation} C\frac{dv_C(t)}{dt} + i(t) + i_X(t) = 0\tag{7.8.33} \end{equation}
🔗
Perform KVL around the right-hand loop of the circuit and solve for \(i_X(t)\text{.}\)
🔗
\begin{align} v_C(t) \amp= r_mi_X(t) + Ri_X(t)\tag{7.8.34}\\ \amp= (r_m+R)i_X(t)\tag{7.8.35}\\ i_X(t) \amp= \frac{v_C(t)}{r_m+R}\tag{7.8.36} \end{align}
🔗
Plug (7.8.36) into (7.8.33) to remove \(i_X(t)\) terms.
🔗
\begin{equation} C\frac{dv_C(t)}{dt} + i(t) + \frac{v_C(t)}{r_m+R}\tag{7.8.37} \end{equation}
🔗
One last equation that relates the voltage dropped over the inductor to \(i(t)\) is given by (6.3.1). Plug (6.3.1) into (7.8.37) and reduce until the differential equation is in standard form.
🔗
\begin{align*} 0 \amp= LC \frac{d^2i(t)}{dt^2} + i(t) + \frac{L}{r_m+R}\frac{di(t)}{dt}\\ \amp= \frac{d^2i(t)}{dt^2} + \frac{1}{C(r_m+R)}\frac{di(t)}{dt} + \frac{1}{LC}i(t) \end{align*}
🔗
Plug in component values, using base units.
🔗
\begin{equation*} 0 = \frac{d^2i(t)}{dt^2} + 2000 \frac{di(t)}{dt} + 1 \times 10^6 \end{equation*}
🔗
Use (7.2.1) to calculate the damping parameter and use (7.2.2) to calculate the resonant frequency.
🔗
\begin{gather*} \alpha = 1000~\textrm{Np/s}\\ \omega_0 = 1000~\textrm{rad/s} \end{gather*}
🔗
This circuit is critically damped.
🔗
Use (6.3.1) to calculate \(i'(0^+)\text{.}\)
🔗
\begin{align*} i'(0^+) \amp= \frac{v_C(0^+)}{L}\\ \amp= \frac{10~\textrm{V}}{0.005~\textrm{H}}\\ \amp= 2000~\textrm{A/s} \end{align*}
🔗
Use (7.5.8) and (7.5.9) to calculate the coefficients.
🔗
\begin{align*} A_1 \amp= 0~\textrm{A}\\ A_2 \amp= 2000~\textrm{A/s} \end{align*}
🔗
Plug everything into (7.5.7) to obtain the equation for \(i(t)\text{.}\)
🔗
\begin{equation*} i(t) = 2000~\textrm{A/s}~t~\textrm{e}^{-1000t}~u(t) \end{equation*}
