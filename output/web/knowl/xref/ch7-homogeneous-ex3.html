Exercise 8.

Derive a second-order differential equation in standard form in terms of \(i(t)\) given the circuit shown in Figure 7.8.27. The switch is closed for a very long time before opening at a time of zero seconds.
🔗
Answer.
\begin{equation*} 0 = \frac{d^2i(t)}{dt^2} + \left[\frac{R_2}{L_1} + \frac{R_2}{L_2} + \frac{R_3}{L_2} + \frac{R_1}{L_1}\right]\frac{di(t)}{dt} + \left[\frac{R_1R_2}{L_1L_2} + \frac{R_1R_3}{L_1L_2} + \frac{R_2R_3}{L_1L_2}\right]i(t) \end{equation*}
🔗
🔗
Solution.
Analyze the circuit at \(t=0^+\text{.}\)
🔗
Perform KCL at the node connecting \(L_1\text{,}\) \(R_2\text{,}\) and \(L_2\text{.}\)
🔗
\begin{equation*} i_X(t) + \frac{v_X(t)}{R_2} + i(t) = 0 \end{equation*}
🔗
Solve for \(i_X(t)\text{.}\)
🔗
\begin{equation} i_X(t) = -\frac{v_X(t)}{R_2} - i(t)\tag{7.8.5} \end{equation}
🔗
Perform KVL around the left loop of the circuit.
🔗
\begin{equation} v_X(t) = L_1 \frac{di_X(t)}{dt} + R_1i_X(t)\tag{7.8.6} \end{equation}
🔗
Plug (7.8.5) into (7.8.6) to remove all \(i_X(t)\) terms from (7.8.6).
🔗
\begin{align} v_X(t) \amp= L_1\frac{d}{dt}\left[-\frac{v_X(t)}{R_2} - i(t)\right] + R_1\left[-\frac{v_X(t)}{R_2} - i(t)\right]\tag{7.8.7}\\ 0 \amp= v_X(t) + L_1\frac{di(t)}{dt} + \frac{L_1}{R_2}\frac{dv_X(t)}{dt} + R_1i(t) + \frac{R_1}{R_2}v_X(t)\tag{7.8.8} \end{align}
🔗
Perform KVL around the right loop of the circuit.
🔗
\begin{equation} v_X(t) = L_2 \frac{di(t)}{dt} + R_3i(t)\tag{7.8.9} \end{equation}
🔗
Plug (7.8.9) into (7.8.8) to remove all \(v_X(t)\) terms from (7.8.8). Then, reduce to standard form.
🔗
\begin{align*} 0 \amp= L_2\frac{di(t)}{dt} + R_3i(t) + L_1\frac{di(t)}{dt} + \frac{L_1}{R_2}\frac{d}{dt}\left[L_2\frac{di(t)}{dt} + R_3i(t)\right] + R_1i(t) + \frac{R_1}{R_2}\left[L_2\frac{di(t)}{dt} + R_3i(t)\right]\\ \amp= L_2\frac{di(t)}{dt} + R_3i(t) + L_1\frac{di(t)}{dt} + \frac{L_1L_2}{R_2}\frac{d^2i(t)}{dt^2} + \frac{R_3L_1}{R_2}\frac{di(t)}{dt} + R_1i(t) + \frac{R_1L_2}{R_2}\frac{di(t)}{dt} + \frac{R_3R_1}{R_2}i(t)\\ \amp= \frac{L_1L_2}{R_2}\frac{d^2i(t)}{dt^2} + \left[L_1 + L_2 + \frac{L_1R_3}{R_2} + \frac{R_1L_2}{R_2}\right]\frac{di(t)}{dt} + \left[R_1 + \frac{R_1R_3}{R_2} + R_3\right]i(t)\\ \amp= \frac{d^2i(t)}{dt^2} + \left[\frac{R_2}{L_1} + \frac{R_2}{L_2} + \frac{R_3}{L_2} + \frac{R_1}{L_1}\right]\frac{di(t)}{dt} + \left[\frac{R_1R_2}{L_1L_2} + \frac{R_1R_3}{L_1L_2} + \frac{R_2R_3}{L_1L_2}\right]i(t) \end{align*}
