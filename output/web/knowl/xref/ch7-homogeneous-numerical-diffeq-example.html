Example 7.5.22 Homogeneous general second-order circuit in numeric form.

Calculate \(i(t)\) for the circuit shown below. The switch is closed for a very long time before opening at a time of zero seconds. The circuit parameters are \(R_1 = 20~\Omega\text{,}\) \(R_2 = 30~\Omega\text{,}\) \(R_3 = 30~\Omega\text{,}\) \(L_1 = 500~\textrm{mH}\text{,}\) and \(L_2 = 400~\textrm{mH}\text{.}\)
🔗
Analyze the circuit in its initial steady-state configuration Both inductors can be replaced by shorts.
🔗
Transform the voltage source into a current source.
🔗
Calculate the equivalent resistance of the circuit.
🔗
\begin{align*} R_{EQ} \amp= 20~\Omega // R_1 // R_2 // R_3\\ \amp= 20~\Omega // 20~\Omega // 30~\Omega // 30~\Omega\\ \amp= 6~\Omega \end{align*}
🔗
Use the current divider rule to calculate \(i(0)\text{.}\) This value will be continuous with time.
🔗
\begin{align*} i(0) \amp= 0.5~\textrm{A}\left(\frac{6~\Omega}{30~\Omega}\right)\\ \amp= 0.1~\textrm{A} \end{align*}
🔗
Use KCL to calculate \(i_X(0)\text{.}\) This value will also be continuous with time. Because both \(R_2\) and \(R_3\) are 30 Ω resistors, they will have equal current values in the initial steady-state condition.
🔗
\begin{align*} i_X(0) \amp= 0.1~\textrm{A} + 0.1~\textrm{A}\\ \amp= 0.2~\textrm{A} \end{align*}
🔗
Use Ohm’s law to calculate \(v_X(0^-)\text{.}\)
🔗
\begin{align*} v_X(0^-) \amp= (0.1~\textrm{A})(30~\Omega)\\ \amp= 3~\textrm{V} \end{align*}
🔗
\(v_X(t)\) may not be continuous with time. Analyze the circuit at \(t=0^+\) to calculate \(v_X(0^+)\text{.}\) Replace \(L_1\) with a 0.2 A current source. Replace \(L_2\) with a 0.1 A current source.
🔗
From KCL, we can see that the current through \(R_2\) will be equal to 0.1 A. Therefore, \(v_X(0^+) = 3~\textrm{V}\text{.}\)
🔗
Analyze the circuit at \(t=0^+\) to derive the second-order differential equation.
🔗
Perform KCL at the node connecting \(L_1\text{,}\) \(R_2\text{,}\) and \(R_3\text{.}\)
🔗
\begin{equation} i_X(t) = \frac{v_X(t)}{R_2} + i(t)\tag{7.5.13} \end{equation}
🔗
Perform KVL around the left-hand loop of the circuit.
🔗
\begin{equation} v_X(t) = -L_1\frac{di_X(t)}{dt} - R_1i_X(t)\tag{7.5.14} \end{equation}
🔗
Plug (7.5.13) into (7.5.14) to remove \(i_X(t)\) terms.
🔗
\begin{align} v_X(t) \amp= -L_1\frac{d}{dt}\left(\frac{v_X(t)}{R_2} + i(t)\right) - R_1\left(\frac{v_X(t)}{R_2} + i(t)\right)\tag{7.5.15}\\ \amp= -\frac{L_1}{R_2}\frac{dv_X(t)}{dt} - L_1\frac{di(t)}{dt} - \frac{R_1}{R_2}v_X(t) - R_1i(t)\tag{7.5.16}\\ 0 \amp= v_X(t) + \frac{R_1}{R_2}v_X(t) + \frac{L_1}{R_2}\frac{dv_X(t)}{dt} + L_1\frac{di(t)}{dt} + R_1i(t)\tag{7.5.17}\\ \amp= \left(1 + \frac{R_1}{R_2}\right)v_X(t) + \frac{L_1}{R_2}\frac{dv_X(t)}{dt} + L_1\frac{di(t)}{dt} + R_1i(t)\tag{7.5.18} \end{align}
🔗
Perform KVL around the right-hand loop of the circuit.
🔗
\begin{equation} v_X(t) = R_3i(t) + L_2\frac{di(t)}{dt}\tag{7.5.19} \end{equation}
🔗
Plug (7.5.19) into (7.5.18) and reduce to standard form.
🔗
\begin{align*} \amp= \left(1 + \frac{R_1}{R_2}\right)\left(R_3i(t) + L_2\frac{di(t)}{dt}\right) + \frac{L_1}{R_2}\frac{d}{dt}\left(R_3i(t) + L_2\frac{di(t)}{dt}\right) + L_1\frac{di(t)}{dt} + R_1i(t)\\ \amp= R_3i(t) + L_2\frac{di(t)}{dt} + \frac{R_1R_3}{R_2}i(t) + \frac{L_2R_1}{R_2}\frac{di(t)}{dt} + \frac{L_1R_3}{R_2}\frac{di(t)}{dt} + \frac{L_1L_2}{R_2}\frac{d^2i(t)}{dt^2} + L_1\frac{di(t)}{dt} + R_1i(t)\\ \amp= \frac{L_1L_2}{R_2}\frac{d^2i(t)}{dt^2} + \left(L_2 + \frac{L_2R_1}{R_2} + \frac{L_1R_3}{R_2} + L_1\right)\frac{di(t)}{dt} + \left(R_3 + \frac{R_1R_3}{R_2} + R_1\right)i(t)\\ \amp= \frac{d^2i(t)}{dt^2} + \left(\frac{R_2}{L_1} + \frac{R_1}{L_1} + \frac{R_3}{L_2} + \frac{R_2}{L_2}\right)\frac{di(t)}{dt} + \left(\frac{R_2R_3}{L_1L_2} + \frac{R_1R_3}{L_1L_2} + \frac{R_1R_2}{L_1L_2}\right)i(t) \end{align*}
🔗
Plug in component values using base units.
🔗
\begin{equation*} 0 = \frac{d^2i(t)}{dt^2} + 250\frac{di(t)}{dt} + 10500i(t) \end{equation*}
🔗
Use (7.2.1) to calculate the damping parameter and (7.2.2) to calculate the resonant frequency.
🔗
\begin{align*} \alpha \amp= \frac{250}{2}\\ \amp= 125~\textrm{Np/s}\\ \omega_0 \amp= \sqrt{10500}\\ \amp= 102.47~\textrm{rad/s} \end{align*}
🔗
This circuit is overdamped.
🔗
Use (7.5.19) to calculate the value of \(i'(0^+)\text{.}\)
🔗
\begin{align*} i'(0^+) \amp= \frac{v_X(0^+) - R_3i(0^+)}{L_2}\\ \amp= \frac{3~\textrm{V} - (0.1~\textrm{A})(30~\Omega)}{0.4~\textrm{H}}\\ \amp= 0~\textrm{A/s} \end{align*}
🔗
Use (7.2.3) and (7.2.4) to calculate the roots of the characteristic equation.
🔗
\begin{align*} s_1 \amp= -125 + \sqrt{125^2 - 102.47^2}\\ \amp= -53.41\\ s_2 \amp= -125 - \sqrt{125^2 - 102.47^2}\\ \amp= -196.59 \end{align*}
🔗
Use (7.5.2) and (7.5.3) to calculate the coefficients of the equation.
🔗
\begin{align*} A_1 \amp= \frac{(0.1)(-196.59)}{-196.59+53.41}\\ \amp= 0.14~\textrm{A}\\ A_2 \amp= \frac{-(0.1)(-53.41)}{-196.59+53.41}\\ \amp= -0.04~\textrm{A} \end{align*}
🔗
Plug all of these quantities into (7.5.1) to obtain the equation for i(t).
🔗
\begin{equation*} i(t) = \left(0.14~\textrm{A}~\textrm{e}^{-53.41t} - 0.04~\textrm{A}~\textrm{e}^{-196.59t}\right)~u(t) + 0.1~\textrm{A}~u(-t) \end{equation*}
