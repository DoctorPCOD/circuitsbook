Exercise 12.

Derive an equation for \(i(t)\) based on the circuit shown in Figure 7.8.42. The switch is in position a for a very long time before moving to position b at a time of zero seconds. The component values are \(V_{S1} = 8~\textrm{V}\text{,}\) \(V_{S2} = 10~\textrm{V}\text{,}\) \(R_{S1} = 3.5~\Omega\text{,}\) \(R_{S2} = 4~\Omega\text{,}\) \(R = 0.5~\Omega\text{,}\) \(L = 1~\textrm{H}\text{,}\) and \(C = 1~\textrm{F}\text{.}\)
🔗
Answer.
\begin{equation*} i(t) = \left[-2.22~\textrm{A} + 4.22~\textrm{A}~\textrm{e}^{-3t} - 6.33~\textrm{A/s}~t~\textrm{e}^{-3t}\right]~u(t) + 2~\textrm{A}~u(-t) \end{equation*}
🔗
🔗
Solution.
Analyze the circuit in its initial steady-state condition. The capacitor can be replaced by an open and the inductor can be replaced by a short.
🔗
Use Ohm’s law to calculate \(i(0)\text{.}\) This value is continuous with time.
🔗
\begin{align*} i(0) \amp= \frac{8~\textrm{V}}{3.5~\Omega + 0.5~\Omega}\\ \amp= 2~\textrm{A} \end{align*}
🔗
Use the voltage divider rule to calculate \(v_X(0)\text{.}\) This value is also continuous with time.
🔗
\begin{align*} v_X(0) \amp= 8~\textrm{V}\left(\frac{0.5~\Omega}{3.5~\Omega + 0.5~\Omega}\right)\\ \amp= 1~\textrm{V} \end{align*}
🔗
Analyze the circuit in its final steady-state configuration to calculate \(i(\infty)\text{,}\) the value of the particular solution.
🔗
Use Ohm’s law to calculate \(i(\infty)\text{.}\)
🔗
\begin{align*} i(\infty) \amp= \frac{-10~\textrm{V}}{4~\Omega + 0.5~\Omega}\\ \amp= -2.222~\textrm{A} \end{align*}
🔗
Analyze the circuit at \(t=0^+\) to derive the differential equation.
🔗
Perform KVL around the entire circuit and solve it for \(v_X(t)\text{.}\)
🔗
\begin{align} -V_{S2} \amp= R_{S2}i(t) + v_X(t) + L\frac{di(t)}{dt}\tag{7.8.19}\\ v_X(t) \amp= -V_{S2} - R_{S2}i(t) - L\frac{di(t)}{dt}\tag{7.8.20} \end{align}
🔗
Perform KCL at the node connecting \(R\text{,}\) \(C\text{,}\) and \(L\text{.}\)
🔗
\begin{equation} i(t) = \frac{v_X(t)}{R} + C\frac{dv(t)}{dt}\tag{7.8.21} \end{equation}
🔗
Plug (7.8.20) into (7.8.21) and reduce until the differential equation is in standard from.
🔗
\begin{align*} i(t) \amp= \frac{1}{R}\left(-V_{S2} - R_{S2}i(t) - L\frac{di(t)}{dt}\right) + C\frac{d}{dt}\left(-V_{S2} - R_{S2}i(t) - L\frac{di(t)}{dt}\right)\\ \amp= \frac{-V_{S2}}{R} - \frac{R_{S2}}{R}i(t) - \frac{L}{R}\frac{di(t)}{dt} - R_{S2}C\frac{di(t)}{dt} - LC\frac{d^2i(t)}{dt^2}\\ \frac{-V_{S2}}{R} \amp= LC\frac{d^2i(t)}{dt^2} + \left(\frac{L}{R} + R_{S2}C\right)\frac{di(t)}{dt} + \left(1 + \frac{R_{S2}}{R}\right)i(t)\\ \frac{-V_{S2}}{RLC} \amp= \frac{d^2i(t)}{dt^2} + \left(\frac{1}{RC} + \frac{R_{S2}}{L}\right)\frac{di(t)}{dt} + \left(\frac{1}{LC} + \frac{R_{S2}}{RLC}\right)i(t) \end{align*}
🔗
Plug in numerical values using base units.
🔗
\begin{equation*} -20 = \frac{d^2i(t)}{dt^2} + 6\frac{di(t)}{dt} + 9 \end{equation*}
🔗
Use (7.2.1) to calculate the damping parameter and use (7.2.2) to calculate the resonant frequency.
🔗
\begin{align*} \alpha \amp= \frac{6}{2}\\ \amp= 3~\textrm{Np/s}\\ \omega_0 \amp= \sqrt{9}\\ \amp= 3~\textrm{rad/s} \end{align*}
🔗
This circuit is critically damped. Use (7.8.20) to calculate \(i'(0^+)\text{.}\)
🔗
\begin{align*} i'(0^+) \amp= \frac{-v_X(0^+) - V_{S2} - R_{S2}i(0^+)}{L}\\ \amp= \frac{-1 - 10 - (4)(2)}{1}\\ \amp= -19~\textrm{A/s} \end{align*}
🔗
Use (7.6.10) and (7.6.11) to calculate the coefficients of the equation.
🔗
\begin{align*} A_1 \amp= 2~\textrm{A} + 2.22~\textrm{A}\\ \amp= 4.22~\textrm{A}\\ A_2 \amp= -19~\textrm{A/s} + (3~\textrm{Np/s})(2~\textrm{A} + 2.22~\textrm{A})\\ \amp= -6.33~\textrm{A} \end{align*}
🔗
Plug everything into (7.6.9) to obtain an equation for \(i(t)\text{.}\)
🔗
\begin{equation*} i(t) = \left[-2.22~\textrm{A} + 4.22~\textrm{A}~\textrm{e}^{-3t} - 6.33~\textrm{A/s}~t~\textrm{e}^{-3t}\right]~u(t) + 2~\textrm{A}~u(-t) \end{equation*}
