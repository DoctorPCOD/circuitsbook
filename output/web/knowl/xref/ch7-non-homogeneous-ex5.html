Exercise 15.

Derive an equation for \(i(t)\) given the circuit shown in Figure 7.8.53. The switch is open for a very long time before closing at a time of zero seconds. The component values are \(V_S = 20~\textrm{V}\text{,}\) \(R_S = 2~\Omega\text{,}\) \(R_1 = 5~\Omega\text{,}\) \(R_2 = 2~\Omega\text{,}\) \(L = 2~\textrm{H}\text{,}\) and \(C = 0.1~\textrm{F}\text{.}\)
🔗
Answer.
\begin{equation*} i(t) = \left[2.86~\textrm{A} + \textrm{e}^{-2.75t}\left(-2.86~\textrm{A}~\cos{1.09t} - 2.62~\textrm{A}~\sin{1.09t}\right)\right]~u(t) \end{equation*}
🔗
🔗
Solution.
In the initial steady-state condition, \(i(0)\) is equal to zero. The voltage over the capacitor is also zero. This is because there is no source connected to the circuit at this time. These two values are continuous with time. While \(v_X(0^-)\) is zero, that value may not be continuous. Analyze the circuit at \(t=0^+\text{.}\) The inductor will be replaced by a 0 A current source and the capacitor will be replaced by a 0 V voltage source.
🔗
The 0 A current source can be replaced by an open and the 0 V voltage source can be replaced by a short.
🔗
Use the voltage divider rule to calculate \(v_X(0^+)\text{.}\)
🔗
\begin{align*} v_X(0^+) \amp= 20~\textrm{V}\frac{2~\Omega}{2~\Omega + 2~\Omega}\\ \amp= 10~\textrm{V} \end{align*}
🔗
Analyze the circuit in its final steady-state configuration to calculate \(i(\infty)\text{,}\) which is the particular solution. The inductor can be replaced by a short and the capacitor can be replaced by an open.
🔗
Use Ohm’s law to calculate \(i(\infty)\text{.}\)
🔗
\begin{align*} i(\infty) \amp= \frac{20~\textrm{V}}{2~\Omega + 5~\Omega}\\ \amp= 2.8571~\textrm{A} \end{align*}
🔗
Analyze the circuit at \(t=0^+\) to derive the differential equation.
🔗
First, perform KCL at the node connecting \(R_S\text{,}\) \(R_1\text{,}\) and \(R_2\text{.}\) The current through the branch containing \(R_2\) and \(C\) will be depicted as \(i_C(t)\text{.}\) Solve this equation for \(i_C(t)\text{.}\)
🔗
\begin{align} \frac{V_S - v_X(t)}{R_S} \amp= i(t) + i_C(t)\tag{7.8.25}\\ \frac{V_S}{R_S} \amp= \frac{v_X(t)}{R_S} + i(t) + i_C(t)\tag{7.8.26}\\ i_C(t) \amp= \frac{V_S}{R_S} - \frac{v_X(t)}{R_S} - i(t)\tag{7.8.27} \end{align}
🔗
Relate \(v_X(t)\) to the branch containing \(R_2\) and \(C\text{.}\)
🔗
\begin{equation} v_X(t) = R_2i_C(t) + \frac{1}{C}\int i_C(t) \,dt\tag{7.8.28} \end{equation}
🔗
Plug (7.8.27) into (7.8.28) to remove all \(i_C(t)\) terms. Simplify and collect like terms.
🔗
\begin{align} v_X(t) \amp= R_2\left(\frac{V_S}{R_S} - \frac{v_X(t)}{R_S} - i(t)\right)\tag{7.8.29}\\ \amp+ \frac{1}{C}\int \left(\frac{V_S}{R_S} - \frac{v_X(t)}{R_S} - i(t)\right)\, dt\tag{7.8.30}\\ v_X(t) \amp= \frac{R_2}{R_2}V_S - \frac{R_2}{R_S}v_X(t) - R_2i(t)\tag{7.8.31}\\ \amp+ \frac{1}{CR_S}\int V_S \,dt\tag{7.8.32}\\ \amp- \frac{1}{CR_S}\int v_X(t) \,dt - \frac{1}{C}\int i(t) \,dt\tag{7.8.33}\\ \frac{R_2}{R_S}V_S + \frac{1}{CR_S}\int V_S \,dt \amp= v_X(t) + \frac{R_2}{R_S} v_X(t)\tag{7.8.34}\\ \amp+ \frac{1}{CR_S}\int v_X(t) \,dt + R_2i(t) + \frac{1}{C}\int i(t) \,dt\tag{7.8.35} \end{align}
🔗
Relate \(v_X(t)\) to the branch containing \(R_1\) and \(L\text{.}\)
🔗
\begin{equation} v_X(t) = R_1i(t) + L\frac{di(t)}{dt}\tag{7.8.36} \end{equation}
🔗
Plug (7.8.36) into (7.8.34) and reduce to standard form.
🔗
\begin{align*} \frac{R_2}{R_S}V_S + \frac{1}{CR_S}\int V_S \,dt \amp= \left(R_1i(t) + L\frac{di(t)}{dt}\right) + \frac{R_2}{R_S} \left(R_1i(t) + L\frac{di(t)}{dt}\right)\\ \amp+ \frac{1}{CR_S}\int \left(R_1i(t) + L\frac{di(t)}{dt}\right) \,dt + R_2i(t)\\ \amp+ \frac{1}{C}\int i(t) \,dt\\ \amp= R_1i(t) + L\frac{di(t)}{dt} + \frac{R_2R_1}{R_S}i(t) + \frac{R_2L}{R_S}\frac{di(t)}{dt}\\ \amp+ \frac{R_1}{CR_S}\int i(t) \,dt + \frac{L}{CR_S}i(t) + R_2i(t)\\ \amp+ \frac{1}{C}\int i(t) \,dt\\ \frac{R_2}{R_S}\frac{dV_S}{dt} + \frac{1}{CR_S}V_S \amp= R_1\frac{di(t)}{dt} + L\frac{d^2i(t)}{dt^2} + \frac{R_2R_1}{R_S}\frac{di(t)}{dt} + \frac{R_2L}{R_S}\frac{d^2i(t)}{dt^2}\\ \amp+ \frac{R_1}{CR_S} i(t) + \frac{L}{CR_S}\frac{di(t)}{dt} + R_2\frac{di(t)}{dt} + \frac{1}{C}i(t)\\ \frac{V_S}{CR_S} \amp= \left[L + \frac{R_2L}{R_S}\right]\frac{d^2i(t)}{dt^2}\\ \amp+ \left[R_1 + \frac{R_1R_2}{R_S} + \frac{L}{CR_S} + R_2\right]\frac{di(t)}{dt}\\ \amp+ \left[\frac{R_1}{CR_S}+\frac{1}{C}\right]i(t)\\ \frac{V_S}{CL(R_S+R_2)} \amp= \frac{d^2i(t)}{dt^2}\\ \amp+ \left[\frac{R_1R_S + R_1R_2 + R_2R_S}{L(R_S+R_2)} + \frac{1}{C(R_S+R_2)}\right]\frac{di(t)}{dt}\\ \amp+ \left[\frac{R_1+R_S}{LC(R_S+R_2)}\right]i(t)\\ 2.5 \amp= \frac{d^2i(t)}{dt^2} + 5.5\frac{di(t)}{dt} + 8.75 \end{align*}
🔗
Use (7.2.1) to calculate the damping parameter and use (7.2.2) to calculate the resonant frequency.
🔗
\begin{align*} \alpha \amp= 2.75~\textrm{Np/s}\\ \omega_0 \amp= 2.958~\textrm{rad/s} \end{align*}
🔗
This circuit is underdamped. Use (7.2.5) to calculate the oscillation frequency of the circuit.
🔗
\begin{align*} \beta \amp= \sqrt{2.958^2 - 2.75^2}\\ \amp= 1.0897~\textrm{rad/s} \end{align*}
🔗
Use (7.8.36) to calculate \(i'(0^+)\text{.}\)
🔗
\begin{align*} i'(0^+) \amp= \frac{v_X(0^+) - R_1i(0^+)}{L}\\ \amp= \frac{10 - 0}{2}\\ \amp= 5~\textrm{A/s} \end{align*}
🔗
Use (7.6.7) and (7.6.8) to calculate the coefficients of the equation.
🔗
\begin{align*} B_1 \amp= -2.8571~\textrm{A}\\ B_2 \amp= \frac{5 + 2.75(-2.8571)}{1.0897}\\ \amp= -2.6219~\textrm{A} \end{align*}
🔗
Plug everything into (7.6.6) to obtain the equation for \(i(t)\text{.}\)
🔗
\begin{equation*} i(t) = \left[2.86~\textrm{A} + \textrm{e}^{-2.75t}\left(-2.86~\textrm{A}~\cos{1.09t} - 2.62~\textrm{A}~\sin{1.09t}\right)\right]~u(t) \end{equation*}
