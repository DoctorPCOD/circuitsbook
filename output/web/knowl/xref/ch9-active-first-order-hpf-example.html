Example 9.4.5 Active first-order high-pass filter.

An active first-order high-pass filter is shown below.
🔗
The first-order differential equation that describes the behavior of this high-pass filter can be derived by performing KCL at the inverting input of the op-amp.
🔗
\begin{equation*} -\frac{R_2}{R_1}\frac{dv_{in}(t)}{dt} = \frac{dv_{out}(t)}{dt} + \frac{1}{R_1C}v_{out}(t) \end{equation*}
🔗
The cutoff frequency of this filter is defined below.
🔗
\begin{equation*} \omega_c = \frac{1}{R_1C} \end{equation*}
🔗
To determine the filter type, first analyze the circuit at \(\omega=0\) to calculate \(v_{out}(0)\text{.}\) The capacitor can be replaced by an open.
🔗
The output is zero because the input is not connected to the output.
🔗
Analyze the circuit at \(\omega\rightarrow\infty\) to calculate \(v_{out}(\infty)\text{.}\) The capacitor can be replaced by a short.
🔗
Use (4.5.2) to calculate \(v_{out}(\infty)\text{.}\)
🔗
\begin{equation*} v_{out}(\infty) = -\frac{R_2}{R_1}v_{in} \end{equation*}
🔗
Consult Table 9.3.31. The circuit is a first-order, active, high-pass filter.
