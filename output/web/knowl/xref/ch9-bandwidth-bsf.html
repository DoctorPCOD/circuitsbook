Derivation

The transfer function of an RLC band-stop filter will take the form shown below.
🔗
\begin{equation*} H(j\omega) = \frac{-\omega^2 + a_0}{-\omega^2 + a_1 j\omega + a_0} \end{equation*}
🔗
The magnitude of this transfer function is shown below.
🔗
\begin{equation*} |H(j\omega)| = \frac{(a_0 - \omega^2)}{\sqrt{(a_0-\omega^2)^2 + (a_1 \omega)^2}} \end{equation*}
🔗
Set the magnitude of the transfer function equal to \(1/\sqrt{2}\) and solve for the two values of \(\omega\) that are positive. These will describe the two cutoff frequencies \(\omega_{c1}\) and \(\omega_{c2}\text{.}\)
🔗
\begin{align*} \frac{1}{\sqrt{2}} \amp= \frac{(a_0 - \omega^2)}{\sqrt{(a_0-\omega^2)^2 + (a_1 \omega)^2}}\\ \frac{1}{2} \amp= \frac{(a_0 - \omega^2)^2}{(a_0-\omega^2)^2 + (a_1 \omega)^2}\\ 2(a_0 - \omega^2)^2 \amp= (a_0-\omega^2)^2 + (a_1 \omega)^2\\ (a_0 - \omega^2)^2 \amp= (a_1 \omega)^2\\ 0 \amp= a_0^2 - 2a_0\omega^2 + \omega^4 - a_1^2 \omega^2 \\ \amp= \omega^4 - (2a_0 + a_1^2) \omega^2 + a_0^2 \end{align*}
🔗
The two positive real roots are shown below. These will not be derived in this book.
🔗
\begin{align*} \omega_{c1} \amp= \frac{1}{2}\left(\sqrt{a_1^2+4a_0} - a_1\right)\\ \omega_{c2} \amp= \frac{1}{2}\left(\sqrt{a_1^2+4a_0} + a_1\right) \end{align*}
🔗
Subtract \(\omega_{c1}\) from \(\omega_{c2}\) to calculate the bandwidth.
🔗
\begin{align*} \beta \amp= \frac{1}{2}\left(\sqrt{a_1^2+4a_0} + a_1\right) - \frac{1}{2}\left(\sqrt{a_1^2+4a_0} - a_1\right)\\ \amp= \frac{1}{2}a_1 + \frac{1}{2}a_1\\ \amp= a_1 \end{align*}
