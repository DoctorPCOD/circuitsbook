Example 9.3.23 Band-pass filter analysis.

Analyze the following band-pass filter. Calculate the center frequency and the quality factor of the circuit. The circuit parameters are \(C_1 = 40~\mu\textrm{F}\text{,}\) \(C_2 = 20~\mu\textrm{F}\text{,}\) \(R_1 = 200~\Omega\text{,}\) and \(R_2 = 120~\Omega\text{.}\)
🔗
The second-order differential equation describing the output voltage is shown below.
🔗
\begin{equation*} \frac{1}{R_2C_2}\frac{dv_{in}(t)}{dt} = \frac{d^2v_{out}(t)}{dt^2} + \left[\frac{1}{C_1R_1} + \frac{1}{C_2R_2} + \frac{1}{C_1R_2}\right]\frac{dv_{out}(t)}{dt} + \left[\frac{1}{C_1C_2R_1R_2}\right]v_{out}(t) \end{equation*}
🔗
The transfer function of the circuit is therefore equal to
🔗
\begin{equation*} H(j\omega) = \frac{\frac{1}{R_2C_2} j\omega}{-\omega^2 + \left[\frac{1}{C_1R_1} + \frac{1}{C_2R_2} + \frac{1}{C_1R_2}\right]j\omega + \left[\frac{1}{C_1C_2R_1R_2}\right]}\text{.} \end{equation*}
🔗
Plug in component values using base units.
🔗
\begin{equation*} H(j\omega) = \frac{416.6667 j\omega}{-\omega^2 + 750 j\omega + 52083.33} \end{equation*}
🔗
Use (9.3.5) to calculate the center frequency of the circuit.
🔗
\begin{align*} \omega_c \amp= \sqrt{52083.33}\\ \amp= 228~\textrm{rad/s} \end{align*}
🔗
Use (9.3.2) to calculate the quality factor of the circuit.
🔗
\begin{align*} Q \amp= \frac{228}{750}\\ \amp= 0.304 \end{align*}
🔗
There is no value of the magnitude of the transfer function that is equal to \(1/\sqrt{2}\text{.}\) Therefore, it’s not possible to directly calculate the cutoff frequencies of this circuit. However, this circuit is built from two stages. The first stage (consisting of resistor \(R_1\) and capacitor \(C_1\)) is a high-pass filter. The second stage (consisting of resistor \(R_2\) and capacitor \(C_2\)) is a low-pass filter. The cutoff frequency of each of these two stages can be calculated.
🔗
Stage one is a HPF with a transfer function defined below.
🔗
\begin{equation*} H(j\omega) = \frac{j\omega}{j\omega + \frac{1}{R_1C_1}} \end{equation*}
🔗
The magnitude of this transfer function is equal to
🔗
\begin{equation*} |H(j\omega)| = \frac{\omega}{\sqrt{\omega^2 + \left(\frac{1}{R_1C_1}\right)^2}} \end{equation*}
🔗
Set \(|H(j\omega)|\) equal to \(1/\sqrt{2}\) and solve for \(\omega\) to calculate the cutoff frequency of stage one. This will be one of the two cutoff frequencies of the band-pass filter.
🔗
\begin{align*} |H(j\omega_c)| = \frac{1}{\sqrt{2}} \amp= \frac{\omega_c}{\sqrt{\omega_c^2 + \left(\frac{1}{R_1C_1}\right)^2}}\\ \frac{1}{2} \amp= \frac{\omega_c^2}{\omega_c^2 + \left(\frac{1}{R_1C_1}\right)^2}\\ \omega_c^2 + \left(\frac{1}{R_1C_1}\right)^2 \amp= 2\omega_c^2\\ \omega_c^2 \amp= \left(\frac{1}{R_1C_1}\right)^2\\ \omega_c \amp= \frac{1}{R_1C_1}\\ \amp= \frac{1}{(200)(40 \times 10^{-6})}\\ \amp= 125~\textrm{rad/s} \end{align*}
🔗
Stage two is a LPF with a transfer function defined below.
🔗
\begin{equation*} H(j\omega) = \frac{\frac{1}{R_2C_2}}{j\omega + \frac{1}{R_2C_2}} \end{equation*}
🔗
The magnitude of this transfer function is equal to
🔗
\begin{equation*} |H(j\omega)| = \frac{\frac{1}{R_2C_2}}{\sqrt{\omega^2 + \left(\frac{1}{R_2C_2}\right)^2}} \end{equation*}
🔗
Set \(|H(j\omega)|\) equal to \(1/\sqrt{2}\) and solve for \(\omega\) to calculate the cutoff frequency of stage two. This will be the second of the two cutoff frequencies of the band-pass filter.
🔗
\begin{align*} |H(j\omega_c)| = \frac{1}{\sqrt{2}} \amp= \frac{\frac{1}{R_2C_2}}{\sqrt{\omega_c^2 + \left(\frac{1}{R_2C_2}\right)^2}}\\ \frac{1}{2} \amp= \frac{\left(\frac{1}{R_2C_2}\right)^2}{\omega_c^2 + \left(\frac{1}{R_2C_2}\right)^2}\\ \omega_c^2 + \left(\frac{1}{R_2C_2}\right)^2 \amp= 2\left(\frac{1}{R_2C_2}\right)^2\\ \omega_c^2 \amp= \left(\frac{1}{R_2C_2}\right)^2\\ \omega_c \amp= \frac{1}{R_2C_2}\\ \amp= \frac{1}{(120)(20 \times 10^{-6})}\\ \amp= 417~\textrm{rad/s} \end{align*}
