Exercise 12.

Calculate \(i(t)\) given the circuit diagram shown in Figure 9.6.27. The source value is \(v_{AC}(t) = 30~\textrm{V}~\cos(2\pi 100t + 45\pi/180)\text{.}\)
🔗
Answer.
\begin{equation*} i(t) = 1.83~\textrm{A}~\cos(2\pi100t + 103 \pi/180) \end{equation*}
🔗
🔗
Solution.
Use (8.2.4) to calculate the impedance of both capacitors.
🔗
\begin{align*} \frac{1}{j(2\pi 100)(160 \times 10^{-6})} \amp= -j9.9472~\Omega\\ \frac{1}{j(2\pi 100)(250 \times 10^{-6})} \amp= -j6.3662~\Omega \end{align*}
🔗
Use (8.2.5) to calculate the impedance of the inductor.
🔗
\begin{equation*} j(2\pi 100)(0.008) = j5.0265~\Omega \end{equation*}
🔗
Transform the source into a phasor.
🔗
\begin{align*} \vec{V_{AC}} \amp= 30~\cos{45^\circ} + j30~\sin{45^\circ}~\textrm{V}\\ \amp= 21.2132 + j21.2132~\textrm{V} \end{align*}
🔗
The 30 Ω resistor and −j6.37 Ω impedance are connected in series.
🔗
Mesh current \(\vec{I_A}\) will flow clockwise around the upper mesh. Mesh current \(\vec{I_B}\) will flow clockwise around the lower-left mesh. Mesh current \(\vec{I_C}\) will flow clockwise around the lower-right mesh. Derive the mesh equations.
🔗
\begin{align*} 0 \amp= (30-j6.37)\vec{I_A} + j5.03(\vec{I_A}-\vec{I_C}) + 15(\vec{I_A}-\vec{I_B})\\ 21.21+j21.21 \amp= 15(\vec{I_B}-\vec{I_A}) -j9.95(\vec{I_B}-\vec{I_C})\\ 0 \amp= -j9.95(\vec{I_C}-\vec{I_B}) + j5.03(\vec{I_C}-\vec{I_A}) + 20\vec{I_C} \end{align*}
🔗
The three equations can be expressed in a matrix. The left column contains coefficients of \(\vec{I_A}\text{,}\) the middle-left column contains coefficients of \(\vec{I_B}\text{,}\) the middle-right column contains coefficients of \(\vec{I_C}\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 45-j1.34 \amp -15 \amp -j5.03 \amp 0\\ 4-15 \amp 15-j9.95 \amp j9.95 \amp 21.21+j21.21\\ 4-j5.03 \amp j9.95 \amp 20-j4.92 \amp 0 \end{bmatrix} \end{equation*}
🔗
Solve the matrix for \(\vec{I_B}\) and \(\vec{I_C}\text{.}\)
🔗
\begin{align*} \vec{I_B} \amp= 0.31+j1.83~\textrm{A}\\ \vec{I_C} \amp= 0.73+j0.05~\textrm{A} \end{align*}
🔗
Calculate the branch current \(\vec{I}\text{.}\)
🔗
\begin{align*} \vec{I} \amp= (\vec{I_B}-\vec{I_C})\\ \amp= (0.31+j1.83~\textrm{A})-(0.73+j0.05~\textrm{A})\\ \amp= -0.42+j1.79~\textrm{A}\\ \amp= 1.83~\textrm{A} \angle 103.18^\circ \end{align*}
🔗
Convert to time-varying form.
🔗
\begin{equation*} i(t) = 1.83~\textrm{A}~\cos(2\pi100t + 103 \pi/180) \end{equation*}
