Exercise 13.

Calculate \(v(t)\) given the circuit diagram shown in Figure 9.6.30. The source value is \(v_{AC}(t) = 12~\textrm{V}~\cos(2\pi200t)\text{.}\)
🔗
Answer.
\begin{equation*} v(t) = 5.05~\textrm{V}~\cos(2\pi200t + 32.4 \pi/180) \end{equation*}
🔗
🔗
Solution.
Use (8.2.4) to calculate the impedance of the capacitor.
🔗
\begin{align*} \vec{Z_C} \amp= \frac{1}{j(2\pi200)(5 \times 10^{-6})}\\ \amp= -j31.8310~\Omega \end{align*}
🔗
Use (8.2.5) to calculate the impedance of the inductor.
🔗
\begin{align*} \vec{Z_L} \amp= j(2\pi200)(0.095)\\ \amp= j119.38~\Omega \end{align*}
🔗
Transform the source to a phasor.
🔗
\begin{align*} \vec{V_{AC}} \amp= 12~\cos{0^\circ} + j12~\sin{0^\circ}~\textrm{V}\\ \amp= 12~\textrm{V} \end{align*}
🔗
Mesh current \(\vec{I_A}\) will flow clockwise around the left mesh. Mesh current \(\vec{I_B}\) will flow clockwise around the upper-right mesh. Mesh current \(\vec{I_C}\) will flow clockwise around the lower-right mesh. Derive the mesh equations.
🔗
\begin{align*} 12 \amp= 130\vec{I_A} - j159.15(\vec{I_A}-\vec{I_B}) + 80(\vec{I_A}-\vec{I_C})\\ 0 \amp= -j159.15(\vec{I_B}-\vec{I_A}) + 56\vec{I_B} + 210(\vec{I_B}-\vec{I_C})\\ 0 \amp= 80(\vec{I_C}-\vec{I_A}) + 210(\vec{I_C}-\vec{I_B}) + j119.38\vec{I_C} \end{align*}
🔗
The three equations can be expressed in a matrix. The left column contains coefficients of \(\vec{I_A}\text{,}\) the middle-left column contains coefficients of \(\vec{I_B}\text{,}\) the middle-right column contains coefficients of \(\vec{I_C}\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 210-j159.15 \amp j159.15 \amp -80 \amp 12 \\ j159.15 \amp 266-j159.15 \amp -210 \amp 0 \\ -80 \amp -210 \amp 290+j119.38 \amp 0 \end{bmatrix} \end{equation*}
🔗
Solve the matrix for \(\vec{I_C}\text{.}\)
🔗
\begin{equation*} \vec{I_C} = 22.68-j35.74~\textrm{mA} \end{equation*}
🔗
Use Ohm’s law to calculate \(\vec{V}\text{.}\)
🔗
\begin{align*} \vec{V} \amp= (j119.38~\Omega)(\vec{I_C})\\ \amp= (j0.11938~\textrm{k}\Omega)(22.68-j35.74~\textrm{mA})\\ \amp= 4.27+j2.71~\textrm{V}\\ \amp= 5.05~\textrm{V} \angle 32.40^\circ \end{align*}
🔗
Convert to time-varying form.
🔗
\begin{equation*} v(t) = 5.05~\textrm{V}~\cos(2\pi200t + 32.4 \pi/180) \end{equation*}
