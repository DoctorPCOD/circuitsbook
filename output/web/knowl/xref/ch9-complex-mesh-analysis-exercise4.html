Exercise 14.

Calculate \(v(t)\) given the circuit diagram shown in Figure 9.6.32. The source value is \(v_{AC}(t) = 10~\textrm{V}~\cos(2\pi5000t - 50\pi/180)\text{.}\)
🔗
Answer.
\begin{equation*} v(t) = 8.09~\textrm{V}~\cos(2\pi5000t -35.6 \pi/180) \end{equation*}
🔗
🔗
Solution.
Use (8.2.4) to calculate the impedance of the capacitor.
🔗
\begin{equation*} \frac{1}{j(2\pi5000)(1.4 \times 10^{-6})} = -j22.7364~\Omega \end{equation*}
🔗
Transform the source into a phasor.
🔗
\begin{align*} \vec{V_{AC}} \amp= 10~\cos{-50^\circ} + j10~\sin{-50^\circ}~\textrm{V}\\ \amp= 6.4279 - j7.6604~\textrm{V} \end{align*}
🔗
Mesh current \(\vec{I_A}\) will flow clockwise around the left mesh. Mesh current \(\vec{I_B}\) will flow clockwise around the center mesh. Mesh current \(\vec{I_C}\) will flow clockwise around the right mesh. Derive the mesh equations.
🔗
\begin{align*} \vec{V_{AC}} \amp= 20\vec{I_A} + 50(\vec{I_A}-\vec{I_B})\\ 0 \amp= 50(\vec{I_B}-\vec{I_A}) -j22.7364\vec{I_B} + 20(\vec{I_B}-\vec{I_C}) + 2\vec{V}\\ 0 \amp= -2\vec{V} + 20(\vec{I_C}-\vec{I_B}) + 60\vec{I_C} \end{align*}
🔗
Derive an equation for the dependent source.
🔗
\begin{equation*} \vec{V} = 50(\vec{I_A}-\vec{I_B}) \end{equation*}
🔗
The four equations can be expressed in a matrix. The left column contains coefficients of \(\vec{I_A}\text{,}\) the next column contains coefficients of \(\vec{I_B}\text{,}\) the next column contains coefficients of \(\vec{I_C}\text{,}\) the next column contains coefficients of \(\vec{V}\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 70 \amp -50 \amp 0 \amp 0 \amp 6.4279 - j7.6604 \\ -50 \amp 70-j22.7364 \amp -20 \amp 2 \amp 0 \\ 0 \amp -20 \amp 80 \amp -2 \amp 0 \\ -50 \amp 50 \amp 0 \amp 1 \amp 0 \end{bmatrix} \end{equation*}
🔗
Solve the matrix for \(\vec{V}\text{.}\)
🔗
\begin{align*} \vec{V} \amp= 6.5722 - j4.7139~\textrm{V}\\ \amp= 8.0880~\textrm{V} \angle -35.6497^\circ \end{align*}
🔗
Convert to time-varying form.
🔗
\begin{equation*} v(t) = 8.09~\textrm{V}~\cos(2\pi5000t -35.6 \pi/180) \end{equation*}
