Exercise 15.

Calculate \(v(t)\) given the circuit diagram shown in Figure 9.6.34. The source voltage is \(v_{AC}(t) = 15~\textrm{V}~\cos(2\pi 600t + 25\pi/180)\text{.}\) The proportionality constant of the VCCS has a unit of A/V.
🔗
Answer.
\begin{equation*} v(t) = 15.8~\textrm{V}~\cos(2\pi600t + 122 \pi/180) \end{equation*}
🔗
🔗
Solution.
Use (8.2.4) to calculate the impedance of the capacitors.
🔗
\begin{align*} \frac{1}{j(2\pi 600)(6.6 \times 10^{-6})} \amp= -j40.1906~\Omega\\ \frac{1}{j(2\pi 600)(5.3 \times 10^{-6})} \amp= -j50.0487~\Omega \end{align*}
🔗
Transform the source into a phasor.
🔗
\begin{align*} \vec{V_{AC}} \amp= 15~\cos{25^\circ} + j15~\sin{25^\circ}~\textrm{V}\\ \amp= 13.5946 + j6.3393~\textrm{V} \end{align*}
🔗
Mesh current \(\vec{I_A}\) will flow clockwise around the upper mesh. Mesh current \(\vec{I_B}\) will flow clockwise around the lower-left mesh. Mesh current \(\vec{I_C}\) will flow clockwise around the lower-right mesh. The two bottom meshes comprise a supermesh. Derive the mesh and supermesh KVL equations.
🔗
\begin{align*} 0 \amp= (20-j50.05)\vec{I_A} + 60 (\vec{I_A}-\vec{I_C}) + 30 (\vec{I_A}-\vec{I_B})\\ 13.59+j6.34 \amp= 30(\vec{I_B}-\vec{I_A}) + 60(\vec{I_C}-\vec{I_A}) -j40.19\vec{I_C} \end{align*}
🔗
Relate the supermesh mesh currents to the branch current.
🔗
\begin{equation*} 0 = \vec{I_B} - 0.3\vec{V} - \vec{I_C} \end{equation*}
🔗
Derive an equation for the dependent source.
🔗
\begin{equation*} \vec{V} = 20\vec{I_A} \end{equation*}
🔗
The four equations can be expressed in a matrix. The left column contains coefficients of \(\vec{I_A}\text{,}\) the next column contains coefficients of \(\vec{I_B}\text{,}\) the next column contains coefficients of \(\vec{I_C}\text{,}\) the next column contains coefficients of \(\vec{V}\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 110-j50.05 \amp -30 \amp -60 \amp 0 \amp 0 \\ -90 \amp 30 \amp 60-j40.19 \amp 0 \amp 13.59+j6.34 \\ 0 \amp 1 \amp -1 \amp -0.3 \amp 0 \\ -20 \amp 0 \amp 0 \amp 1 \amp 0 \end{bmatrix} \end{equation*}
🔗
Solve the matrix for \(\vec{V}\text{.}\)
🔗
\begin{align*} \vec{V} \amp= -8.43+j13.42~\textrm{V}\\ \amp= 15.84~\textrm{V} \angle 122.13^\circ \end{align*}
🔗
Convert to time-varying form.
🔗
\begin{equation*} v(t) = 15.8~\textrm{V}~\cos(2\pi600t + 122 \pi/180) \end{equation*}
