Exercise 20.

Calculate \(i(t)\) given the circuit diagram shown in Figure 9.6.59. The frequency of operation is 20 Hz.
🔗
Answer.
\begin{equation*} i(t) = 152~\textrm{mA}~\cos(2\pi 20t - 8.72\pi/180) \end{equation*}
🔗
🔗
Solution.
Calculate \(\vec{I_1}\text{,}\) the current contributed by the 5 V source. Deactivate both other sources.
🔗
Calculate the equivalent impedance as seen by the j80 Ω impedance.
🔗
\begin{align*} \amp ((((j60~\Omega)+(120~\Omega)) // 100~\Omega) + 150~\Omega) // j80~\Omega\\ \amp= (((120+j60~\Omega) // 100~\Omega) + 150~\Omega) // j80~\Omega\\ \amp= ((57.6923 + j11.5385~\Omega) + (150~\Omega)) // j80~\Omega\\ \amp= (207.69 + j11.538~\Omega) // j80~\Omega\\ \amp= 25.8026 + j68.6277~\Omega \end{align*}
🔗
Use the voltage divider rule to calculate the voltage dropped over this equivalent impedance.
🔗
\begin{equation*} (5~\textrm{V})\frac{25.8026 + j68.6277~\Omega}{(200~\Omega)+(25.8026 + j68.6277~\Omega)} = 0.9458 + j1.2322~\textrm{V} \end{equation*}
🔗
Use Ohm’s law to calculate \(\vec{I_1}\text{.}\)
🔗
\begin{align*} \vec{I_1} \amp= \frac{0.9458 + j1.2322~\textrm{V}}{j80~\Omega}\\ \amp= 0.0154 - j0.0118~\textrm{A}\\ \amp= 15.4021 - j11.8231~\textrm{mA} \end{align*}
🔗
Calculate \(\vec{I_2}\text{,}\) the current contributed by the 10 V source. Deactivate the other sources.
🔗
The 120 Ω resistor and j60 Ω impedance are connected in series.
🔗
Re-draw the circuit.
🔗
Calculate the equivalent impedance as seen by the j80 Ω impedance.
🔗
\begin{equation*} \frac{(j80~\Omega)(200~\Omega)}{(j80~\Omega)+(200~\Omega)} = 27.5862 + j68.9655~\Omega \end{equation*}
🔗
Use the voltage divider rule to calculate the voltage dropped over the j80 Ω impedance. (Refer to Example 2.5.5 for information on solving a two-mesh voltage divider circuit.)
🔗
\begin{align*} \amp(10~\textrm{V} \angle 60^\circ)\\ \amp\left(\frac{(120+j60~\Omega) // (150~\Omega + (27.6 + j69.0~\Omega))}{100~\Omega + ((120+j60~\Omega) // (150~\Omega + (27.6 + j69.0~\Omega)))}\right)\\ \amp\left(\frac{(27.6 + j69.0~\Omega)}{150~\Omega + (27.6 + j69.0~\Omega)}\right)\\ \amp= -0.8951 + j1.5124~\textrm{V} \end{align*}
🔗
Use Ohm’s law to calculate \(\vec{I_2}\text{.}\)
🔗
\begin{align*} \vec{I_2} \amp= \frac{-0.8951 + j1.5124~\textrm{V}}{j80~\Omega}\\ \amp= 0.0189 + j0.0112~\textrm{A}\\ \amp= 18.9046 + j11.1888~\textrm{mA} \end{align*}
🔗
Calculate \(\vec{I_3}\) the current contributed by the current source. Deactivate the other two sources.
🔗
This is a four-mesh circuit and will use a current divider approach similar to what was explained in Example 2.6.4.
🔗
\begin{align*} \vec{I_3} \amp= (600~\textrm{mA} \angle 45^\circ)\\ \amp\left(\frac{((((200~\Omega // j80~\Omega) + 150~\Omega) // 100~\Omega) + j60~\Omega) // 120~\Omega}{((((200~\Omega // j80~\Omega) + 150~\Omega) // 100~\Omega) + j60~\Omega)}\right)\\ \amp\left(\frac{((200~\Omega // j80~\Omega) + 150~\Omega) // 100~\Omega}{((200~\Omega // j80~\Omega) + 150~\Omega)}\right)\\ \amp\left(\frac{200~\Omega // j80~\Omega}{j80~\Omega}\right)\\ \amp= 115.75 - j22.385~\textrm{mA} \end{align*}
🔗
Calculate \(\vec{I}\text{.}\)
🔗
\begin{align*} \vec{I} \amp= \vec{I_1}+\vec{I_2} +\vec{I_3}\\ \amp= (15.40-j11.82~\textrm{mA}) + (18.90+j11.19~\textrm{mA}) + (115.75-j22.38~\textrm{mA})\\ \amp= 150.05-j23.019~\textrm{mA}\\ \amp= 151.8077~\textrm{mA} \angle -8.7216^\circ \end{align*}
🔗
Convert to time-varying form.
🔗
\begin{equation*} i(t) = 152~\textrm{mA}~\cos(2\pi 20t - 8.72\pi/180) \end{equation*}
