Exercise 27.

Derive the Thévenin equivalent circuit between nodes a and b in the circuit shown in Figure 9.6.94. The current source has a value of \(i_{AC}(t) = 60~\textrm{mA}~\cos(2\pi 1500t)\text{.}\)
🔗
Answer.
🔗
Solution.
Use (8.2.4) to calculate the impedance of the capacitor.
🔗
\begin{equation*} \frac{1}{j(2\pi1500)(2 \times 10^{-6})} = -j53.0516~\Omega \end{equation*}
🔗
Use (8.2.5) to calculate the impedance of the inductor.
🔗
\begin{equation*} j(2\pi1500)(0.01) = j94.2478~\Omega \end{equation*}
🔗
Transform the source into a phasor.
🔗
\begin{align*} \vec{I_{AC}} \amp= 60~\cos{0^\circ} + j60~\sin{0^\circ}~\textrm{mA}\\ \amp= 60~\textrm{mA} \end{align*}
🔗
Calculate the equivalent impedance as seen by the current source.
🔗
\begin{equation*} \frac{(50+j94.2~\Omega)(100-j53~\Omega)}{(50+j94.2~\Omega)+(100-j53~\Omega)} = 73.5207 + j24.9562~\Omega \end{equation*}
🔗
Use the current divider rule to calculate the current flow through the branch including the 100 Ω resistor.
🔗
\begin{equation*} 60~\textrm{mA}\left(\frac{73.5207 + j24.9562~\Omega}{100-j53.05}\right) = 28.2248 + j29.9474~\textrm{mA} \end{equation*}
🔗
Use Ohm’s law to calculate the Thévenin equivalent voltage.
🔗
\begin{align*} \vec{V_{TH}} \amp= (28.2248 + j29.9474~\textrm{mA})(0.1~\textrm{k}\Omega)\\ \amp= 2.8225 + j2.9947~\textrm{V}\\ \amp= 4.1152~\textrm{V} \angle 46.6962^\circ \end{align*}
🔗
Deactivate the source and calculate the Thévenin equivalent impedance.
🔗
\begin{align*} \vec{Z_{TH}} \amp= (100~\Omega)//(50~\Omega+j94.25~\Omega-j53.05~\Omega)\\ \amp= 38.0092 + j17.0252~\Omega \end{align*}
🔗
Use (8.2.5) to calculate the value of the inductance based on the Thévenin equivalent reactance of the circuit.
🔗
\begin{align*} L \amp= \frac{17.03}{2 \pi 50}\\ \amp= 1.8064~\textrm{mH} \end{align*}
