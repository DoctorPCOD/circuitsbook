Exercise 8.

Calculate \(v(t)\) given the circuit diagram shown in Figure 9.6.17. The source frequency is 20 kHz.
🔗
Answer.
\begin{equation*} v(t) = 14.6~\textrm{V}~\cos(2\pi 20000t + 4.18\pi/180) \end{equation*}
🔗
🔗
Solution.
The −j3 Ω and 4 Ω impedances are connected in series.
🔗
Define branch currents.
🔗
Perform KCL at two perfect nodes. All units used in subsequent equations in this problem are V, A, and Ω.
🔗
\begin{align*} \vec{I_1} + \vec{I_2} \amp= 15 \angle 0^\circ\\ \vec{I_2}-\vec{I_3}-\vec{I_4} \amp= 0 \end{align*}
🔗
Perform KVL around two loops. The equations below use the center loop and right loop of the circuit.
🔗
\begin{align*} -6\vec{I_1} +j9\vec{I_2} + (4-j3)\vec{I_3} \amp= 0\\ -(4-j3)\vec{I_3} + (8+j5)\vec{I_4} \amp= 0 \end{align*}
🔗
The four equations can be expressed in a matrix. The left column contains coefficients of \(\vec{I_1}\text{,}\) the next column contains coefficients of \(\vec{I_2}\text{,}\) the next column contains coefficients of \(\vec{I_3}\text{,}\) the next column contains coefficients of \(\vec{I_4}\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp 1 \amp 0 \amp 0 \amp 15 \angle 0^\circ\\ 0 \amp 1 \amp -1 \amp -1 \amp 0\\ -6 \amp j9 \amp (4-j3) \amp 0 \amp 0\\ 0 \amp 0 \amp -(4-j3) \amp (8+j5) \amp 0 \end{bmatrix} \end{equation*}
🔗
The branch current that needs to be known to solve for \(\vec{V}\) is \(\vec{I_4}\text{.}\) This value is
🔗
\begin{equation*} \vec{I_4} = 0.2130 - j2.9179~\textrm{A}\text{.} \end{equation*}
🔗
Use Ohm’s law to calculate \(\vec{V}\text{.}\)
🔗
\begin{align*} \vec{V} \amp= (0.2130 - j2.9179~\textrm{A})(j5~\Omega)\\ \amp= 14.5897 + j1.0652~\textrm{V}\\ \amp= 14.6286~\textrm{V} \angle 4.1758^\circ \end{align*}
🔗
Convert the signal to a time-varying function.
🔗
\begin{equation*} v(t) = 14.6~\textrm{V}~\cos(2\pi 20000t + 4.18\pi/180) \end{equation*}
