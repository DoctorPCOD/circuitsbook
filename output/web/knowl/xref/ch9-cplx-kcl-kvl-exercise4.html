Exercise 9.

Calculate \(v(t)\) given the circuit diagram shown in Figure 9.6.20. The source frequency is 30 Hz.
🔗
Answer.
\begin{equation*} v(t) = 146~\textrm{V}~\cos(2\pi30t + 14.0 \pi/180) \end{equation*}
🔗
🔗
Solution.
Define branch currents.
🔗
Perform KCL at two perfect nodes. All units used in subsequent equations in this problem are V, A, and Ω.
🔗
\begin{align*} \vec{I_2}-\vec{I_3}-\vec{I_4} \amp= 0\\ \vec{I_1}+\vec{I_4}-\vec{I_5} \amp= 0 \end{align*}
🔗
Perform KVL around three perfect loops.
🔗
\begin{align*} 5\vec{I_2} -j10\vec{I_3} \amp= 100 \angle 0^\circ\\ j10\vec{I_3} + 10\vec{I_4} + j10\vec{I_5} \amp= 0\\ -j5\vec{I_1} - 10\vec{I_4} - 5\vec{I_2} \amp= 0 \end{align*}
🔗
The five equations can be expressed in a matrix. The left column contains coefficients of \(\vec{I_1}\text{,}\) the next column contains coefficients of \(\vec{I_2}\text{,}\) the next column contains coefficients of \(\vec{I_3}\text{,}\) the next column contains coefficients of \(\vec{I_4}\text{,}\) the next column contains coefficients of \(\vec{I_5}\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 0 \amp 1 \amp -1 \amp -1 \amp 0 \amp 0\\ 1 \amp 0 \amp 0 \amp 1 \amp -1 \amp 0\\ 0 \amp 5 \amp -j10 \amp 0 \amp 0 \amp 100 \angle 0^\circ\\ 0 \amp 0 \amp j10 \amp 10 \amp j10 \amp 0\\ -j5 \amp -5 \amp 0 \amp -10 \amp 0 \amp 0 \end{bmatrix} \end{equation*}
🔗
The branch current that needs to be known to solve for \(\vec{V}\) is \(\vec{I_5}\text{.}\) This value is
🔗
\begin{equation*} \vec{I_5} = 3.53-j14.12~\textrm{A}\text{.} \end{equation*}
🔗
Use Ohm’s law to calculate \(\vec{V}\text{.}\)
🔗
\begin{align*} \vec{V} \amp= (3.53-j14.12~\textrm{A})(j10~\Omega)\\ \amp= 141.18+j35.29~\textrm{V}\\ \amp= 145.52~\textrm{V} \angle 14.04^\circ \end{align*}
🔗
Convert to time-varying form.
🔗
\begin{equation*} v(t) = 146~\textrm{V}~\cos(2\pi30t + 14.0 \pi/180) \end{equation*}
