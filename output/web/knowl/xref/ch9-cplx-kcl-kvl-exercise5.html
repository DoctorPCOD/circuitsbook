Exercise 10.

Calculate \(v(t)\) given the circuit diagram shown in Figure 9.6.22. The source value is \(v_{AC}(t) = 5~\textrm{V}~\cos(2\pi 200 t)\text{.}\) The proportionality constant of the VCCS has a unit of A/V.
🔗
Answer.
\begin{equation*} 3.12~\textrm{V}~\cos(2\pi200t - 8 \pi/180) \end{equation*}
🔗
🔗
Solution.
Use (8.2.4) to calculate the impedance of the capacitors.
🔗
\begin{align*} \vec{Z_{C40}} \amp= \frac{1}{j(2\pi 200)(40 \times 10^{-6})}\\ \amp= j19.8944~\Omega\\ \vec{Z_{C100}} \amp= \frac{1}{j(2\pi 200)(100 \times 10^{-6})}\\ \amp= j7.9577~\Omega \end{align*}
🔗
Convert the source to phasor form.
🔗
\begin{align*} \vec{V_{AC}} \amp= 5~\cos{0^\circ} +j5~\sin{0^\circ}~\textrm{V}\\ \amp= 5~\textrm{V} \end{align*}
🔗
The 7 Ω resistor is connected in parallel with the −j7.96 Ω impedance.
🔗
\begin{align*} \vec{Z'} \amp= \frac{(7~\Omega)(j7.9577~\Omega)}{(7~\Omega)+(j7.9577~\Omega)}\\ \amp= 3.9464 - j3.4714~\Omega \end{align*}
🔗
Define branch currents.
🔗
Perform KCL at two perfect nodes. All units used in subsequent equations in this problem are V, A, and Ω.
🔗
\begin{align*} \vec{I_1}-\vec{I_2}-\vec{I_3} \amp= 0\\ \vec{I_3} - 0.5\vec{V} - \vec{I_4} \amp= 0 \end{align*}
🔗
Perform KVL around two perfect loops.
🔗
\begin{align*} 2\vec{I_1} +5\vec{I_2} \amp= \vec{V_{AC}}\\ -5\vec{I_2} - j19.89\vec{I_3} + (3.94-j3.47)\vec{I_4} \amp= 0 \end{align*}
🔗
Derive a dependent source equation.
🔗
\begin{equation*} \vec{V} = 5\vec{I_2} \end{equation*}
🔗
The five equations can be expressed in a matrix. The left column contains coefficients of \(\vec{I_1}\text{,}\) the next column contains coefficients of \(\vec{I_2}\text{,}\) the next column contains coefficients of \(\vec{I_3}\text{,}\) the next column contains coefficients of \(\vec{I_4}\text{,}\) the next column contains coefficients of \(\vec{V}\text{,}\) and the right column contains constants.
🔗
\begin{equation*} \begin{bmatrix} 1 \amp -1 \amp -1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp -1 \amp -0.5 \amp 0 \\ 2 \amp 5 \amp 0 \amp 0 \amp 0 \amp 5 \\ 0 \amp -5 \amp -j19.89 \amp 3.9-j3.74 \amp 0 \amp 0 \\ 0 \amp 5 \amp 0 \amp 0 \amp -1 \amp 0 \end{bmatrix} \end{equation*}
🔗
Solve the matrix for \(\vec{V}\text{.}\)
🔗
\begin{align*} \vec{V} \amp= 3.0910 - j0.4346~\textrm{V}\\ \amp= 3.1214~\textrm{V} \angle -8.0037^\circ \end{align*}
🔗
Convert to time-varying form.
🔗
\begin{equation*} v(t) = 3.12~\textrm{V}~\cos(2\pi200t - 8 \pi/180) \end{equation*}
