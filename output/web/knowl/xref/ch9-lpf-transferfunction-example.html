Example 9.2.1 First-order RC circuit transfer function.

Derive the transfer function, magnitude response, and phase response of the circuit shown below.
🔗
The voltage divider rule can be used to derive the transfer function of the circuit.
🔗
\begin{align*} H(j\omega) \amp= \left( \frac{\frac{1}{j\omega C}}{R + \frac{1}{j\omega C}} \right)\\ \amp= \frac{1}{j\omega RC + 1}\\ \amp= \frac{\frac{1}{RC}}{j\omega + \frac{1}{RC}} \end{align*}
🔗
Use the Pythagorean theorem in both the numerator and denominator to derive the magnitude response of the transfer function.
🔗
\begin{align*} |H(j\omega)| \amp= \left| \frac{\frac{1}{RC}}{j\omega + \frac{1}{RC}} \right|\\ \amp= \frac{|\frac{1}{RC}|}{|j\omega + \frac{1}{RC}|}\\ \amp= \frac{\frac{1}{RC}}{\sqrt{\omega^2 + (\frac{1}{RC})^2}} \end{align*}
🔗
Use the arctan function to derive the phase response of the transfer function.
🔗
\begin{align*} \angle H(j\omega) \amp= \frac{\angle (\frac{1}{RC})}{\angle (j\omega + \frac{1}{RC})}\\ \amp= \frac{0^\circ}{\atantwo{(\omega, \frac{1}{RC})}}\\ \amp= -\atantwo{\left(\omega, \frac{1}{RC}\right)} \end{align*}
