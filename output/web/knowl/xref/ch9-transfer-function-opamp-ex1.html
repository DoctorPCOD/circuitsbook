Example 9.2.5 Op-amp transfer function in symbolic form.

Derive the transfer function for the circuit shown below. Use KCL at the inverting input of the op-amp.
🔗
\begin{align*} \frac{v_{in}(\omega)}{R_1} \amp= -\frac{v_{out}(\omega)}{R_2} - \frac{v_{out}(\omega)}{\frac{1}{j\omega C}}\\ \amp= -v_{out}(\omega)\left(\frac{1}{R_2}+j\omega C\right)\\ H(j\omega) \amp= \frac{-\frac{1}{R_1}}{j\omega C + \frac{1}{R_2}}\\ \amp= \frac{-\frac{1}{R_1C}}{j\omega + \frac{1}{R_2C}} \end{align*}
