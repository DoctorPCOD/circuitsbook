Example 9.2.7 Op-amp transfer function in symbolic form.

Derive the transfer function of the circuit shown below. Use KCL at the inverting input of the op-amp.
🔗
\begin{align*} \frac{v_{in}(\omega)}{R_1+\frac{1}{j\omega C}} \amp= -\frac{v_{out}(\omega)}{R_2}\\ H(j\omega) \amp= -\frac{R_2}{R_1+\frac{1}{j\omega C}}\\ \amp= -\frac{j\omega CR_2}{j\omega CR_1+1}\\ \amp= \frac{-j\omega \frac{R_2}{R_1}}{j\omega + \frac{1}{R_1C}} \end{align*}
