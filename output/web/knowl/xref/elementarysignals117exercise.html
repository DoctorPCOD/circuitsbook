Exercise 17.

Derive an equation for the signal shown in Figure 1.7.13.
🔗
Hint.
There is more than one correct answer to this question.
🔗
🔗
Answer.
Using the step function: \(f(t) = u(t+4) + u(t+1) -3u(t-1) +u(t-4)\)
🔗
Using the rectangular pulse function: \(f(t) = \textrm{rect}\left(\frac{t+2.5}{3}\right) +2~\textrm{rect}\left(\frac{t}{2}\right) - \textrm{rect}\left(\frac{t-2.5}{3}\right)\)
🔗
🔗
Solution.
Option one is to use step functions to create this signal. The first step function occurs at \(t = -4~\textrm{s}\) and has an amplitude of \(A = 1\text{.}\) This is equal to \(u(t+4)\text{.}\)
🔗
At \(t = -1~\textrm{s}\text{,}\) another step function with amplitude of \(A = 1\) is added. This is equal to \(u(t+1)\text{.}\) The total amplitude of the function becomes 2 at this point (this is equal to the sum of the amplitudes of this and the previous step function).
🔗
At \(t = 1~\textrm{s}\text{,}\) another step function of amplitude \(A = -3\) is added. This is equal to \(-3u(t-1)\text{.}\) The total amplitude of the function becomes −1 at this point (this is equal to the sum of the amplitudes of this and the previous two step functions).
🔗
At \(t = 4~\textrm{s}\) a step function with amplitude of \(A = 1\) is added. This is equal to \(u(t-4)\text{.}\) The total amplitude of the function becomes zero at this point (this is equal to the sum of the amplitudes of this and the previous three step functions). After that point, the signal remains constant at zero.
🔗
Option two is to use the rectangular pulse function to create this signal. A rectangular pulse can be used to define each individual rectangular area of the graph. The first is highlighted in yellow below.
🔗
This pulse spans between \(t = -4~\textrm{s}\) and \(t = -1~\textrm{s}\text{,}\) which means it’s centered at \(\lambda = -2.5~\textrm{s}\) and has a width of \(\tau = 3~\textrm{s}\text{.}\) The amplitude of this rectangle is \(A = 1\text{.}\) This is equal to \(\textrm{rect}\left(\frac{t + 2.5}{3}\right)\text{.}\)
🔗
The second rectangular area is highlighted in yellow below.
🔗
This pulse spans between \(t = -1~\textrm{s}\) and \(t = 1~\textrm{s}\text{,}\) which means it’s centered at \(\lambda = 0~\textrm{s}\) and has a width of \(\tau = 2~\textrm{s}\text{.}\) The amplitude of this rectangle is \(A = 2\text{.}\) This is equal to \(2\textrm{rect}\left(\frac{t}{2}\right)\text{.}\)
🔗
The third and last rectangular area is highlighted in yellow below.
🔗
This pulse spans between \(t = 1~\textrm{s}\) and \(t = 4~\textrm{s}\text{,}\) which means it’s centered at \(\lambda = 2.5~\textrm{s}\) and has a width of \(\tau = 3~\textrm{s}\text{.}\) The amplitude of this rectangle is \(A = -1\text{.}\) This is equal to \(-\textrm{rect}\left(\frac{t-2.5}{3}\right)\text{.}\)
