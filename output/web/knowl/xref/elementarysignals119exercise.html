Exercise 19.

Sketch the function \(f(t) = 3u(t+5) + \frac{t}{2}u(t)\text{.}\)
🔗
Answer.
🔗
Solution.
The signal has a value of zero until \(t = -5~\textrm{s}\) when a step function with amplitude \(A = 3\) will start. The function will have a constant amplitude of 3 until \(t = 0\text{,}\) at which time a ramp function with a slope of 0.5 is added.
