Derivation

\begin{align*} R_{EQ} \amp = \frac{\rho l}{A_1+A_2+A_3+...+A_n}\\ \amp = \frac{1}{\frac{A_1}{\rho l}+\frac{A_2}{\rho l}+\frac{A_3}{\rho l}+...+\frac{A_n}{\rho l}}\\ \frac{1}{R_{EQ}} \amp = \frac{A_1}{\rho l} + \frac{A_2}{\rho l} + \frac{A_3}{\rho l} + ... + \frac{A_n}{\rho l}\\ \amp = \frac{1}{R_1} + \frac{1}{R_2} + \frac{1}{R_3} + ... + \frac{1}{R_n} \end{align*}
