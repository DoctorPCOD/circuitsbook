Exercise 11.

What kind of dependent source is depicted in Figure 1.7.5? How do you know?
🔗
Answer.
The dependent source is a voltage-controlled voltage source (VCVS). The controlling value is a voltage and the source itself is a voltage source.
🔗
🔗
Solution.
The controlling value is \(V_X\text{.}\) Because the symbol contains the letter \(V\text{,}\) that means this quantity represents a voltage drop. This means the source must be either a VCVS or a VCCS.
🔗
To determine if the source is a voltage source or a current source, compare to the circuit symbols shown in Figure 1.5.1. The symbol on the dependent source contains a + and − sign indicating that it is a voltage source. This means the source is a VCVS.
