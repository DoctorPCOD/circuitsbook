Exercise 12.

What kind of dependent source is depicted in Figure 1.7.6? How do you know?
🔗
Answer.
The dependent source is a current-controlled voltage source (CCVS). The controlling value is a current and the source itself is a voltage source.
🔗
🔗
Solution.
The controlling value is \(I_X\text{.}\) Because the symbol contains the letter \(I\text{,}\) that means this quantity represents a current. This means the source must be either a CCVS or a CCCS.
🔗
To determine if the source is a voltage source or a current source, compare to the circuit symbols shown in Figure 1.5.1. The symbol on the dependent source contains a + and − sign indicating that it is a voltage source. This means the source is a CCVS.
